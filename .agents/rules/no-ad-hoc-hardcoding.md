# IntMap — 場当たりのハードコーディングを禁止する (No case-by-case hardcoding)

> **恒久指示。** 利用者の指示（#R515）:「**ハードコーディングで逐事的に対処すること自体を恒久的に禁止しろ。**」
> `AGENTS.md` §3 の 9 番がこのファイルを指す。正本はここ。

## 1. 何を禁止するのか

**報告された 1 件を消すために、その 1 件のための記述をコードへ足すこと。**

具体的に、次を書いてはならない:

- **症状ごとの分岐・特例**（「この名前のときだけ」「この国のときだけ」「この URL のときだけ」）
- **名前・ID・綴り・URL の埋め込み一覧**で、実体から導けるもの
  （レイヤー名・ファイル名・能力 ID・関数名・テストが守るべき綴り……）
- **由来を書けない定数**（どこから来た数か、いつ失効するかを言えない閾値・件数・ミリ秒）
- **1 つの呼び出し元だけを守る検査**。規則は**関数ではなく事実**に付ける
- **既にある仕組みの写し**。同じ判断を 2 か所に持たせない

⚠ **禁じているのは「定数」ではなく「事例ごとの記述」である。** 観測から導いた閾値は正当な実装であり、
下の §4 の 3 点を書けるなら書いてよい。書けないなら、それは場当たりである。

## 2. 代わりに何をするのか

1. **直すのは事例ではなく、その事例を生んだ構造。**
   「なぜこの 1 件が通ったのか」ではなく「**この種のものが通る仕組みは何か**」を直す。
2. **判断が要るなら、判断できるものに訊く。**
   データ・上流・**Atlas**（`atlas-full-authority-no-new-limits`）。
   **コードの仕事は判断することではなく、根拠のないものを拒むこと。**
3. **同じ判断を既に持っている場所を先に探す。** あれば**配る**（依存として注入する）。写さない。
4. **一覧が要るなら、一覧を発見する。** ディレクトリ・レジストリ・スキーマ・実データから数え上げる。
   手で並べた一覧は、次に足されたものを黙って落とす。

## 3. 着手前の 3 問（1 つでも「いいえ」なら、まだ直っていない）

- この修正は、**報告された 1 件以外の同種のもの**にも効くか。
- この規則は、**次に同じ経路を通る新しいコード**にも効くか（＝関数ではなく事実に付いているか）。
- 同じ判断が**もう 1 か所にもある**なら、そちらも同じ答えを返すか。

## 4. 定数を書くときに必ず書くこと

1. **観測** — いつ・何を測って得た数か（推定なら推定と書く）
2. **失効条件** — 何が変われば無効になるか
3. **正本** — 同じ数を必要とする箇所が他にもあるなら、どこが正本か

## 5. 実測された失敗の形（このリポジトリの記録から）

| ラウンド | 場当たりだったもの | 構造としての直し方 |
|---|---|---|
| #R515 | `geocode()` が `limit=1` で先頭を無検証採用。名前の一覧で例外を足せば「その港」は直るが次の港は直らない | **尺度**（文字 bigram の一致度）で判定し、一致が無ければ拒む。さらに**何であるかは Atlas と実ウェブに訊く**——コードは根拠のないものを拒むだけ |
| #R515 | 名前一致の規則が `_nomExtent` と `_atlNameOk` に**2 つあり**、片方は地域だけ・片方は Latin only | 規則を**事実**（「返ってきた名前は問い合わせと一致するか」）に付け、経路ごとの写しをやめる |
| #R488 | 検査が CSS 選択子の**綴り**を固定していたので、死んだ規則が緑のまま残った | 「その選択子は何かに当たっているか」を CSSOM に訊く |
| #R429 | 1 ファイルに向けて書いた検査が、そのファイルだけを守っていた | 守るべき事実を全経路に対して測る |
| #R505 | ソースを**読む**検査は評価順序を見られない | 関数を**実際に評価**する |
| #R500 | 機械が持つ数を散文が写した箇所は必ず離れる | 散文の数を実体から照合する（`doc-facts`） |

⚠ **この表は網羅ではなく、形の見本である。** 新しい形を見つけたら 1 行足す。

## 6. どうしても事例ごとの記述が要るとき

上流が壊れている・仕様がその 1 件だけ違う、ということは実際にある。そのときは:

- **その 1 件であることをコードに書く**（何が・いつから・何が変われば消せるのか）
- **消せる条件を検査にする**か、消せないなら**なぜ消せないか**を書く
- `DEV-NOTES.md` に**なぜ構造で直せなかったか**を残す

⚠ **「時間が無い」「とりあえず」は理由ではない。** それは `AGENTS.md` §3 の 3 が禁じる暫定実装である。
