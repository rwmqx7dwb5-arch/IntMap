# fonts/ — the typeface IntMap draws every character with (#R242)

「IntMap内のすべての文字は以下にしろ。すべての文字をこうしろ。地名ラベルも例外ではない。（恒久的に）」

| script | face | where it comes from |
|---|---|---|
| Latin / Cyrillic / Greek | **Inter** | bundled — `inter-*.woff2` (UI) and `Inter Regular/*.pbf` (map labels) |
| 日本語 | **Noto Sans JP** | Google Fonts, unicode-range subsets (see `css/fonts.css`) |
| 简体中文 | **Noto Sans SC** | Google Fonts |
| 繁體中文 | **Noto Sans TC** | Google Fonts |
| 한국어 | **Pretendard** | bundled — `pretendard.woff2` |
| 🇯🇵 flags | Twemoji Country Flags | bundled at the repo root (`TwemojiCountryFlags.woff2`, #R79e) |

## What each file is

* `inter-{latin,latin-ext,cyrillic,cyrillic-ext,greek}.woff2` — Inter 4.1 as a **variable** font
  (weights 100–900), split by `unicode-range` so a page downloads only the scripts it paints.
  Declared in `css/fonts.css`.
* `pretendard.woff2` — Pretendard 1.3.9 Regular, scoped to the Hangul blocks for the same reason.
  766 KB, and it is fetched **only** when Hangul is actually on screen.
* `Inter Regular/{range}.pbf` — **SDF glyph atlases for the map**, generated by
  `scripts/build-glyphs.mjs` from `src/Inter.ttf`. A MapLibre symbol layer cannot read CSS: it asks a
  glyph server for `{fontstack}/{range}.pbf`, and no public glyph server serves Inter (measured:
  `Inter Regular/0-255.pbf` is a 404 on tiles.openfreemap.org; fonts.openmaptiles.org publishes
  Metropolis / Open Sans / Noto only). So the app ships its own and `js/map-typography.js` redirects
  those ranges to them.
  ⚠ Each atlas is a **superset** of the Noto Sans range it replaces: a codepoint Inter does not have
  keeps its Noto glyph, so nothing that is on the map today can disappear. Ranges outside the
  generated set (Arabic, Thai, Devanagari, Hebrew, CJK…) are untouched and still come from
  openfreemap.
* `src/Inter.ttf` — the generator's INPUT, kept in the repo so the atlases are reproducible. It is
  excluded from the deploy (`vite.config.js` → `STATIC_EXCLUDE`).

## Regenerating

```
node scripts/build-glyphs.mjs           # rebuild every range (needs the network for the Noto fill-in)
node scripts/build-glyphs.mjs --check   # verify the committed atlases still cover the font
```
