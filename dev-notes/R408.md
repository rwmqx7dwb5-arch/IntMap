### 2. 一番大きかったのは、宣言だけあって呼び出し元が0件の機構

`js/runtime.js` は #R234 から **「hidden なタブでは動かない1本のタイマーホイール」** を持ち、

`js/label-occlusion.js` がさらに style を2周）は **`document.hidden` で守られていない**。

**174ラウンド、宣言と実体が食い違ったまま**——#R394 の「走っていない機構を名乗る列」と同じ形。

⇒ **30 ファイル・43 本**を移した。`js/runtime.js` に `everyTick(key,ms,fn,opts)` /
`stopTick(stop)` / `tickKey(prefix)` を足し、各ファイルはそれを import する。

### 3. プレビューのキューは、パネルを開かなくても 33 件を一気に流していた

`_openQueue`（`js/layer-previews.js`）は `_paintQ` を **1回の同期 forEach で drain** し、
`deadline.timeRemaining()` はこのファイルに 0 件、入力中断もモバイル抑止も無かった。

- **6 ms スライス**。`requestIdleCallback` の deadline と時計の**両方**で区切り、残りは次の idle へ。
  `requestIdleCallback` が無い環境も同じ 6 ms を時計で守る。
- ⚠ **1スライスで必ず1件は走る。** 予算を毎回見ると、予算より長いペインタ（実測 `statChoro` 85.1 ms）
  で**1件も進まないまま永久に再予約する**。最初の1件を無条件に走らせることが停止性の根拠でもある。

- **携帯では起動経路（最初の idle / 6 秒）が門を開かない。** `kick()` は無傷なので、**シートを開けば

- `js/layer-previews.js:709` のコメントを実測に書き直した（28 枚 / 4,051,978 B / 即時 33 件 /

### 4. 警報の斜線カットは、パンのたびに必ずキャッシュを外していた

鍵に**視野の矩形**（0.25 度丸め）が入っていた。0.25 度は指が動かすどのパンよりも細かいので、
**警報を出したままパンすると毎回外れる**。外したあとに走るのは `shown`（数千地物）からの
「答えている地面」の一覧・そこから作る 10 度の格子・視野の旗・頂点数での整列であり、肝心の引き算だけが
`cutMemo` で無料——そして #R344 の出力署名が「変わっていない」と結果を捨てる。
つまり**毎パン、同じ絵を作り直して捨てていた**。#R387 の実測では、警報を載せたパンは
**7,074 ms**（載せないと 345 ms）で、その **74 % がレンダラの外**にある。

⇒ 切った結果は `sig` と tier 0 の集合と「**どの tier 0 の国が視野にいるか**」の関数であって、
**同じ国の集合の中で動くかぎり出力は 1 地物も変わりえない**。鍵を `zeroSeen`（視野内 tier 0 の集合）に
し、そのために必要な視野の旗を**早期 return の前**で数えるよう上げた（下で数え直すと、鍵が指すものと
実際に回すものが 2 か所で決まる）。⚠ **切る集合そのものは変えていない**——変えたのは鍵だけ。

### 直し方: 主張する側が主張を確かめる

`mountInto` は携帯で**2回**呼ばれ、**2つのうち片方だけが `kick()` の言う意味を満たす**:

| 呼び出し元 | いつ | シート |

⇒ `mountInto` の側で「格子を載せているシートが表示されているか」を見る。

### ⚠⚠⚠ そして pan-alerts は、この主張の検証になっていない

`scripts/mobile-trace.mjs` の `PAN = { dx:170, dy:120 }` は、アプリ既定の `zoom:1.7`
（`js/app-body.js`。世界幅 ≈ 832 px）では**経度で約 74°＝視野幅の約 44 % の跳躍**である。
R408 の新しい鍵は「**視野に入っている tier 0 の国の集合**」なので、**その大きさのパンでは新旧
どちらの鍵も外れる**。つまりこの位相は、**修正が適用されない側のケースだけを駆動している。**

⇒ **`pan-alerts` の 7,074 / 7,314 ms を「R408 で変わらなかった」の根拠にしてはならない。**
測るなら、R408 が名指した条件——**都市ズームでの数 px のパン**（＝同じ国の集合の中で動く）——で
駆動しなければならない。#R387 が「条件の違う 2 つの数を並べるな」と書いたのと同じ形が、今度は
**同じ計器の中で**起きている。

⚠ **hidden タブのタイマーは、この 2 計器のどちらにも該当機構が無い**（`frame-profile.mjs` にも
`mobile-trace.mjs` にも `document.hidden` / `visibilitychange` / visibility emulation の呼び出しは
0 件）。**測れなかったのであって 0 ではない**（#R322）。
⇒ ここは**本番で測れた**: 本番のホイールに自前のプローブを 2 本登録し、24,535 ms のあいだに
