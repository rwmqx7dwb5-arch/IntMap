〈依頼〉 利用者の決定（2026-10-02）: 絵文字のアイコン（Tools の地球・定規・鉛筆・氷・丸・カメラ等）を iOS 風の
線画アイコン（SVG）に置き換えてよい。1 つのモジュールに統一した線画を名前で持ち `icon(name)` が markup を返す・
CSS は 1 か所・製品のコード／index.html／静的ページ／ロケールの文字列から**全数**置き換え・アイコンとしての
絵文字が新しく入ったら赤になる門（check:static の規則。新しい check:* は足さない）。

## 0. 測った

- 本番の DOM（依頼時の実測）: 時計 10・地球 6・カメラ 5・警告 4・カード索引 3・錠 3、ほか約 30 種。
- 配信物の**文字列（コメントを除く・エスケープも展開）**を数えた結果（`scripts/icon-glyphs.mjs` の初回）:
  **106 ファイル・1,767 箇所**。内訳の大きいもの: Atlas の `warn('⚠ …')` 315・ロケール辞書（fr/ko/zh/zh-hans が
  英語キーごと約 80 ずつ）・Atlas の確認行 `note('🌊 …')`・天気コードの表・再生器の ▶ ⏸ ⏭・index.html 24。
- コメントの ⚠ は数えていない（このリポジトリの注記の作法で、読者には見えない）。© と文中の矢印（↗ ↔ など）は
  **文字として読む記号**なので対象外にした（ライセンス表記・「Wikipedia ↗」・相関の ↗／↘）。

## 1. 体系（js/icons.js）

- 24 グリッド・線幅 1.75・丸い端・currentColor・1 アイコン 1 path、114 種。図はすべて自前（ベンダーの
  記号集合から写していない）。ウィジェットの `WC.icon` と同じ図は同じ path を使った。
- `icon()`（markup・`IntMapSafe.markup` 製）／`iconNode()`（DOM）／`data-icon` 枠＋`hydrateIcons()`（静的
  マークアップ）／`withIcons()`（訳文の `{icon:name}`）／`iconImageData()`（地図のシンボル層の画素）。
- CSS は `css/intmap.css` の `.im-icon` 1 つ。大きさと線は属性なので intmap.css を読まないページでも同じ大きさ。

## 2. 置き換え——直したのは構造

- **Atlas の警告行は `warn()` が自分で警告の印を描く。** 315 の呼び出しが各自 `'⚠ '` を前に書いていた。
  印を描く場所を 1 つにしたので、呼び出し側は文だけを渡す（以前から ⚠ の無かった 18 行も警告の印が付く）。
- **文字と絵を分けた。** ロケールの文字列（keyed も inline も）から絵文字を外し、絵は UI 側（`data-icon`・
  `icon()`）が描く。`data-i18n` がボタン全体の `innerText` を書き換えていた所は、ラベルを内側の `<span>` に
  移した（そのままだと翻訳の適用で絵が消える）。
- **ボタンの名前を絵で呼ぶ文**（「▶ を押すと」「🚗 か 🚶 を」「⏭ の計算上限」）は 9 言語とも同じ
  `{icon:play}` などのトークンを持ち、`withIcons()` が描く——翻訳を書き直さずに意味を保った。
  ストリートビューの「◀ ▶ で向きを変える」は**ボタンの実物が ↺ ↻** だったので、その文字に合わせた。
- **`textContent` で絵を差し替えていた所**（再生／一時停止・消音・コピーの完了）は `replaceChildren(iconNode())`。
  コピーの完了表示は「✓ Copied!」を「チェックの絵＋Copied!」にし、戻すときも絵を描き直す。
- **データの欄**: 共同体の分類 `emoji` → `icon`（名前）、飛行機の種類・天気コード・地図の対象種別も名前に。
  国旗の無い国に `flagFromISO2` が埋めていた白旗は**データとしては空**にし、表示側が旗の絵を描く。
- **地図の印**: ライブカメラの記号層は `text-field:'📷'` だった（地図の字形サーバに絵文字は無いので、描かれて
  いなかったと推定——未測定）。`iconImageData('camera')` を `addImage` して `icon-image` で描く。凡例の色付き
  丸は絵文字の近似色ではなく**各フィードがピンに塗っている実際の色**で描く。
- **静的ページ**: 言語ピッカーの地球と「限界」の印を icons.js で描く。逐語コピーのページなので
  `vite.config.js` の STATIC_ASSETS に `js/icons.js` を足した（無いと import が 404 でページの機械ごと止まる）。
- admin.html も同じ（インラインの本文が変わったので CSP のハッシュは `scripts/csp.mjs --write` で書き直した）。
- Atlas のカタログ文（モデルに渡す文）の ⚠ は外した。強調は大文字の文そのものが担っている。

## 3. 例外（宣言・理由つき）

- **アバター**（`js/auth-ui.js` の選択肢と `js/app-body.js` の既定値）: 利用者が選んだ**文字**を自分の印として
  保存・同期している値で、こちらが描くアイコンではない。値の形式を変えると既存の利用者のアバターが変わる。

## 4. 翻訳の行が「減った」理由（門の床を下げた）

- 絵文字を外したことで、`"🕸 Industry web"` と既にあった `"Industry web"` のように**同じ英語キーに合流した**
  行が fr/ko/zh/zh-hans で 9、de/es の位置引数で 1。消した訳は無い。`tests/i18n-coverage-floor.json` を
  `--update-floor` で更新した。
- 合流で**意味が衝突した** 3 キーは `i18n-key-collision-audit` が捕まえた: 「海流／海流（暖流・寒流）」
  「現在の地図の中心／現在の地図表示」は 1 行で両方に正しい（BENIGN に理由つきで追加）。
  「出来事／件数」（ダッシュボードの切替と火山の件数）は 1 行では務まらないので、ダッシュボード側の英語を
  **World events** にした（fr/ko/zh の訳はそのまま）。
- 訳の置き場（`scripts/i18n/*.json`・`scripts/zh/*.json`）も同じ変換をした（しないと「もう届かない行」になる）。

## 5. 検査

- 門 `icon-glyphs`（`scripts/icon-glyphs.mjs`・check:static）: 配信物（runtime-scripts と同じ発見＋css/）の
  文字列（acorn の cooked 値）・ページの文字（数値参照を展開）・インライン script・style・CSS の content。
  正規表現とコメントは読まない。宣言は「まだ当たっているか」を両方向に確かめる。
- `tests/icon-system-checks.test.mjs`: 全アイコンの形・DOM 版・`withIcons`・コードが書いた全アイコン名の
  解決（不明な名前は実行時に throw するので試験で出会う）・訳文のトークンが全言語で一致・門の読み方（エスケープ／
  テンプレート／コメント／正規表現／©／ページ／CSS）・古い宣言の拒否。
- 綴りを固定していた既存の試験 3 つを新しい形に合わせた（地震の実行ボタンの文言、地震の再計算の指示文、
  #R474 の「マークアップが飾るキー」の読み方＝`data-icon` 枠を飾りとして読む）。
