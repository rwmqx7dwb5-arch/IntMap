## R450 — **17の面が全部「want ∩ have」を数えていたので、`want` に無い行はどの分数にも入っていなかった**

**報告（#R432 の調査中に見つかった別件）**: `js/locales/ui.{fr,ko,zh,zh-hans}.js` の4本に
`"Volcanoes (GVP Holocene, all 1,215)"` の訳が1行ずつ在るが、**この英語を出す場所が js/ のどこにも
無い**。しかも 1,215 という件数は上流が 1,214 に改訂した時点で古く、#R432 でカタログは 1,218 になった。

### 到達不能であることの確認

`js/lang-registry.js` が `inline` 表を読むのは**2か所だけ**——`pick()` が `arguments[0]`（:257）、
`t()` が `arguments[1]`（:336）。`fn.arr(tuple)` は `pick()` の適用なので3つ目の規則ではない。
そして**添字は無加工**である（trim も正規化も接頭辞も単複変化も無い）。
`data-i18n*` 属性は `js/app-body.js:436-444` から **keyed `ui` 表**を引き、inline 表には触らない。
つまり **inline 行に届きうるのは「その英語原文そのもの」だけ**。
この綴りは `DEV-NOTES.md` の記録以外、出荷される木のどこにも無い。git で追うと
**#R251 が4言語ぶんの訳を足し、#R353 が英語側を消した**——2ラウンド孤児のままだった。

### 1件ではなかった

同じ問いを全表に掛けると **413 鍵・1,959 行**。内訳は inline 表 340（fr/ko 各 314・zh/zh-hans 各 339）と
keyed `ui` 表 73（9言語すべて）。退役した機能の残骸が大半で、`tabInfo`（#R139 で撤去された
Information タブ）・`optCyber` / `optBaroque`（退役テーマ）・`measureBtn` / `areaBtn`・
`lgd*Title`（凡例が `IntMapLang.t(…)` の直書きに移った）などが並ぶ。

### なぜ17面のどれも見ていなかったか

被覆はどれも **`want ∩ have`** である（`scripts/i18n-report.mjs:240`
`[...inline.keys()].filter(s=>i.has(s))`）。`have` にしか無い行は**分子からも分母からも**落ちるので、
「足りない」でも「英語のまま」でもなく、**存在しないのと同じ**になる。
`scripts/i18n-keyed-audit.mjs:138` は `ui:` 表について `stale` を計算しているが、
`scripts/i18n-audit.mjs` は `keyed.undeclared` しか読んでおらず、**`stale` は一度もゲートに載っていなかった**。
inline 表については、この向きの検査が**1本も無かった**。

### ⚠⚠⚠ この検査だけは `shapeOf()` の宇宙を使ってはならない

素直な実装は `dead = have − want` で、`want` は `scripts/i18n-helpers.mjs` が既に作っている。
**それは間違いで、しかも取り返しのつかない向きに間違う。**

`want` は「ヘルパ解決が**証明できた**call site」の集合であり、穴がある。実測:

```
js/map-readout.js:20   const L=(...a)=>{ if(!_L) _L=window.IntMapLang.pick(()=>HOST.lang); return _L(...a); };
```

`bindsHelper()` は CallExpression / MemberExpression しか見ないので、この**遅延ラッパ**は
ヘルパと認識されない。すると `strictNames()` は「`L` は何か別のものに束縛されている」と判断して
慣習の種を撒かず、**このファイルの10サイトは全計器の視野の外**に出る。
16の被覆面にとってこの穴は「翻訳を頼まれない文字列」＝**過小計上**で済むが、この面では
«Tropic of Cancer»・«Tropic of Capricorn»・«Wind from the {d} — the arrow points the way it is blowing»
などが「死んだ鍵」と報告され、**生きている訳が消える**。

**だから問いを弱くして健全にした**——「その鍵は**出荷される木のどこかに書かれているか**」。
どこにも書かれていない文字列は、誰がどう綴ったヘルパであろうと、どのパーサが読めなかろうと、
`pick()` の第0引数にはなりようがない。

### ⚠⚠ 綴りと値は別物である（23行が1エスケープ差で消えかけた）

最初の版は生テキストの部分文字列検索だけだった。鍵は literal が**表す**文字列で、ファイルが持つのは
**綴られ方**なので、エスケープを含む呼び出しは両者が一致しない。
**実測 23 行**——4つの inline 表それぞれで、生きた行が「死んだ」と報告された
（`npm run check:i18n` が「fr / ko / zh / zh-hans が不完全」と落ちて発覚）。
コーパスを**生テキスト ∪ 出荷ファイルの全 string literal の値**（52,593 語）にして解消。
全 literal を取るのに「どの呼び出しが翻訳呼び出しか」の理論は要らない——それがこの計器が
**仮定してはならない**当のものである。パースできないファイルは生テキストで寄与するので、
和集合はどちらの半分より狭くならない。

### ⚠⚠ 書かれずに到達しうる唯一の経路: 組み立て

`'transfer'+(tf===1?'':'s')` のように**定数と変数を連結して鍵を作る** call site が **107** ある。
そこへ届く文字列はソースに存在しないので、コーパスには絶対に入らない。
各サイトを**生成しうる文字列のパターン**（定数部を順に並べ、間を任意一致）に変換し、
どれかに当たる鍵は**消さずに保留**として報告する。
⚠ **定数部を持たない連結（`x + y`）はパターンにしない**——全鍵に当たって表ごと保留になり、
「緑だが何も主張していない」状態を作る（#R399）。
実測: 413 鍵のうち保留 **0**。107 のどれもこれらを生成できない。

### ⚠⚠ ratchet ではなく 0 で締めた

#R242 の規則「1ラウンドで届かないゲートは次のラウンドに消される」——`PAIR_CEILING` が天井である
理由——は、**4言語ぶんの本文を書く**仕事についての話である。ここで閉じる作業は
**誰も読まない行を消す**ことなので、測った 413 をそのラウンドで 0 にできた。
413 という天井は、根拠の無い数を1つ増やすだけだった。

### ⚠⚠ 消した行が戻れないことまでが同じゲートの仕事

`scripts/i18n-apply-inline.mjs` は `scripts/i18n/r*.json` を合流させ、
`scripts/i18n-append-inline.mjs` が **locale に無い鍵を全部**挿入する（フィルタは無い。
`rm ui.zh.js` → 再生成が 205 訳を破壊した実測があるので、**追加は無条件**が正しい設計）。
だから locale から消すだけでは、**手動の top-up 1回で全部戻る**。staging 側にも同じ問いを掛け、
**17ファイル 100 行**を落とした。掛けなければ「次に翻訳を足した人が、自分の diff に無い理由で
CI を赤くする」ことになる。

### ⚠⚠⚠ 同じ欠陥がこのラウンドの最中に main へ入ってきた

火山レイヤーの凡例は 「…, all 1,215」 → 「Volcanoes (GVP Holocene)」(#R353) →
**「Volcanoes (Smithsonian GVP)」(#R432)** と**2度**改名されており、**そのたびに前の綴りが
4言語ぶん残っていた**。2件目は rebase で取り込んだ側に入っており、**書いている最中のゲートが
捕まえた**。1件消すだけでは足りないことの、これ以上ない実測。

### ⚠⚠⚠ staging は2つあり、最初の版は片方しか知らなかった

`scripts/i18n/*.json` を塞いだだけでは足りなかった。**`scripts/zh/*.json`** は
`scripts/build-ui-zh.mjs` が `js/locales/ui.zh.js` を組み直す元で（`tests/r223 ⑩` 自身が
「the translation is REBUILDABLE: it lives in scripts/zh/*.json」と主張している）、
inline 側は英語原文で、**keyed 側は `"ui:<name>"`** と綴る。
接頭辞を外さない走査からは**構造的に見えない**。走査対象に足したところ **11ファイル 246 行**。
「戻る経路を塞いだ」は、塞いだつもりで**半分しか塞いでいなかった**。

### 検査

- ① 孤児の綴り2つが9ファイルと staging から消えていること。**生きているラベルは
  `js/beta-overlays.js` から読む**（3度目の改名でこの検査が空振りに変わらないように）
- ② 全表・全 staging で 0。コーパスが空でないこと（296ファイル・52,593語）も同時に主張
- ③ **計器が「dead」と言えること**——nonce を1つ渡す（発火しない検査は通った検査と区別できない）
- ④ ⚠ **遅延ラッパ越しにしか生きていない文字列**（«Tropic of Cancer»）を名指し、
  **`want` に無いこと**と**それでも `live` と判定されること**を両方主張する。
  誰かが `have − want` へ「簡略化」したら、訳が壊れる前にここが赤くなる
- ⑤ 40 パターンから実際に候補文字列を作って保留を確認。定数部の無いワイルドカードが
  パターン集合に入っていないことも
- ⑥ ゲートに配線されていること。**ゲートブロックだけ**を見て `>` 比較が無いこと＝ratchet 化の禁止
  （上の報告行は自分の一覧を `> 20` で切るので、ファイル全体に掛けると誤検出する）
