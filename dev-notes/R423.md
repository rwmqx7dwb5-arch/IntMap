## R423 — **ノルウェーの行が無かったのは、Natural Earth の1行が自分と矛盾していたから**

報告は 1 つ。「Norway has no row in the Countries list, at ANY year including the present.」
#R410 の本番検証中に、ビルド R415 と R416 で観測されたもの。

### 着手前に測ったこと

報告は**自分で切り分けを済ませていた**——歴史地図は 1916 でも他の年でも «Norway» のラベルを
描き、Countries 一覧には行が無い。そして**現在時刻でも**同じで、DOM に出た 240 行のうち "N" で
始まる 14 行にノルウェーは無く、Niue・Vatican City・Pitcairn Islands は在る。つまり時間旅行の
欠陥ではなく、#R410（`tagSame` の時代名解決）でもない。

出荷ローダを実際の Natural Earth 2 ファイルに対して走らせて再現した:

```
countryStats.NOR present?  true          ← 行は在る
  nameEn="Norway"  sov=false             ← 一覧の絞り込みで落ちる
rows renderStats would draw: 240
Norway among them?  false
rows starting with N: Namibia … Northern Mariana Islands   （14 行・Norway なし）
```

⇒ **行は最初から在った。** #R375 が確立した不変条件（`countryGeo` の全 id が `countryStats` に
行を持つ）は満たされたまま、**「行がある」と「一覧に出る」の差**で落ちていた。

### ① 根本原因 — 同じ 1 行の中で、Natural Earth が自分と矛盾している

```
TYPE        "Sovereign country"      ← その地物が何であるか
FCLASS_TLC  "Unrecognized"           ← ある視点がこの多角形をどう分類するか
ISO_A3      "-99"   ISO_A2 "-99"   ISO_N3 "-99"
WOE_NOTE    "Does not include Svalbard, Jan Mayen, or Bouvet Islands (28289410)."
```

#R23 の `_nonSov` は**後者だけ**を読んでいた:

```js
const _nonSov=(p.TYPE==='Indeterminate')||/indetermin|unrecogn/i.test(String(p.FCLASS_TLC||…));
```

`FCLASS_*` の family は**視点ごとの分類**であって国家の存否ではない。`WOE_NOTE` がその視点差の
理由を書いている——この多角形は Svalbard・Jan Mayen・Bouvet を含まず、ISO の NOR は含む。
`ISO_A3` 等が `-99` なのも同じ理由である。

⚠ **この family が主権の欄でないことは、ファイル自身が示している。** 実在する未承認国家 2 つ——
ソマリランドと北キプロス——は `FCLASS_ISO:"Unrecognized"` かつ `FCLASS_TLC:"Admin-0 country"` と
いう**逆の並び**を持ち、どちらも一覧に出ている。読んでいる `FCLASS_TLC` の側では、両国は
「承認されていない」とは書かれていない。

### ② 直したのは「ノルウェーを通す」ではなく、どちらの欄が上位かという規則

```js
const _neType=String(p.TYPE||'');
const _neCountry=/^(sovereign country|country)$/i.test(_neType);
const _nonSov=(_neType==='Indeterminate')||(!_neCountry&&/indetermin|unrecogn/i.test(String(p.FCLASS_TLC||…)));
```

**範囲を広げる修正は、何件動かすかを先に数えてから入れた**（出荷している 2 ファイルを実測）:

| | 110 m | 10 m |
|---|---|---|
| FCLASS 分岐が立つ地物 | 4 | 13 |
| うち `TYPE:"Indeterminate"` でないもの | **1（Norway）** | **1（Norway）** |
| `TYPE:"Country"` で立つもの | 0 | 0 |
| TYPE を上位にして**判定が動く**件数 | **1** | **1** |

⇒ Scarborough Shoal・Serranilla・Bajo Nuevo・Bir Tawil・Wake・Siachen・南パタゴニア氷原・
キプロス緩衝地帯は**全部そのまま**除外される。#R23 は弱まっていない。

修正後: 一覧 **240 → 241 行**、`sov:false` は 12 → 11 件（動いたのはノルウェーだけ）。
行の中身も実データで揃っている（Oslo / NOK / Norwegian / GDP $486B / HDI 0.966 / 寿命 83.2 /
🇳🇴 / ノルウェー）。

### ③ 1 枚のフラグが 6 か所を同時に消していた

`sov` は Countries 一覧の私有フィールドではない。書くのは `_mkStat()` の **1 か所**、読むのは
**5 ファイル 6 か所**:

| 読み手 | 消えていたもの |
|---|---|
| `js/countries-ui.js` `renderStats` | Countries 一覧の行（**報告された症状**） |
| `js/stats-compare.js` `cList` | 5 か国比較のピッカー |
| `js/atlas-console.js`（2 か所） | 国名のゆるい一致・**「top N by X」の全順位付け** |
| `js/atlas-examples.js` `exFacts` | Atlas の起点チップ |
| `js/time-borders.js` `tagSame` | 現代名の対照表 |

⚠ **報告されていなかった症状がもう 1 つ画面に出ていた。** `tagSame` の `cur` は `sov!==false` で
作るので、ノルウェーは `_same=0` になる——つまり **`imtb-lbl`（消滅した国の書式）**で描かれ、
`_modName` を持たないので**現地語ラベルも失う**。日本語利用者には «ノルウェー» ではなく
«Norway» が出ていた。1 か所で直したので 6 か所とも直る。

### ④ 検査 — 国名を書かず、`TYPE` から導き、絞り込み式は出荷ファイルから抜く

**`tests/r423-checks.test.mjs`（6 本・毎 push のゲート）**。守らせているのは「ノルウェーが出る」
ではなく、#R375 が一歩手前で止まった不変条件である:

> ⚠ **地図が「国」として描くものは、Countries 一覧に行がある。**

- 一覧に出るべき集合は**地物自身の `TYPE`** から導く（国名の表を書かない）。
- 「出ている」の判定は `renderStats` の絞り込み式を **`js/countries-ui.js` から正規表現で抜き出して**
  使う。写すと、実物を変えたあとも検査だけが古い主張を続ける。⓪ がその抽出自体を見張る。
- ① は **TYPE × FCLASS_TLC の全 35 組合せ**を出荷ローダに食わせる。今日のリリースにたまたま
  存在する形ではなく、NE が渡しうる形の空間を掃く。壊れたビルドでの出力は
  `X02/X03/X07/X08`（`Sovereign country`・`Country` × `Admin-0 indeterminant`・`Unrecognized`）。
- ② は逆向き（`Indeterminate` は 1 件も一覧に漏れない・全件が行は持つ＝#R375）。
- ④ は 6 つの読み手を数える（読み手が黙って増えたらこの数が動く）。

**`tests/r410.spec.js` の `R423` ステップ（画面側）**。`countryGeo` が国として持つコードを、
**実際に DOM に描かれた `.stat-row`** と突き合わせる。壊れたビルドでの出力は
`["NOR Norway (TYPE=Sovereign country)"]`。

⚠ **変異で確かめた。** `js/countries-ui.js` を revert して再実行 → 検査 ①③⑤ と spec のステップが
赤。②④⓪ は両方で緑（過剰修正と抽出の見張りなので、それが正しい）。

### ⑤ 途中で捨てたもの、と測って分かったこと

⚠⚠ **視野を含まない spec は、緑のまま何も測らない。** 1916 の掃引を最初 #R410 ① の視野
（`[8,48]` z4.2・中欧）で書いた。**壊れたビルドで通った**——ノルウェーのラベルが画面外だったから
である。`queryRenderedFeatures` は**置かれたもの**しか返さないので、対象を含まない視野は
「何も測っていない緑」になる。北海・バルト海（`[12,55]` z3.2）に移すと赤になった。

⚠⚠ **era ラベルの全掃引は不変条件ではない。** 「描かれたラベルは全部一覧にある」と書きかけて
測ったら、«India (UK)»・«Tibet»・«Iceland (Denmark)»・«Spanish Morocco» が出た——**正しく描かれ、
正しく現在の国の一覧に無い**。正しい述語は「**現在の国名で描かれたもの**は一覧にある」で、
その集合も `countryGeo` から導ける（実測: 描画 18 件中 9 件が現在の国名）。

⚠⚠ **それでも 1916 版は落とした。天井に余裕が 0 だったから。** `scripts/test-budget.mjs` は
**core 28/28 秒・total 4,598/4,598 秒**——ちょうど 0。実測:

| 版 | `tests/r410.spec.js`（1 worker） |
|---|---|
| 変更前（R410 ① だけ） | 9.65 s / 7.09 s（記録値 12 s） |
| 別ファイルに 2 テスト | **25 s**（差のほとんどは 2 つ目の worker 起動） |
| R410 ① に 1916＋現在の 2 ステップ | **21.3 s**（+11.7 s。カメラ移動と再描画待ちが高い） |
| **R410 ① に現在時刻のステップだけ** | **9.05 s** ← 採用 |

⇒ **既に払ってある舞台に相乗りする**（#R207 と同じ形）。現在時刻の掃引は `setNow()` の直後に
`page.evaluate` を 1 回足すだけなので、記録値 12 秒を超えない。1916 の証拠は
`tests/r423-checks.test.mjs` が年に依存しない形（`sov` は時計で変わらない）で持っている。

⚠ **`Architecture.md` にラウンド番号を書いて門に捕まった**（`doc-facts.mjs` の `arch-rounds`）。
§9 のとおりで、正しい拒否である。

### 範囲外として切り出したもの

`countryStats[code].bbox` は NE 地物**全体**の外接矩形なので、海外領土を 1 地物にまとめている国は
惑星規模の枠になる。実測（10 m・緯度差 40° 超）: ノルウェー 135.2°（Bouvet 島が −54.5°S）・
フランス 72.5°・アメリカ 52.5°（経度差 **358.9°**）・オーストラリア 45.5°・ニュージーランド 44.1°・
オランダ 41.5°・カナダ 41.4°・ロシア 40.7°。**このラウンドの変更が作ったものではなく**、
他の 7 か国では以前から到達可能だった（`resolveCountrySync` の完全一致は `sov` を見ない）。
別タスクとして切り出した。
