〈依頼〉 新しい流通経路。SNS で流通する単位は静止画なのに、いまの地図を 1 枚の画像として保存・共有する手段が
画面録画しかなかった。また共有リンクは状態を運ぶが「意味」（作者の一言）を運ばない。⑴ 地図の絵葉書（共有パネルの
第 3 のタブ「画像」・3 つの形・`navigator.share({files,url})`／使えなければ保存＋リンクのコピー）⑵ 共有リンクに
題と一言（URL hash・開いた人には地図の上の帯と `document.title`・埋め込みにも）⑶ Atlas から両方。

## 0. 測った（着手前）

- 画像として持ち出す経路は `js/map-recorder.js` の `compareImage`（比較ウィンドウが開いているときだけ）と
  タイムラプスの動画だけ。どちらも**凡例を持たない**——色分けの地図が鍵なしで出ていく。
- 共有リンクの欄は `js/map-state.js` の `SCHEMA` が 1 回だけ宣言し、出荷済みのリンクは
  `tests/map-state-store-checks.test.mjs` ① がバイト単位で往復を確かめている。新しい欄は**最後に**足し、無いときは
  何も書かないので、既存のリンクは 1 バイトも変わらない（同じ検査が緑のまま）。

## 1. 共有リンクの題と一言

- `SCHEMA` に `title` / `note`（`params` は同名、`restore:'always'`・`at:[300]`・持ち主 `js/map-ui.js`）。
  `always` にしたのは、文字列は「アプリを落とした層」になりえないから（落ちた後の再読み込みが視野だけに戻る理由が無い）。
  `at:[300]` は基図の段と同じ最初の段取り——依存が無く、同期の段は視野だけに保つ（③ の検査がそれを述べている）。
- `captionText` が書き手と読み手の両方で同じ規則を当てる: 制御文字と双方向上書き文字（U+202A–202E・2066–2069・
  2028/2029 ほか）を空白に、空白の連なりを 1 つに、**文字単位**で `TITLE_MAX`=100 / `NOTE_MAX`=280 に切る
  （絵文字を割らない）。上限は推定（題は 1200×630 の最小字で 2 行、一言は 1 投稿の長さ）で、根拠と失効条件は定数の
  横に書いた。手で作ったリンクもそれ以上を持ち込めない。壊れた `%` は「題なし」で、例外にならない。
- 帯 `#im-caption`（`js/map-ui.js` `share`）: 題・一言（3 行で畳み、押すと全文）・閉じる。**テキストとしてしか入らない**
  （`textContent`。パネルの入力欄は `.value` で埋め、パネルの markup に連結しない）。`document.title` は
  「題 — アプリの題」。`js/lang-registry.js` の `syncDocument` が言語の切り替えでアプリの題を書き直すので、`<title>` を
  MutationObserver で見張り、書き直された題を新しい土台にして前に付け直す（題が無い間は見張らない）。
- **置き場所は測って決める。** 最初の版は検索欄の下の中央に固定で、ブラウザ検査で**ケッペンの凡例（左上から積まれる）の
  下に潜った**（凡例の z が上）。いまは、同じ行にある箱（地図の操作群・凡例・埋め込みの帯・検索欄）を避けた最も広い
  区間の中央に置き、狭めて背が伸びたら 2 回目を測る。凡例は層が点いた後で現れるので、層の変化の時刻だけでは
  間に合わなかった（実測: 凡例が出る前に置かれて、その後動かない）——避ける箱を ResizeObserver で見張る
  （凡例の大きさが 0 から変わる＝現れた）。携帯は出典の小札の上（小札は折り返すので高さを測る）、シート全開で隠れる。
- 埋め込み: `EMBED_CSS` の残す一覧に `#im-caption`。閉じるボタンは出さない（読み取り専用）。

## 2. 地図の絵葉書

- `postcard({ size, title, note, link })`（`js/map-recorder.js`）。地図は描画の tick の中で読む（タイムラプスのコマと同じ
  `captureCanvas`。隠れたタブでは `not-drawn` で、黒い絵を作らない）。瞬間は時計の精度で: 年として合わせた時計
  （`js/chronos.js` `setYear` の 6 月 15 日正午——`js/compare.js` の `clockLabel` と同じ読み）は年、それ以外は日付。
  ライブは「今日」ではなく**その日の日付**（画像は後で読まれる）。
- 形は 3 つ（`POSTCARD_SIZES`）: リンクカード 1200×630（Open Graph／X の大きいカード）・正方形 1080×1080・
  縦長 1080×1350（Instagram の 4:5）。各社の公表サイズで、こちらの閾値ではない。
- 配置は純関数のまま足した: `layoutFrame` の `caption`（瞬間・題 ≤3 行・一言 ≤4 行のカード。最小字でも入らない
  ときだけ最終行を「…」で切る——全文はリンクにある）と `legends`（`layoutLegends`）。凡例は右端に 1 つの縮尺で並べ、
  上限 1.5・床 0.9（frame px / CSS px、1080 基準）。**床で入らない凡例は落として数え**、パネルが件数を述べる
  （判読できない切手に縮めない）。先頭の 1 枚は必ず入れる。
- リンクの印字: 共有リンクが 1 行に**丸ごと**入るならそれ、入らなければサイトのアドレス。**切ったリンクは印字しない**
  （別の地図を開く）。題と一言を持つリンクはほぼ入らないので、実際にはアドレスになる——リンクそのものは共有シートの
  `url` とコピーで運ぶ。
- **凡例は DOM をそのまま読む**（`rasterLegend`）。凡例は ~30 種類あり、種類ごとの写しを書けば次の種類が漏れる。
  各箱の背景色・`linear-gradient`（`parseGradient`。角度・`to <side>`・位置の省略は CSS どおり均等割り・2 位置の
  硬い帯）・4 辺の枠線、文字は `Range#getClientRects` でブラウザが置いた行ごとに、描ける画像（同一オリジン・data・
  blob の `<img>`、汚れていない `<canvas>`、`currentColor` を解決したインライン SVG）、切り抜きは overflow の祖先の
  交差。**汚れた（cross-origin の）画像は描かない**——描けば PNG を書き出せなくなる。
  ⚠ 実測で 2 回直した: ⑴ 最初は「ボタンは取っ手」として除いたら、**ケッペンの凡例が題と期間だけで 30 の気候区分が
  1 つも無かった**（行が `role="button"`——押すとその気候を強調）。⑵ 次に「掴む／動かすカーソルは取っ手」を足したら
  **凡例の見出しが消えた**（見出しがドラッグの取っ手を兼ねる）。規則はいま「文字か見本を持つものは描く。入力欄・
  スライダーと、何も述べない取っ手（×・–・▶・⋮⋮）だけ除く」。
- 携帯の凡例トレイは閉じていても凡例を `visibility:hidden` で**組んだまま**置いている（`css/intmap.css`）ので、
  地図上の凡例として絵に入る。
- 画像タブ（`createPostcardTab`）: 形の 3 択・プレビュー（**保存・共有されるファイルそのもの**）・「共有…」
  （`navigator.canShare({files})` が真の端末だけ。`title`・`text`（一言）・`url` を一緒に渡す）または
  「画像を保存してリンクをコピー」（1 回の押下で両方）・「画像を保存」・焼き込んだ出典の一覧。形・題・地図が
  変わると作り直し、古い呼び出しの結果は捨てる。オブジェクト URL は最後の 1 枚だけ持つ。タイムラプスの録画中は
  作らない（`busy`——地図が下で動いている）。

## 3. Atlas

- `panel.postcard`（綴り `postcard`、別名 `mapPostcard,shareImage,mapImage`、書く先は `panel.share`＝共有と直列）。
  画像タブを開いて作り、ファイル名・大きさ・題と一言・凡例の件数（入らなかった件数）・焼き込んだ出典を結果に載せる。
  共有シートは読者の押下でしか開けないので、Atlas は作り、送るのは読者（結果がそう述べる）。失敗は理由つきで `ok:false`。
- `panel.share` に `title` / `note`: パネルを開く前に題を付けるので、Atlas が返すリンク・埋め込みコードが題を運ぶ。
- ⚠ **結果が言い返す題と一言は Atlas 自身が渡したものだけ。** 題は読者が開いた**他人のリンク**からも来る。その文を
  結果に載せると、第三者の文が「IntMap が観測したこと」としてモデルに届く（どちらの行も列 11 `ingests:'external'` を
  宣言していない）。他人の題は「リンクの題と一言がある」とだけ述べる（`captioned:true`）。検査 ④ が両方を評価する。
- catalogue の文は形の名前と大きさを述べ、`tests/map-postcard-checks.test.mjs` ④ が `POSTCARD_SIZES` と突き合わせる。

## 6. 統合のときに直したもの

- **ケッペンの層の出典が、どこにも出ていなかった（CC BY 4.0 の帰属表示の欠落）。** 原因は 2 つ重なっていた。
  ① `src-climate` のソースが `attribution` を宣言していなかった。② 宣言しても届かない——maplibre-gl 6.11.2 の
  `ImageSource` は `options.attribution` を読まず、`serialize()` は type/url/coordinates しか書かず、style spec の
  image/video には `attribution` の鍵が無いので検証が**ソースごと**拒む。座標で置くソース（image/video/canvas）は
  すべて同じで、夜の灯り（#R196 の canvas）が宣言していた NASA の出典も同じく消えていた。
  ⇒ Köppen のソースに出典（Beck et al. 2023, Scientific Data 10:724, CC BY 4.0）を宣言し、`js/geo-engine.js` の
  `_addSourceCarryingCredit` が「座標で置かれ、出典を宣言したソース」という**事実**に対して、レンダラが受け付ける
  spec を渡したうえで出典をソースとその直列化に持たせる（ID の一覧は持たない）。帯（絵葉書・動画）と副ビューの出典は
  どちらもソースに訊くので、両方に出る。
- **凡例の絵から操作の案内を外した。** 文言ではなく DOM が述べている性質で判別する: ① 札の中の操作部品の
  `aria-describedby` が指す要素＝その部品の使い方の説明（Köppen の行が `#kl-hint` を指すようにした。支援技術にも
  同じ説明が届く）② 入力欄を持ち、その欄の名前（`<label>`・`aria-labelledby`）以外に文字も色見本も無い箱＝その欄の行
  （「不透明度 100%」。「100%」は文字を持たない）。
- `tests/map-postcard.spec.js` ①に足した: 帯に Beck et al. 2023 / CC BY 4.0 が在る／復号した絵の、案内文と不透明度の行が
  ページで占めていた場所が無地で、題の場所にはインクが在る。3 つとも直す前のコードへ戻すと赤になることを確かめた。
- 実測: `tests/map-postcard.spec.js` は 1 worker・既存サーバでテスト本体 12.9 / 12.3 / 9.8 s（上限で 13 を記入）。
  これで core は 6 本に戻る。全体は天井 87.5 分に対し 87.7 分——**天井は上げていない**（余地は PR #911 が作る）。
- `check:perf` で上げた天井と、その理由（越えた行だけ `--update`）:
  eager raw 4628.5→4655.7 kB・gzip 1523.9→1532.9・brotli 1149.9→1157.0——共有リンクの題と一言の codec（`js/map-state.js`）、
  地図の上の題の帯（`js/map-ui.js`）、Atlas の `postcard`/`share`（`js/atlas-cap-panel.js`）、eager な en の文言。
  async gzip 3774.0→3794.1・`map-recorder` 18.2→35.8 kB——絵葉書の合成（凡例を絵にする読み手・レイアウト・題のカード）は
  画像タブを初めて開いたときにだけ取りに行くチャンクに置いた。`ui.jp` 20.7→23.1 kB——同じ文言の日本語。
