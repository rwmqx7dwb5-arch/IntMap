## 0. 測った（着手前）

| 何 | 結果 |

## 1. 作ったもの

- **`simulate(…, { release })`**（`js/radiation-model.js`）: 区間の表 `[{t0, t1, bq, zBot, zTop}]` を受け取る。粒子は同じ放射能を運び、
  放出時刻と高さは累積放出の逆関数を (i+½)/N で引く（決定的。乱数は輸送だけに使うので、`release` が無い経路は種ごとに従来と同じ沈着）。
  窓の外は放出せず `releaseOutsideBq` で述べる。`RAD.releasePlan` を公開。
- **地域の入れ子 `RAD.midPlan`**（±2.5° に 13×13）: 場に `mid` があれば内側→地域→外側の順に混ぜ、無ければ従来と同じ計算。
- **`depositableFraction`**: 1 回の実行で沈着可能割合を述べる口（既定は変えていない。§3）。
- **`data/fukushima-release.json`**＋`scripts/build-fukushima-release.mjs`: zip の md5 を固定（上流は公表していないので 2026-10-03 の実測値）、
  区間が時間を隙間なく覆うこと・和が CSV の総量と 1 % 以内で一致することを確かめてから書く。出自・権利は値で（`GOVERNANCE`・DATA_SOURCES の行・出典ページ en/jp）。
- **外れの内訳の段**（`scripts/radiation-hindcast-config.mjs` の `variants`）: `jaea` → `jaea-regional` → `jaea-regional-particulate`。
  束 `data/radiation-hindcast.json` に `variants` と `release`（毎時の放出率・出典・「独立の検証ではない」の注記）を足した。preset の段は 1 バイトの差も無く同じ。
- **風の固定**: `scripts/radiation-hindcast-fetch-wind.mjs` は**足りない入れ子だけ**取る（既にある入れ子を取り直すと、記録が取り直した日の関数になる）。
  地域の入れ子 169 点を足した（657 kB → 1.18 MB、`tests/fixtures/`。読者には配らない）。
- **パネル**（`js/sims.js`）:「モデルに与えたもの」——段のボタン（束の `variants` から。段の一覧の写しは無い）、JAEA の放出率の時間変化（棒・対数）と
  プリセットの一定の放出率（破線）、段ごとの r・中央のセル・2 倍以内の表、段が preset でないときは「独立の検証ではない」。DOM で組んだ（出力の taint 台帳を増やさない）。
- **Atlas**: `radiation` に `rung`。答えは表示中の段に加えて**全段の指標**を持つので、「なぜ外れるのか」「放出のせいはどれだけか」に段の比較で答えられる。
  未知の段は**段の一覧つきで**拒む（次の呼び出しが正しくなるように）。
- 検査: `tests/science-next-checks.test.mjs`（8 件・約 40 秒——3 段を worker で並列に回し直す）。各段の指標が記録より悪化したら赤、
  地図が今のモデルと違えば赤。束の `jaea-regional-particulate` の FAC2 を 0.5 に書き換えると赤になることを確かめた。
  `tests/science-next.spec.js`（パネルの段と表と時系列、扉の `rung`）。既存の `tests/radiation-hindcast-checks.test.mjs` は import の形の正規表現 2 つを新しい形に合わせた（主張は同じ）。

## 3. 踏んだもの・決めなかったこと

- **既定値（0.55）は直していない。** 物理としては根拠が無い（放出量は核種の放射能で、希ガスは入っていない）が、直すと §10 の門の
  1 MBq/m² の FMS が 0.191→0.179 に下がる——プリセットの熱い場所がずれているので、量を正しくすると外れた場所の面積が広がる。
  **門を弱めて記録を取り直すかどうかは判断が要る**ので、§10b に数を書き、呼び出し元に上げた。降水の時刻合わせ（1 時間のずれ）も同じ理由で入れていない。
- **ライブのシミュレータは地域の入れ子を取得しない。** 1 回の実行で Open-Meteo の地点が 218→387 に増える（利用者の IP ごとの無料枠を消費する）。
  入れるかどうかは提案に留めた。
- ツール経由の文字列で `\'` が `'` になる事故が 3 回（sims.js・atlas-cap-sim.js・pages.en.js）。`node --check` が全部拾った。
- `check:datagov` の outbound-disclosed: SVG の名前空間 URL を変数に入れると「ブラウザが要求するホスト」と数えられる。他のファイルと同じく `createElementNS` の引数に直に書いた。
- `python3` を呼んだら Windows のストアの殻が入力待ちで止まった（このマシンに Python は無い）。

## 4. 残り
