## R263 — **地震動の「地域定数」を場所から決める：CRUST1.0・Slab2・PB2002 と、周波数の関数になった地盤増幅**

「地震シミュレータの震度計算精度をさらに上げてください。地域限定の補正や日本専用データには依存せず、
世界中で同一の計算体系を使うこと。」——5項目の指示。**特定の地震に合わせて係数を調整することは禁止**、
改善は**任意の場所・任意の地震にそのまま適用できる物理・地球モデルの改善**として実装すること。

### ⓪ この5つは同じ1つの欠陥の別々の面だった

`js/seismic.js` の物理は #R176 から #R247 まで丁寧に積み上がっていて、**間違っている式は1つも無かった**。
間違っていたのは**適用範囲**である。Q₀=180·f^0.45 は南カリフォルニアの地殻、Δσ=3 MPa は活断層帯、
κ=0.035 s は西部アメリカの浅部、幾何減衰の折れ点 70/130 km は**地殻厚 35 km の測定値**——この4つが
カナダ楯状地にもチベットにも同じ値で当たっていた。つまり**「地域限定の補正に依存していた」のは
今の実装のほう**で、指示はそれを外せと言っている。

### ① 場所を訊く：同梱した全球データ3つ（`js/earth-structure.js`）

| データ | 何を答えるか | 格子 | 同梱サイズ |
|---|---|---|---|
| CRUST1.0（Laske et al. 2013） | 地殻8層＋マントルの Vs・密度・層境界 | 1° | 686 kB |
| Slab2（Hayes et al. 2018） | 沈み込み帯27箇所のスラブ上面の深さ・走向・傾斜 | 0.05° | 950 kB |
| PB2002（Bird 2003） | 最近接プレート境界までの距離と種別・orogen | 0.25° | 306 kB |

判定則は **Atkinson & Boore (2003) 自身のもの**——「正断層は常にスラブ内／逆断層は 50 km 未満かつ
低角ならプレート境界型／50 km 超か高角ならスラブ内」——の、**彼らが深さ 50 km で代用した部分を
Slab2 の実面に置き換えた**もの。2003年に全球スラブ形状は存在しなかった。

⚠ **`slab2.bin.gz` は 3.12 MB から 950 kB になった**。絶対値の 16 bit 深さは下位バイトがほぼ乱数で、
gzip は 3.86 MB を 3.12 MB にしかできない（＝ほぼ何も見つけていない）。スラブ面は滑らかなので
**行方向の差分**にすると 3分の1になる。⚠ **0.1° への間引きは検査で却下された**——全ノードを
読み直して粗い格子の双線形補間と比べる検査を先に書いてあり、**Puysegur で 6.17 km** を失うと出た。
6 km は interface と intraslab を分ける窓そのものなので、解像度は公表値のままにして、
**行ごとに1本の run** で疎に持つことでバイトを取り戻した（外接矩形の 16% しか埋まっていない）。
⚠ **存在マスクは独立した面**にした。最初は「dip が 0 なら不在」で済ませ、その仮定を検査する
assert を書いたら**落ちた**——深さが無く dip だけある節点が **877** ある。dip 面をマスクに使えば
その 877 点に「スラブがある」と言わせていた。

### ② 何が変わるか：公表パラメータ一式を、丸ごと

| | active-crustal / interface | stable-continental |
|---|---|---|
| Δσ | 3 MPa（従来どおり） | **14 MPa**（140 bar） |
| κ | 0.035 s | **0.005 s** |
| Q | 180·f^0.45 | **893·f^0.32（下限 1000）** |
| 幾何減衰 | R⁻¹ / R⁰ / R⁻⁰·⁵ | **R⁻¹·³ / R⁺⁰·² / R⁻⁰·⁵** |
| 折れ点 | 70 / 130 km（地殻 35 km） | 70 / 140 km（地殻 40 km） |

安定大陸の列は **Atkinson & Boore (2006) Table 1 をそのまま**（論文 PDF から読み出して確認した）。
⚠ **折れ点は「その土地の Moho」に比例させる**。両方の公表値は post-critical な Moho 反射が現れて
表面波に譲る距離で、**地殻厚の測定値**である。CRUST1.0 が実際の Moho を持っているので H/H_ref を
掛ける——各公表値はその基準厚で**厳密に**再現され、チベットの 70 km 地殻は 140 km で折れる。
⚠ **Moho より深い震源には地殻導波路が無い**ので平坦枝そのものが無い（幾何であって係数ではない）。
⚠ **スラブ内固有の応力降下量は与えていない**。観測上は界面型より高いが、**全球で1つに定まる公表値が
無い**ので書かない——特定の地震を合わせるために数字を作るのは、この規程が最も強く禁じていること。

### ③ Vs30 は「深さ30 mについての1つの数」だった（`js/seismic-site.js`）

`√(ρ_src·β_src/(ρ·Vs30))` は **1/4波長増幅を深さ30 mで1点評価した値**で、その1点は
軟弱地盤で 1.5 Hz・岩盤で 6.3 Hz。**PGA を運ぶ 10 Hz にも高層を揺らす 0.3 Hz にも同じ値**が当たっていた。
低周波では**両方向に間違う**——薄い軟弱層は過大評価、深い堆積盆地は過小評価。
**スカラの場址項では盆地効果は原理的に出せない**（ラスタをいくら細かくしても）。

→ 上位 30 m を Vs30、その下を CRUST1.0 の実層構造（両者の間は log-log の**べき乗**補間＝新しい定数を
1つも導入しない）とした速度柱から **A(f)** を積分する。
⚠ **高周波の極限は従来値とビット一致する**（30 m 層が定数 Vs30 なので、1/4波長が 30 m 以下の全 f で
β̄=Vs30）。`tests/r263-checks ①` がそれを assert する。**変わるのはその下の周波数だけ**。
⚠ **最初の版は盆地が岩盤より弱く増幅した**——CRUST1.0 は8層に対し境界を9個ぶら下げるので、
区間 [bnds[i], bnds[i+1]] に **vs[i]** を組ませねばならないところを vs[i+1] と組ませ、
柱が丸ごと1層ずれて**堆積層に結晶質地殻の速度**を配っていた。実測で 0.2 Hz が逆転して捕まった。
⚠ 場の 200 万セルには**補正表**として入れる：`K = A(f)版 / A(∞)版` は 1 の近くの滑らかな比なので、
セルごとの**スカラは 0.05° の分解能のまま**で、K だけを Vs30×堆積層厚×距離の小さな表から引く
（実測 756 回の追加評価＝場が既に使う 3,360 回に対して誤差）。

### ④ 有限断層を subfault に（`js/seismic-subfault.js`）

k⁻² すべり（Herrero & Bernard 1994）・**総モーメント厳密保存**（実測 1e−16）・
破壊時刻 |r−r_hypo|/Vr・ライズタイム τ=2.03e−9·M₀^(1/3)（Somerville et al. 1999）。
⚠ **粗さの唯一の自由度も公表統計から導いた**：Somerville et al. (1999) の「平均すべりの1.5倍以上の
面積が 22%」から σ=0.648（実測アンサンブル 22.6%）。位相は断層形状を種にした決定的生成なので
**同じ断層なら常に同じすべり**（揺らぐと地図がちらつき、検査も嘘になる）。
⚠ **震源核は面の上にある**——along-strike の投影をクランプしていなかったので、面の外に落ちた
震源核は**断層全体を同時に遅く破壊させ**、この機構が生む directivity を黙って消していた
（`tests/r263-checks ③` が捕まえた）。

### ⑤ 採点する（`scripts/build-seismic-observations.mjs` → `scripts/seismic-validate.mjs`）

観測は**記憶から打ち込まない**。USGS ShakeMap の **station list** を取得して、
**器械記録（seismic）だけ**を残す＝15地震・**1,283 地点**の実測 PGA/PGV。
採点は**出荷されるモデルそのもの**を実ブラウザで走らせ、パネルの表が呼ぶのと同じ `at()` 経路を通す。

| | baseline（#R263 無効） | #R263 | |
|---|---|---|---|
| ln PGA bias / MAE | −0.14 / 0.85 | −0.21 / 0.86 | ほぼ不動（**設計どおり**） |
| ln PGV bias / MAE | +0.42 / 0.75 | **+0.13 / 0.70** | 改善 |
| MMI bias / MAE | +0.69 / 0.93 | **+0.37 / 0.79** | 改善 |
| MMI ±0.5 以内 | 29.5 % | **37.1 %** | +7.6 pt |
| MMI ±1.0 以内 | 59.9 % | **67.9 %** | +8.0 pt |

PGA が動かず PGV と震度だけ良くなるのは**物理の予言どおり**——A(f) は 30 m の角周波数より上で
飽和するので、PGA を運ぶ帯域では K=1 が構成上保証されている。
⚠ **`--baseline` は同じページで `window.IntMapEarth` を消すだけ**なので、2回の走行の差は
この改修そのものしかない。**A/B できないモデル変更は主張であって測定ではない**。
⚠ **スマトラ2004・チリ1960・アラスカ1964 は採点できない**——ShakeMap の該当エントリは
21/207/233 件すべて macroseismic で、器械記録が1点も無い。空の行として残すと
「15地震を検証した」と言いながら3件が何も寄与しない状態になるので、**`excluded` に理由付きで**落とした。
⚠ **この採点に閾値は無い**。スコアに門を付けると「閾値を通るまで係数を触る」への招待状になり、
それはこのラウンドが禁じられていることそのもの。

### ⑥ 検査が3つ、自分の仕事を捕まえた

⑴ Slab2 の 0.1° 間引き（6.17 km の欠損）。⑵ dip 面を存在マスクにする仮定（877 節点）。
⑶ 断層外の震源核（directivity が消える）。いずれも**書いた assert が落ちて**分かった。
⚠ そして**シェルの行数上限（`tests/r168 #8`・残り2行）が設計を1段良くした**——3つの新モジュールを
`src/main.js` から eager に import する最初の版が予算に当たり、**唯一の消費者である
`js/seismic.js` 自身が import する**形に変えた結果、boot バンドルではなく**遅延ロードされる
seismic のチャンクに載る**ようになった。#R253 の「予算に当たったら設計を見直せ」。
⚠ **前ラウンドのテスト4本が正当な変更を退行に見せた**（#R189 の「1セル1回の掛け算」・#R192 の
`disp` の字面・#R223 の「0.25°」・#R250 の far 場の1行）。**消さずに、守っていた性質へ書き換えて
理由を書いた**——4ラウンド連続で同じ形が出ている。

### 残っている限界（隠さずに書く）

- **CRUST1.0 は 1°＝111 km** なので、関東平野や LA 盆地を個別の盆地として解像しない。浅い側は
  0.05°（DEM があれば ~1 km）なので、**深さで分解能が違う**構造になっている。
- **`ACTIVE_KM=150 km` だけは出典の無い閾値**。最初の 100 km は神戸1995とクライストチャーチ2011を
  「安定大陸」にした（Bird 自身の orogen 内で境界線までの距離を測ると**中央値 352 km**）。
  GEM Global Active Faults（CC-BY-SA）を同梱すれば実測の活断層距離に置き換えられるが、
  **public リポジトリに share-alike を持ち込む判断はユーザーのもの**なので入れていない。
- **subfault は運動学まで**。スペクトルの非干渉和（EXSIM の Σ|Aᵢ(f)|²）はまだ入っていない——
  低周波の可干渉性と dynamic corner frequency を正しく扱わない実装は、
  総モーメントの水準を壊すので入れないほうがよい。
- **スラブ内固有の応力降下量**（上記②）。
