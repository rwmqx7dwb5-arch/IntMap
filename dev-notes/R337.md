## R337 — **気温の上に風を流す1つのスイッチ、まだ定型文だったチップ、NATO へ飛ぶ表、目盛りの無かった時計**

依頼は4件。⑴ 気温レイヤーにも風のパーティクルのトグル、⑵ Atlas のプリセット送信文を
「まだほぼ定型文みたいなものしかない。もっとその場所にあったものに」、⑶ NATO members を
オンにしたら NATO へ、⑷ Chronos の Time のタイムスライダーに目盛り。

### ⚠⚠⚠ ① 2つ目のスイッチは、1つ目が入っていないと何もしないスイッチだった

#R313 は粒子を色ラスタから切り離したが、**切り離した両方が同じ `on`（＝風レイヤー自身のスイッチ）に
ぶら下がったまま**だった。だから気温の場の上を空気が流れるのを見る方法は「風レイヤーも点けて、
その色ラスタごと持ってくる」しかない。**最初のスイッチが入っていないと何もしない2つ目のスイッチは、
何もしないスイッチである。**

⇒ `soloOn`（＝このレイヤー以外の誰かが筋を欲しがっている）と、`live() = on || soloOn`。
**`on` の使われ方をすべて2つに割った**——場の読み込み・広げる梯子・フレームループ・キャンバスは
`live()`、`addField`/`ensureField`/その reveal＝**地図の上の2つのラスタスロットは `on` のまま**。
気温の上に風を頼んだ読み手は、風の色を上に乗せてくれとは頼んでいない。

⚠ **2つのスイッチは別の問いで、別の既定値を持つ。** 「風レイヤーはアニメーションするか」は
`partsOn`（#R313 以来 既定 ON）。「気温の上に風を描くか」は気温凡例の箱で、**既定 OFF**——筋は
u と v の2変数を読む。気温ラスタだけを出している読み手が一度も払っていない読み込みで、触らない
読み手にとって何も変わらないことが条件だった。

⚠ **2つのモジュールの間を渡るのは実効値1つ**（箱 AND そのレイヤーが on）で、押し出す場所は
`syncLegend()`。レイヤーの on/off が変わる経路は**すべてそこを通る**——読み手のチェック解除、
セッション復元、そして ECMWF に繋がらなかったときに `toggle()` 自身が行う取り消し。
⚠ `stop()` が `_quiesce()`（梯子・階段・軌跡・キャンバス・共有フレームの解放）を呼ぶのは
**もう誰も場を欲しがっていないときだけ**。`disposeWind()` も `soloOn` の間は GL を返さない。

⚠ 扉は1つ（`window._imWxTempParts`）。凡例の箱・Atlas の dispatch（`{"type":"windParticles",
"over":"temperature"}`）・返信に載るインライントグルの3つが同じ関数を通るので、**3者が状態について
違う考えを持つことがありえない**（#R313 ① と同じ形）。

**実測（本番ビルド・Playwright、tests/r337.spec.js ①）**: 気温レイヤーが off の状態で箱だけ立てても
`Wind.solo()` は false のまま。レイヤーを on にして箱を入れると `Wind.solo()` true・`#wind-canvas`
表示・**`wind-field-a` / `wind-field-b` は 0 レイヤー**・`dl-wind` は未チェックのまま。
気温レイヤーを消すと重ねも一緒に消える。

### ⚠⚠⚠ ② 定型文が残っていた理由は数えられた——**特定的な候補が1つ残らず「世界の極値」で門を作っていた**

#R313 はチップを「4つの固定文」から「述語つきの候補プール」に置き換えた。それでも読み手には
定型文に見えていた。理由は好みの問題ではなく**数**である：#R313 が書いた**特定的な候補は、
1つ残らず世界の極値で門を作っている**——人口密度の上位10、面積の上位8、国防費比の上位12。
**極値には10か国しか入れない。** 何の極値でもない約150か国にとって、資格を持つ候補は
常に真の尻尾（`capital` / `subregion` / `latest` / `neighbours` / `since1990` / `wx`）だけで、
それは #R309 のメールマージに2文足したものである。**プールにはなった。問いは4つのままだった。**

⇒ **⑴ 尻尾は競争相手ではなく落穂拾いにした。** #R313 は全候補を1つの重みで並べて上位4つを取り、
尻尾に 2〜5 の重みを与えていた。それは**世界の極値には負けるが、ありふれた事実には負けない**高さで、
だから「1つだけ特徴のある国」は、その特徴について1問と、何でもない話3問を渡されていた。
`tail:1` を持つ候補は**資格のある特定的な候補を1つも押しのけられない**（順序は各群の中では重みのまま）。

⇒ **⑵ 世界の端を掬うのではなく、世界を分割する事実を26件足した。** すべて `countryStats` が
**既に持っている**データで、典型はこの3種類：
* **国がどこにあるか**——#R185 の `bbox`（[w,s,e,n]）から測る。赤道が箱の中にある／北極圏が箱の
  中にある／箱ぜんぶが回帰線の間にある、の3つは**測定値の構成から真**。4つ目は2つの測定値の比
  ——陸1 km² あたりどれだけの海に領土が散らばっているか。
  ⚠ **これは「群島か」ではなく「遠く離れた領土を持つか」を測っている**ので、門が支える文もそう
  書いてある（フランス 184＝ギアナとレユニオンが同じフィーチャに入る／フィリピン 6.4＝島が密集）。
  ⚠ **経度をまたぐ主張は 180° より広い箱には出さない**。ロシア・アメリカ・フィジー・
  ニュージーランド・キリバスは ±180 をまたぐ環で届くので素の extent が 360° になる。
  **「日付変更線をまたぐ」と「惑星をまたぐ」をこのモジュールは区別できない**——推測するチップこそ
  このラウンドが消しに来たものなので、**拒否する**。
* **国が何で回っているか**——言語の数（`LANGS`）、誰の通貨か（`CURRENCY`）。
  「自国通貨ではなく米ドルを使っている」は8か国についての問いで、他のどの国についての問いでもない。
* **2つの事実の組**——豊かで**かつ**統治が強い／経済規模は大きく**かつ**1人あたりは低い／
  長寿で**かつ**所得は控えめ。**カタールとノルウェーは1人あたり所得の上位10に両方入っていて、
  最初の組に入るのは片方だけ**。単独のランクには分けられない国を、組は分ける。

  …に加えて**レイヤー門の候補を8つ**（#R313 は 100 行あるパネルのうち7行しか見ていなかった。
  読み手のカーソルの下にあるレイヤーについての問いは、いちばん特定的な問いである）。

⚠ **尻尾は消していない。** テーブルがほとんど何も知らない国が受け取るものであり、4文とも実在の
問いで9言語の訳が生きている。変わったのは、**テーブルが何かを知っている国から3枠を奪えなくなった**
ことだけ。

⚠⚠⚠ **そしてこの検査は、最初の版が「正しい理由で緑」ではなかった。** 描画されたままのチップで
比べると**どの2か国も重なり0**——チップは国名を含むので、**メールマージされた同じ文の2枚は
決して同じ文字列にならない**。それがまさに今回の苦情の正体である。⇒ **比較の前に国名を外す**
（`tests/r337-checks.test.mjs` と `tests/r337-atlas.spec.js` の両方で）。
⚠ 合成世界も作り直した。プールの帯は「上位25」「下位90」で、**70行の表と195行の表では意味が違う**
——240の filler を線形に並べ、`PLAIN` は**全分布のちょうど中央**、各 shape の1つの値は
**パーセンタイルから取る**（打ち込まない）。
**実測**: `MULTI`（4つの事実を持つ国）は**尻尾を1つも受け取らない**。1つだけ事実を持つ16の shape は
どれも**自分の事実についての問いを受け取り**、その問いは**他のどの shape とも共有されない**。

### ⚠⚠ ③ NATO は表に1行足しただけ——ただし「表が1つ」であることが足せる理由だった

#R313 の `js/layer-home.js` は CONSTITUTION §3（「レイヤーを選択しても視点を1px も動かさない」）の
**穴ではなく狭め**で、対象は「データが1つの地域にしか存在しないレイヤー」に限られる。NATO は
その形をしている——しかも他のどれよりはっきりと。`buildNatoFC()` は**北回帰線より南の多角形を
落としてから**塗る（Article 6 が条約適用地域をそう定義しているため。凡例が回帰線を描いているのも
それ）ので、**枠はそのまま条約地域の実測になる**。オーストラリアで点ければ空の地図が出る。

⇒ `window.IntMapNatoFC` を公開し、`HOMES['dl-nato']` を1行、`nato` の分岐に `arrive('dl-nato')` を
1行。**箱は打っていない**（EU と同じく、国コードごとに最大の陸塊）。⚠ その grouping が NATO でも
効く：アリューシャン列島は ±180 の向こう側で `USA` の下に来るので、**フィーチャごと**に最大を取ると
枠が東太平洋へ伸びる（#R313 がクリッパートン島で踏んだのと同じ形）。**コードごと**なら本土が勝つ。
⚠ CONSTITUTION §3 の一覧と `tests/r313-checks ⑤` の `deepEqual` を**更新した**——例外が「憲法が
数え上げられる名前つきの集合」であることがこの検査の要点なので、**集合が変わったら赤くなるのが正しい**。
**実測（本番ビルド）**: 枠は 西 −141 / 南 23.4 / 東 45 / 北 71 の範囲に収まり、東京から点けると
カメラは実際に動き、`arrive()` の2度目は false（1セッション1回）。

### ⚠⚠ ④ Time タブの下にあったのは目盛りではなく、flexbox で等間隔に置かれた5つの数字だった

`.ntl-scale` は `justify-content:space-between` の5つのラベルで、**軸のどこに当たるかを示す印が
1つも無い**。しかもこのタブでそれを使うには2つ問題がある：⑴ マークアップの順が
slider → `.ntl-player`（このタブに出る ECMWF の輸送ボタン）→ `.ntl-scale` なので、**数字はボタンの
行の下**に座る。軸から切り離された目盛りは目盛りではない。⑵ **等間隔に置くことは、位置を計算する
ことではない**。0–1439 を4等分するぶんにはたまたまほぼ正しく、一般には正しくない。

⇒ `#ntl-ticks` をスライダーの**直下**に新設し、**1時間ごとに1本**・6本ごとにラベル。位置は
`(v − min) / (max − min)`。⚠ 軸の終わりは `_timeMaxMins()` に**訊く**（#R210 が「範囲を述べる唯一の
場所」にした関数。1440 を打ち込むと、そこが変わったとき印だけが取り残される）。
⚠ **レールは親指の半分ぶん内側**——range input の親指の**中心**は 9px から width−9px までしか動かない
ので、素のパーセントで置いた印は端で最大 9px ずれる。⚠ Year と Date のタブは**1文字も触っていない**
（報告はこのタブについてのものだった）。
**実測（本番ビルド）**: 印 25 本・ラベル `00:00 / 06:00 / 12:00 / 18:00 / 24:00`・**12:00 はレールの
中心から 2px 以内**・両端のラベルはパネルの中に収まり、`.ntl-scale` は Time タブでは非表示、
Year タブに戻すと元通り。

### 追記 — **本番検証が本番で拾った: 「The equator runs through Norway」**

このラウンド自身の本番検証で出た。**外接矩形は位置ではない。**

`countryStats` の `bbox` は**エクステント**であって、国がどこにあるかではない。ノルウェーの箱は
**ブーベ島（南緯 54.4°・ノルウェー領）**まで届くので、`bb[1] < -0.2 && bb[3] > 0.2` は
「南に飛び地を1つ持つ北の国」に対してそのまま成立する。しかも同じ箱のせいで**中点が 8.4°N** になり、
「冬は日が短い」のチップは**それを書いた当の国で発火していなかった**。1つの誤りが2つの向きに出た。

- ⇒ **国がどこにあるかを言う2つの主張は、国自身のラベル点**（`latlng`＝Natural Earth の
  `LABEL_Y`/`LABEL_X`。本土の中に置かれる錨）**を読む**。無ければ**主張しない**。
  `equator` は「箱が赤道をまたぐ」に加えて**ラベルが赤道から 25°以内**、`farsouth`／`highnorth` は
  箱の中点ではなく**ラベルの緯度**。エクステントは岩1つで伸びるが、ラベル点は伸びない。
- ⚠ **残る3つはそのまま**で、理由は**失敗の向きが「拒否」だから**である。`tropics` は**箱全体**が
  回帰線の内側かを訊くので、遠い島は発火ではなく拒否しか起こせない。`arctic` は箱の**北の縁**が
  北極圏に入るかを訊き、縁は実在の幾何が作るので、そこには本当に陸がある。`spread` は
  **その遠い破片についての主張**なので、ブーベ島はそれを真にする側である。
- ⚠ **実データで数え直した**（本番の `countryGeo`・177 フィーチャ）: 修正後の `equator` が発火する
  のは **10 か国**——インドネシア・コンゴ民主共和国・ソマリア・ケニア・ブラジル・コロンビア・
  エクアドル・コンゴ共和国・ガボン・ウガンダ。`arctic` は **7**（カナダ・アメリカ・ロシア・
  ノルウェー・グリーンランド・スウェーデン・フィンランド）。
- 検査は `tests/r337-checks.test.mjs` の「追記 ②」で、**合成世界にノルウェーの形を1つ足した**
  （箱は −54.4〜71.2、ラベルは 64.0N）。⚠ **origin/main のコードに当てて赤くなることを確認した**
  ——赤くならない検査は、直したことを何も言っていない。

### ⚠ 起動予算は上がった。上がった理由は「9言語ぶんの文章」で、それは黙って通してよい種類ではない

`npm run check:perf`（#R311）は eager を両方向にラチェットし、async チャンクと `dist/` を天井で見る。
このラウンドは天井を**上げた**ので、上げた理由をここに書く——ゲート自身が
「A startup cost that goes up needs a reason — say it, or take it back out」と言うからである。

| | before | after | Δ |
|---|---|---|---|
| eager raw | 4,312.4 kB | 4,318.0 kB | **+5.6 kB** |
| eager gzip | 1,435.4 kB | 1,437.4 kB | +2.0 kB |
| eager cssRaw | 293.6 kB | 294.3 kB | +0.6 kB |
| async `atlas-console` | 739.7 kB | 758.8 kB | **+19.1 kB** |
| async `ui.fr` / `ui.ko` / `ui.zh` / `ui.zh-hans` | 350.8 / 346.7 / 312.4 / 312.4 kB | 356.5 / 352.5 / 317.2 / 317.2 kB | +5.7 / +5.8 / +4.8 / +4.8 kB |

- **eager の +5.6 kB** は ⑴⑶⑷ のコードそのもの——`js/weather.js` の `soloOn` 配線と気温凡例の行、
  `js/layer-home.js` の NATO の1エントリ、`js/news-timeline.js` の `buildTicks`、`css/intmap.css` の
  目盛り。⚠ **どれも起動時に走る面にある**（気象モジュールも Chronos の UI も eager）。
- **async の +19.1 kB と 4つの言語チャンク**は、⑵ の**候補26件の文章そのもの**である。候補1件は
  9言語ぶんの1文で、5言語はインラインの `L()`、残り4言語は各言語のチャンクに入る。
  ⚠ **これは「削れる無駄」ではなく、機能の実体が文章であるということ**——候補を減らせば減るし、
  減らせば #R313 の欠陥（極値にしか門が無いプール）が戻る。
- ⚠ **atlas-console は on-demand（#R224）で、言語チャンクも読者の言語のぶんだけ**。起動時に払う
  のは eager の +5.6 kB だけである。

### ⚠ 試験時間の予算は、足したぶんを外から持ってきて払った

このラウンドは spec を**2本**足した。`tests/r337.spec.js`（6 s・気温凡例のスイッチと Chronos の
目盛り）は安いほうで、`scripts/tiers.mjs` の規則どおり**このラウンドの spec として門に立つ**。
Atlas のチャンクと国テーブルを要する2件は `tests/r337-atlas.spec.js`（24 s）——**名前が
`rNNN.spec.js` ではない**ので門には入らず、nightly と merge 後に走る（`r318-atlas` と同じ形）。
⚠ **30 s は天井からではなく、古い過大評価から出した**：`tests/r170.spec.js` は 108 s を背負っていたが、
それは #R208 が9回の起動を1回にする**前**に測られた数字で、#R209 が「まだ stale-high」と書いて
手を付けなかったものである。同じマシンで2回測って **60.3 s / 76.5 s**（開きは別セッションのビルド）
なので、台帳には**上のほう（77）**を入れ、主張する節約は小さいほうにした。総額 5,180 → **5,179**。
