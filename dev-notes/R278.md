## R278 — **実装されていた到達圏が、プランナーのカタログに一度も載っていなかった／半径円が所要時間の答えとして代用されていた**

> 「現在地から徒歩一時間で行ける範囲を表示して。」
> → **半径 5 km の円**
> 「いや半径でごまかすな。」
> → 円を消し、**存在しない `control`** を叩いて「実道路ネットワークによる徒歩到達圏（等時間圏）を
>    描画する機能を実行できないため、半径円で代用せず、今回は表示できません。」
> 「ふざけんな」

**最後の一文は事実ではなかった。** 到達圏は #R86 から実装されている。`js/map-tools.js` が
Valhalla／OpenStreetMap の**実道路網**から等時線を取って描き、ツール一覧には 🎯 のボタンがあり、
`js/atlas-console.js` には動作する `case 'isochrone':` がある。**今回、上流エンドポイントを実際に
叩いて確かめた**——利用者自身の座標 (136.934, 35.133) に対し `costing=pedestrian` / `contours=[{time:60}]`
は **HTTP 200・1.2 秒**で実ポリゴンを返す（`Access-Control-Allow-Origin: *`）。

欠けていたのは機能ではなく、**プランナーに渡す操作カタログの項目**だった。

### ① 「カタログに書かれていない操作は、プランナーにとって存在しない」——規則はあり、検査が無かった

`SYS()` が返す文字列がモデルの知る全世界で、そこには `{"type":"radius"…} (circle)` はあり
`isochrone` は**一語も無かった**。だからモデルは、reach の形をした唯一の既知アクションである
`radius` を出し、それを否定されると**知らないものを実行する方法が無い**ので「できません」と答えた。
モデルの嘘ではなく、**カタログの欠落がそのまま返ってきた**。

この規則そのものは同じ関数の 10 行下に書いてある——

> «an action the catalogue does not describe DOES NOT EXIST for the planner»

**書いてあるだけで、誰も突き合わせていなかった。** 機械的に数えたら、
**ディスパッチャの 117 の `case` 群のうち 6 つ**が「実行できるのにカタログに無い」状態だった：

| 実装 | UI からの到達 | カタログ | 症状 |
|---|---|---|---|
| `isochrone` / reach | 🎯 到達圏ボタン | **無** | 半径円で代用され、次に「機能が無い」 |
| `optimizeRoute` / tsp | — | **無** | 「A・B・C を最短で回る順番」が届かない |
| `objects` | オブジェクト一覧 | **無** | 「地図上のものを管理」が `control` 頼み |
| `slope` / `aspect` | 傾斜レイヤー | **無** | 「斜面の向き」が届かない |
| `rfCoverage` / `viewshed` | 電波パネル | **無** | 「電波の届く範囲」が `los` と混同される |
| `earthReplay` | Earth Replay | **無** | 本文に「Earth Replay」と散文で出るだけ |

（`monitor` も無いが、これは #R231 が意図的に撤去したもので、`FEATURE_WITHDRAWN` を返すためだけに
`case` が残っている。**唯一の例外**として理由つきで宣言する。）

→ **6 つ全部をカタログに書いた。** さらに `radius` の項目自身を書き換え、
**所要時間の質問は `isochrone` へ回し、円で代用しない**ことをモデルへの指示として明記した。

⚠ **項目は既存のソース行の中に足した。** `js/atlas-console.js` は #R199 の 5,300 行の天井にいる
（5,298 行）。プロンプト文字列の中の `\n` はモデルにとっては段落だが**このファイルの行ではない**ので、
6 項目と注記を既存行に畳んで **行数は 5,298 のまま**にした。天井を上げるのは、この天井がある理由
そのものを壊すことになる。

### ② 恒久ゲート `scripts/atlas-catalog.mjs` — 次は生まれた瞬間に落ちる

`npm test` の source 側の鎖に入れた（`npm run check:catalog`）。`js/atlas-console.js` だけを読む：

1. `switch(a.type)` の中の `        case 'x': case 'y': …` 1 行＝**1 つの機能**（綴りが何個あっても）；
2. `function SYS()` の本文＝**カタログ**（本文の終端は中括弧の数え上げではなく
   *その関数の閉じ括弧の行*——本文は `{"type":…}` を含む 64 KB のプロンプト文字列で、括弧は数えられない）；
3. 綴りのどれかが**二重引用符つき**で本文にあれば「カタログ済み」。
   **素の単語一致にしなかったのは**、`reach` や `Earth Replay` のような散文はモデルが JSON に
   書ける情報を何も与えないから——そしてそれが、機能が不可視だった間そこにあったものそのものだから。

⚠ **緑が「見ていない」ではないことを証明する。** `tests/r278 ①` は、この欠陥をわざと持った
**架空の atlas-console**（SYS 本文と switch）を組み立て、監査がその機能を名指しすることを確認し、
カタログに 1 項目足すと黙ることを確認する。散文だけの版でも落ちること、`case` が 1 つも無ければ
**空集合を検査して緑になるのではなく例外を投げる**ことも見る。

### ③ AI を通らない決定論パスも、その文を読めていなかった

`localPlan` は AI より**先**に走り、確信のある計画はアカウントも AI クレジットも使わずに実行される。
つまりこの沈黙は「地図が出るか、ログイン画面が出るか」の差だった。
「現在地から徒歩一時間で行ける範囲を表示して」が既存の 4 本のどれにも当たらなかった理由は 2 つ、独立している：

- **「一」は漢数字**で、数字クラスは `\d+` だった；
- 文は**「で行ける範囲」**で、末尾は `以内` / `圏内` / `圏` / `の範囲` しか受け付けなかった。

→ 漢数字・全角数字を読む変換を足し、末尾に「行ける／いける／到達できる／移動できる／歩ける／走れる」
＋「範囲／到達圏／エリア／届く範囲／ゾーン」を足し、**移動手段は所要時間の前後どちらでもよい**
（「1時間で歩いて行ける範囲」）ようにした。ただし**手段は必須のまま**——手段の無い「30分の範囲」は
ここで当て推量せず、（もうその存在を知っている）プランナーへ回す。

実測：**「現在地から徒歩一時間で行ける範囲を表示して」がログイン無し・AI 無しで 988 ms、
76 頂点の実ポリゴン、中心は 136.934, 35.133、`min=60`。**

### ④ 「✓」と言いながら別の場所に描いていた／何も描いていなかった

再現の途中で、報告とは別の 2 つの欠陥が測定された。**どちらも今回の苦情と同じ形**——やっていない
仕事を「やった」と報告する——なので直した。

- **`lng`/`lat` が捨てられていた。** 兄弟のハンドラ（`rfCoverage`・`earthquake`・`tsunami`・
  `nightSky`・`sunHours`…）は全部まず座標を読むのに、このハンドラだけが
  `geocode(a.place||a.from||a.origin||a.center)` しか呼ばず、`geocode('')` は最後の地点か地図中心に落ちる。
  **実測**：`{type:'isochrone',lng:136.934,lat:35.133,mode:'pedestrian',minutes:60}` が
  **「✓ 60 分の到達圏」と答え、等時線を 10°E 20°N に描いた**。修正後は 136.934, 35.133 に描く
  （東京駅で再確認：139.7671, 35.6812）。
- **地図に一片も届かなくても `{ok:true}` を返していた。** `ensureLayers()` は真偽値を返すのに
  戻り値は捨てられ、意味のある唯一の書き込みは `try{…}catch(_){}` の中にあり、
  ポリゴンが 0 本の応答もそのまま成功に落ちていた。**実測**：スタイル読み込み中のタブでは
  `addSource` が «Style is not done loading» を投げ、**何も描かれないまま**
  「✓ 60 分の到達圏」が出た。→ 3 つとも正直に失敗し、呼び出し側が
  **ルータ側の失敗（`api`）と地図側の失敗（`render`）を別の文で**言う。
- ついでに、**上流が扱えない所要時間は黙って `[15,30]` に置き換えられていた**
  （「3時間で行ける範囲」が 30 分の絵になる）。→ 1〜120 分である旨を返して**別の答えを描かない**。
