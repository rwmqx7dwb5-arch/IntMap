## R459 — **「キーが無い属性」を数えるゲートが、マークアップ2枚だけを宇宙にしていた**

「レイヤーのツールチップが9言語すべてで英語のまま。」

### ① 報告された3行より、それを見逃した門のほうが大きい

報告は具体的だった——本番（build R450）を fr / ko / zh-Hant / zh-Hans にして測ると、
`title="Layers"`（レイヤーサイドバーの縁の開閉ボタン）と `title="Favorite"`（★）が9言語すべてで英語。

```
js/map-ui.js:674      tg.title='Layers'
js/map-ui.js:706      st.title='Favorite'      タイル側の★
js/layer-favs.js:68   star.title='Favorite'    従来行の★ — 同じ文字列の2人目の書き手
```

⚠⚠⚠ **手掛かりは同じ要素の上にあった。** `js/atlas-controls.js:124` が同じ★に
`IntMapLang.t(…)` を通して `aria-label` を与えているので、フランス語の読者は**1つのボタン**に
`aria-label="favori : …"` と `title="Favorite"` を同時に見ていた。
**1要素の2属性が食い違う**というのが、宇宙がマークアップで止まっているときの外形である。

⚠⚠⚠ **そして `npm run check:i18n` はこれを 0 と印字し続けていた。** #R240 の第6の面
（`scripts/i18n-attr-audit.mjs`）は自分をこう説明している——「title / aria-label / placeholder / alt
で**キーが無い**もの」。それは**アプリについての主張**だが、実際に読んでいたのは

```js
const FILES = ['index.html', 'admin.html'];
```

の2枚だけだった。**JavaScript が実行時に書く属性は宇宙の外**なので、
`none — every title / aria-label / placeholder / alt carries a key.` は嘘ではなく**別の質問への答え**
で、その別の質問に答えたまま216ラウンド緑だった。

**説明が計測より広いゲート**は、`scripts/i18n-audit.mjs` の冒頭がまさに防ぐために書かれた欠陥
（「毎ラウンド、その日の計器が 100% を印字したまま、読者が画面上の英語を見つけた」）。
だから直すのは3行ではなく**宇宙**である。

### ② 宇宙は3つの形、走査は1本、判定は1つ

読み手に届く属性が書かれる形は3つある。同じタグ走査と同じ判定で読む。

| 形 | 例 |
|---|---|
| ① ディスクのマークアップ | `index.html` · `admin.html`（従来どおり） |
| ② **文字列が組み立てる**マークアップ | `'<b title="Close">'` ／ テンプレート ／ `'<i title="'+…+'">'` |
| ③ 実行時の代入 | `el.title=…` ／ `el.setAttribute('aria-label',…)` |

⚠ **自前のパーサは持たない**（#R372 の規則・`tests/r241 ①`）。`scripts/i18n-helpers.mjs` が
`js/` を1回だけ解析しており、その `shapeOf()` が「これは翻訳呼び出しか」の**唯一の答え**なので、
「システムに入っている」が2つのファイルで別の意味になりようがない。

⚠⚠⚠ **② は `+` 連結を先に畳まないと構造的に見えない。**

```js
'<input id="acled-email" type="email" placeholder="email" value="' + esc(cred.email) + '">'
```

どの文字列リテラル単体にも閉じタグが無いので、リテラルを1つずつ見る走査は `<input … value="` を
見て**何も報告しない**。ここに生きた欠陥が2件隠れていた（ACLED の資格情報欄 = `email` / `API key`）。
**この2件は私の初版も取りこぼし、独立に走らせた全数調査のほうが先に見つけた。**

⚠⚠ **「言語を名指していること」は翻訳ではない。** 初版は `lang` を含む式を全部見逃す抜け道を
持っていた（手書きの梯子は `i18n-two-branch-audit` の領分だから、という理屈）。**実測すると、
その抜け道が守っていたのはリポジトリ全体で1サイトだけ**——`js/tool-panel.js` の最小化ボタンで、
腕がそれ自体三項（`on ? '展開' : '最小化'`）なので**その audit も掴めていなかった**。
5言語を手書きで名指し、fr / ko / zh-Hant / zh-Hans は「Expand」と言われていた。
**1つしか守っておらず、その1つが病巣なら、それは抜け道ではない。**

⚠ **`js/app-body.js` の `d.tzSearch||'Search timezone…'` は死んでいた**——`keyed()` は英語を

今回増えたのは3つ: 装飾つきの固有名詞（`'IntMap — ' + title`）、単独の記号（`m`・`°C`）、
2〜4文字の全大文字の技術略号（`PAPI`・`ILS`——どちらも**隣に同じ綴りの可視ラベルがある**）。
4文字の天井が安全弁で、`CLOSE`(5) や `SEARCH`(6) は入らない。

### ④ 読み物ページでは `t()` は9言語ではなく5言語しか解決できない（ブラウザで測って気づいた）

29件のうち2件は読み物ページの言語ピッカー（`js/page-i18n.js` / `js/legal-page.js` の
`aria-label="Language"`）で、最初は他の27件と同じく `window.IntMapLang.t(lang,'Language','言語',…)`
に直した。**ゲートは緑になった。** そのままブラウザで開いて確かめると:

```
ru → 「Язык」    ✓
fr → 「Language」 ✗   ko → 「Language」 ✗   zh-hans → 「Language」 ✗
```

⚠⚠⚠ **`sources.html` が読み込むのは `js/locales/pages.*.js` と `js/lang-registry.js` だけで、
`js/locales/ui.*.js` は1本も読み込まない。** `pick()` / `t()` は最初の5言語を**位置引数**で解決し、
残る fr / ko / zh-Hant / zh-Hans は **inline 表**（＝`ui.*.js` の中）でしか解決できない。
つまり**読み物ページ上のあらゆる `t()` 呼び出しは、構造上5言語の呼び出しである。**
`check:i18n` はこれを見ない——inline 表の被覆は**アプリ側の宇宙**で 100% だから。

→ そのページが**実際に持っている**9言語の表を使う。`sources.html` / `science.html` は
`pages.*.js` の `common`、`terms.html` / `privacy.html` は `js/legal-page.js` 自身の `S`。
両方に `language` を足し、9言語すべてを**実ブラウザで**確認した（fr Langue / ko 언어 /
zh-Hant 語言 / zh-Hans 语言 / ru Язык / de Sprache / es Idioma / ja 言語 / en Language）。

⚠ **ゲートが緑でも画面は英語だった**——これは #R240 → #R459 が直した欠陥と同じ形が、
**1つ下の層**にもう1つあったということ。門は「表に在るか」しか訊けない。**在る表が
そのページに配られているか**は別の問いで、そこはブラウザを開かないと分からなかった。

### ⑤ 言語切替を生き延びる属性は、文字と鍵の両方を持つ

★とレイヤー欄の縁ボタンは**作り直されない**ので、書いた時点の言語で凍る。
`js/app-body.js` の `updateI18n()` は `[data-i18n-title]` を切替のたびに再適用するので、
**文字（作った瞬間に正しい）と鍵（切替のたびに正しい）の両方**を置く。
`ttlLayersPanel` / `ttlFavorite` を9言語の `ui.*.js` に追加した（zh-Hans は生成物なので
`scripts/zh-hans.mjs` で再生成）。

### ⑥ 開けない指摘は半分の指摘

`js/satellite.js` は **js/ で唯一 blob が CRLF** で、しかもその中に**孤立した `\r` が1つ**あった。
JavaScript は裸の `\r` を行終端と見なし、`grep` / `sed` は見ない。結果として **acorn を使う
この一族の全計器が、このファイルだけ12行目以降を1行ずれて報告していた**（実測: 走査は 146、
実ファイルは 145）。改行を他の全ファイルと同じ LF に正規化した——差分は行末を除けば2行。

同じ理由で、テンプレートの中の指摘は**バッククォートの行**ではなく**属性のある行**を出す
（`flatten()` が定数片ごとの開始行を覚えている）。パネル1枚ぶんのテンプレートは十数行ある。

### ⑦ 検査

`tests/r459-checks.test.mjs` — node 10本。
**①は「出荷当時の3行そのもの」を走査器に渡して3件出ることを固定する。**
「リポジトリが0」としか言えない検査は、216ラウンド緑だったあの検査と見分けがつかない
（[[intmap-recurring-lessons]] B）。そのために走査を**ソースの関数**として切り出し
（`scanSource()`）、CLI 側の `process.exit(0)` は直接実行のときだけ走るようにした
（import した側を殺さないため）。

同時に「翻訳呼び出しを通る値は指摘しない」「単位記号・URL・装飾つき固有名詞は指摘しない」も
固定してある——**全部を指摘する計器は何も指摘していないのと同じ**だから。
