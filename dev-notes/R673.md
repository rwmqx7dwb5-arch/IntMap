## R673 — **同じプログラムの2か所が、同じ問いに違う答えを返していた——パンデミック・シミュレーターの監査9件**

〈利用者の外部監査報告書（実装・疫学・地理表現・UI の総合監査）。固定コミット `563e4766`〉

報告書自身が最初に言っている: **「教育用シミュレーターの基盤は明確に改善している」。**
#R575 が数理を UI から出し、#R666 が滞在時間と移動を直した。今回の 9 件は**その後に残っていたもの**で、
どれも「模型が単純すぎる」ではない——**同じプログラムの 2 か所が、同じ問いに違う答えを返していた**。

### 1. ⚠⚠⚠ 国の時計は、病気が着いた日に始まっていた

```js
for (let i = 0; i < N; i++) {
  const s = st[i];
  if (!s.seeded) continue;      // ← 感染の算術「と一緒に」全部
```

この 1 行が飛ばしていたのは感染の遷移だけではない。**`R`/`V` の免疫減衰・接種・政策更新**も飛ばす。
だから同じ世界で同じ日数が経っても、**未流入国は初期免疫を凍結したまま持ち続け**、世界でワクチンが
使えるようになっても**そこでは 1 人も接種されない**。
**その国に感染が到達した日が、その国の免疫と公衆衛生の時計が動き出す日**になっていた。

直したのは分岐の中身ではなく**継ぎ目**である。全人口に関わる時間発展（減衰・接種）を
`stepUnreached()` に出し、`E`/`I` を要る処理だけを `if (s.seeded)` の内側に残した。

⚠ **未到達国に配らない、という選択は実在する。** だからそれは `vaccinateUnreached` という
**明示された政策**（既定 true）で、制御構造の副作用ではない。`seeded` をその代用品にしない。

### 2. ⚠⚠⚠ 同じ人が、隣人には感染し、空港には感染しなかった

国内の感染力は #R666 以来 `S` と `SV` を**同じハザードで**引く。輸入は引かない:

```js
const k = Math.min(s.S, Math.max(0, cases));   // S だけ
```

`SV` は「接種は受けたが守られなかった人」で、**感染については `S` とまったく同じ**である。
接種が行き渡って `S=0`・`SV>0` になった国は、`E=I=0` でも**算術として輸入不能**だった。
効果 40% のワクチンと長い campaign が普通に到達する状態である。

⇒ `S+SV` から比率どおりに取る。**ついでに「輸入とは何か」を 1 か所に書いた**——
送り出し側の `E`/`I` は減らない＝**人の移動ではなく、到着した感染者が現地で連鎖を始める圧力**であり、
だから消費するのは現地の未感染者で、だから両国の人口が保存する。
**画面もコメントも「感染者が移住する」と説明してはならない。**

### 3. ⚠⚠⚠ `draw(n,p)` が、半端な人数に払う人数を半分にしていた

```js
let k = binomial(whole, p);
if (frac > 0 && rnd() < frac * p) k++;
return Math.min(n, k);            // ← ここ
```

端数のために **1 人まるごとの Bernoulli** を引き、最後に `min(n,k)` で切る。
`n=0.5`・`p=0.5` なら 0.25 の確率で `k=1` になり、それが 0.5 に切られる。**期待値 0.125。**
正しい `n·p` は 0.25。**転記した関数を固定種で 200,000 回引いた平均は 0.1249。**

⚠ **これは「外から小数を入れたとき」の話ではない。** 期待値 30 人を超える遷移は期待値そのものを
返すので、**区画が実数なのはこの模型の通常の状態**である。そして小さい区画こそ、
**流行がひとりでに消えるかどうかを決める場所**だった。

⇒ 整数部は二項分布で引き、**端数は `frac·p` をそのまま払う**。不偏で、上限は `n` を超えず
（だから `min` は要らなくなり、それが隠していた欠陥ごと消える）、**整数の `n` は 1 バイトも変わらない**。

⚠ そして `for (let t = 0; t < leave; t++)` が**実数の `leave` を受けていた**ので、30.2 は 31 回回った。
端数が毎日 1 人ぶん、無料の旅行者を買っていた。

### 4. ⚠⚠⚠ 回線の速さが、「どの世界か」を決めていた

国境表（`data/country-facts.json`）と空港表（`data/airports.json`）は、panel が**タップを
受け付けながら**取得され、`world` に**その場で**書き込まれる。ところが移動行列は
`createPandemicModel()` の時点で**凍る**。

- 早く押せば → 人口と距離だけの世界
- 遅く押せば → 空港規模と陸境つきの世界
- **後から表が届いても、作られた行列は作り直されない**

詳細設定には種の欄があり、「同じ種なら同じ流行」を約束している。
**同じ種が同じ世界を指していなかったので、その約束は成り立っていなかった。**

⇒ 両方が**決着**するまで発生国を選べない。⚠ **成功ではなく決着**——死んだ表が読者を締め出しては
ならず、**名乗られる**べきである。以前の名乗りは `/airports/.test(model.mobility.from)` という
**1 つの正規表現**だったので、`from` が `population+borders` になる世界（国境は読めた、空港は読めなかった）に
**「国境も空港も読み込めませんでした」**と言っていた。表ごとに状態を持つようにした。

### 5. ⚠⚠⚠ 流行が終わった国が、赤い「感染性あり」の点を永久に描いていた

```js
if (act < 1 && a.D < 1) continue;
let k = Math.round(act / perDot);
if (k < 1 && (act >= 1 || a.D > 0)) k = 1;
```

`E=0・I=0・D=100` の国——**流行が終わり、全員が回復したか死んだ国**——は、`D` があるので
除外されず、`k` が 1 に引き上げられ、`kE` は `act=0` なので 0、つまり **`cls=1`＝赤**。
凡例はその赤を「感染性あり」と定義しており、HUD はその国の現感染者を 0 と印字していた。

累計死者は**生きている国の点を暗くする**（そこでの流行がどれだけ致命的かは、まだ症例がある場所の
性質だから）。この層に**国を残す**ことはできない。

### 6. ⚠⚠⚠ 差分の署名が衝突していた

```js
next.set(id, cls + sev * 2);
```

`sev` は 20 分の 1 に丸めてあるので 21 通り、`sev*2` は 0, 0.1 … 2 を取る。
**(cls 1, sev 0) と (cls 0, sev 0.5) は、どちらも厳密に 1。**
その 2 状態をまたいだ点は「変わっていない」と判定され、
**変わったものだけを送るのが仕事の差分が、何も送らない。** 古い色が、たまたま全件再同期が
掃くまで残る。整数で詰めれば衝突しない（21×2 の状態がすべて別の値になる）。

### 7. ⚠⚠⚠ Ebola の R₀ が 3 つあった

| どこ | 値 |
|---|---|
| プリセット／engine が走らせる値 | **1.95** |
| `range.value`（刻み 0.1 なのでブラウザが丸める） | **2** |
| ラベル（`toFixed(1)`） | **1.9** |

読者は**自分が何を走らせているのか確認できない**。

⇒ 丸め規則を足すのではなく、**持ち主を 1 つにする**。`mk()` が入力欄の実際に持てる格子へ丸め、
**描く前に `set()` で engine に書き戻す**。呼び出し側ごとではなく `mk()` に置いたのは、
**次に足されるスライダーにも効かなければならない**から（#R429 の形——規則は関数ではなく事実に付く）。
そのうえで、**プリセットの精度のほうを守るべきときは刻みを変える**（R₀ 0.1 → 0.05 で 1.95 が生き残る）。

### 8. ⚠⚠⚠ 同じ画素・同じラベルで、2 つの異なる流行

```js
function monthsToDays(m) { return (m == null || m <= 0) ? 0 : (m >= 600 ? Infinity : m * 30); }
```

**帯域内の番兵。** 1 つの変数が「期間」と「分類」を同時に運んでいて、その 2 つは
**実在のプリセットのところで正面衝突した**:

- Ebola の `naturalMonths: 120` は**実在する 10 年**。engine は正しく 3,600 日として扱う。
- スライダーは上限 120、書式は `v>=120 ? '∞'`。だから**画面は「∞」と言う**。
- そして**同じ上端に `input` が入ると** setter が `600` を書き、免疫が**本当に無限になる**。
  **表示は「∞」のまま変わらない。**

⇒ `naturalImmunityLifelong` を独立の欄に。スライダーは期間だけを運び、120 は 120。
0 か月（持続免疫なし）は 3 つ目の別の主張で、これとは衝突しない。

### 9. ⚠⚠⚠ 検査が 1 本、構造として無効だった

`tests/r666-model.test.mjs ⑦` は `mixShare` を #R666 の修正に縛りつける**唯一の**検査である。

```js
seed(i, cases) { return inject(i, cases == null ? P.initialCases : cases, null); }
                                                                        // ↑ 固定
```

`inject` は `if (fromShare) mixShare(…)` なので、**`mixShare` は一度も走らなかった。**
検査は株の割合を手で置き、種を播き、割合が変わっていないことを主張する——
**何も触らなければ必ず通る。#R666 の欠陥を実装に戻しても緑のままだった**（実測）。
さらに `variants.length` は新品のモデルで **1** なので、`share[1]` に答えていたのは `normalise` だけだった。

⇒ `fromShare` を**公開シグネチャに入れ**、第 2 変異株を実在させ、
「空の国」と「既に症例がある国」の**両方**を測る。変異テストで赤くなることを確認した。

**引数が私有なら、その規則は間違えようがない**（＝測れない。#R505 の形）。

### 10. ⚠⚠ 「現在の世界」に、今日の医療が入っていなかった

COVID-19 のプリセットだけ `vaccine.availableAtStart` と `treatment.availableAtStart` が
**両方 `false`** で、画面はその横で「2026 年時点でこの病気に実際にある免疫・ワクチン・治療法から
始める」と書いていた。**5 つのプリセットのうち、それを言ってはいけない唯一のもの**についてそう言っていた。

SARS は**対照**である——SARS-CoV-1 の認可ワクチンは存在しないので、`false` のままが正しい。

⚠ **初期免疫のほうは、直せる種類の問題ではない。** この engine の免疫は 1 区画しか無いので、
0.9 は「世界の 90% が完全な感染防御を持つ」と読まれる。WHO がそう推定したのではない。
麻疹の 0.84 は**子どもの MCV1 接種率**で、全年齢・全国に当てている。
⇒ **UI が「仮定した初期免疫」と名乗る**（実在するのはワクチンと治療法のほうだけ）。
部分防御を表す区画を足すのは別の仕事で、今回は**やっていない**。

### 11. ⚠⚠ HUD の 4 つの指標が、4 つとも別のものを名乗っていた

| 印字 | 実際の中身 |
|---|---|
| 「潜伏中 / Incubating」 | `E` は**感染済み・未感染性**。潜伏（発症まで）とは別で、**この模型自身がスライダーの隣でそう説明している** |
| 「接種 / Vaccinated」 `V/pop` | `V` は**いまワクチンで防御されている人**。減衰・免疫逃避・突破感染で減るので、**進んでいる campaign が「接種率が下がっている」ように見える**。`SV` は入っていない |
| 「国 / Countries」 | **いま症例がある国**の数。減る |
| 「感染性 / Infectious」 | 人数なので名詞句で読めるように |

⚠ **`V+SV` も累計接種人数ではない**（接種した人は感染や減衰で他の区画へ移る）。engine は接種の台帳を
持っていないので、**持っていない量の名前を付けるのではなく、持っている量の正しい名前を付けた。**

### 12. ⚠⚠ CFR と IFR は、ラベルだけ分かれて計算は分かれていない

#R575 が `severity.metric` を数と一緒に運ばせたのは正しく、**足りない**。CFR の分母は
**検出された症例**で、engine は値を `I` を離れる**すべての感染**に当てる（検出・報告・未診断を扱う
観測モデルが無い）。SARS の 9.6% と Ebola の 50% は、それを消費する唯一のものから見れば IFR である。

⚠ **根拠のない換算係数を掛けなかった。** それは由来も失効条件も書けない定数になる
（`.agents/rules/no-ad-hoc-hardcoding.md` §4）。⇒ **設定画面が分母を名乗り、読者が下げられる。**

### 13. ⚠⚠ 地図の算術は、DOM のクロージャの中にあった

だから外部監査に見つかり、11 ラウンドの検査に見つからなかった。5・6・7 はどれも**純粋な算術**で、
engine が既に出している読み出しに対する問いである。
`caseDotPlan` / `dotSignature` / `snapToStep` を `js/pandemic-model.js` の export にした——
**#R575 が `scatterCases()` を外へ出したのとまったく同じ理由**で、そのとき同じ段落の残りが置き去りに
なっていた。⚠ **これは疫学ではないので、区画に触れてはならない。**

### 17. ⚠ G4（アンカーの参照）は直した——**大声で壊れなかった理由のほうが教訓**

`resolve()` は #R666 で `{code, s}` を返すようになり、`genPts()` は `.latlng` を
**ラッパーから**読み続けていた＝常に `undefined`。その国自身のラベル点
（Natural Earth の LABEL_X/Y ＝主要陸塊の中のアンカー）が、それ以来**アンカー一覧から黙って
抜けていた**。

⚠ **例外も警告も出ないのは、下の gazetteer 掃引がたいてい都市を見つけるからである。**
点はもっともらしい場所に落ち続け、**欠けているアンカーは誰にも見えなかった**——
「動いているように見える」ことは「意図したものが動いている」ことの証拠にならない。
