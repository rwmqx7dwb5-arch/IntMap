## 1. 作ったもの

- **`js/my-map-doc.js`（新規・純関数）** — 文書の形と検証、リンク形（Encoded Polyline・1e-6°）、`fromLinkValue`（リンクを信用せず読み直し、読めない地物を数える）、描く形（大円を 0.1° 以下の断片・日付変更線で切る・極を囲む範囲は描かない）、FeatureCollection。
- **`js/my-map.js`（新規・遅延 `myMap`、`window.IntMapMyMap`）** — パネル（iOS のシート風・携帯は下端）、地図をクリックして頂点を置く描画（ピン／線／範囲・完了・1 点戻す・やめる・Esc・Enter・Backspace・最初の点で閉じる）、名前・メモ・色・地図で見る・削除、地図の文庫（新しい地図・切り替え・削除）、地図上の物を移す、リンク（コピー・共有シート）、GeoJSON / GeoPackage、分析に使う、地物を押すとポップアップでメモ、受け取った地図の読み取り専用表示と「自分の地図として保存」。
- **`js/map-state.js`** — SCHEMA に `mymap`（`&mm=`・最後尾・`restore:'full'`）と、行の `lazy`：**持ち主が遅延 module の欄は、値を持つ復元だけが `IntMapLazy.need(lazy)` を呼ぶ**。値の無い復元は保留にも積まない（何も描いていない持ち主に渡すものが無い）。⚠ これを入れないと、後で読者がパネルを開いて持ち主が登録された瞬間に、起動時の復元の「無し」が渡されて地図を隠していた（設計時に見つけた順序の欠陥）。
- **入口**: Layers ▸ Tools の行 `tool.myMap`（`js/map-ui.js` SIM_TOOLS。`mod:'IntMapMyMap'` で開いている間は点灯し、2 度目で閉じる）、オブジェクト一覧（`js/map-tools.js`、種類 `mymap`）、`mm=` を持つ共有リンク。
- **Atlas**: `map.myMap`（`js/atlas-cap-map.js`。open / add / edit / remove / title / show / hide / list / link / export / analyze / new / collect / keep / draw。`place` / `places` は Atlas の geocode で解き、解けない名前があれば線を作らずに名指す）。新しい観測器 **`myMap`**（`js/atlas-capabilities.js`）は module 自身の状態と描かれた地物数を**呼んだ後に**読み、結果の `want`（`shown` / `has` / `lacks` / `title` / `mapId` / `features` / `atLeast`）と一致したときだけ完了、呼ぶ前から一致なら `already_there`、module が無ければ `unobserved`、表示中なのに描かれた地物が 0 なら `not_rendered`。状態に `myMap` 節（`js/atlas-state.js`）。
- **オブジェクト一覧の欠陥（構造）**: `IntMapObjects` の描画は手書きの `order` にある種類だけを並べていたので、`collect()` が返す新しい種類は**黙って一覧から落ちていた**。`order` に無い種類は後ろに並べるようにした（アイコンが無い種類も落とさない）。

## 2. 決めたこと（と理由）

- **辺は大円**。計測ツール・面積ツール（`_gcDensify`・`ringArea`）と同じ「地球上の直線」。地図・分析・ファイルが**同じ 1 つの形**（`geometryOf`）を受け取る——画面は大円、書き出したファイルは経緯度の直線、という食い違いを作らない。断片の長さ 0.1° は「断片の弦と大円のずれ ≤ L²·tanφ/8R ≈ 60°N で 4.2 m（11.1 km の断片）」から（`DENSIFY_DEG` の隣）。
- **精度は入口で 1 回**。頂点は文書に入るときに 1e-6°（0.11 m、z20 の 1 CSS px より細かい）に丸める。保存の写しがリンクより細かいと、作者と受け手が違う地図を見る。
- **自分の地図のリンクを開いたら手元の写し**（id が同じ）。リンクはその時点の写真で、手元のほうが新しい。他人の地図は読み取り専用で、保存は**新しい id の写し**（送り手の地図の id を名乗らない）。
- **分析はその時点の写し**。データセットの `provenance` が `map`（どの地図）・`at`（いつ）・`author`（このブラウザの読者／リンクで届いた）を述べる。描き足しても過去の分析は変わらない——変わったら「何の結果か」が言えなくなる。ライセンスは誰も述べていないので書かない。
- **「移す」は移動**。ピン・残した図形・半径円をマイマップの地物にして元を消す（同じ物が 2 つ並ばない）。半径円は円ではないので 64 角形になり、名前がそう述べる（面積は 0.16 % 小さい）。
- **計測の数は計測ツールの関数**（`HOST.ringArea`・turf の大円距離・`HOST.distHTML` / `areaHTML`）。表示は文字にして符号器を通す（`output-taint` の葉を増やさない）。
- **共有の長さに上限を置かない**。断片（`#`）はサーバへ送られないので、ツアーの `?t=` にある 8,192 バイトの実測上限は効かない。ツアーの段に入ったときはツアー作成の計器が測る。パネルはリンクの長さを KB で述べる。

## 3. 歴史地図として

マイマップは年を持たない。描いた図形は Chronos の時刻に従わず、どの年にも同じものを描く（読者が書いた注記であって、ある年に在ったという主張ではない）。授業ツアーの段で 1914 年の地図に図形を載せた場合、その主張の作者は描いた読者である（`historical-verification.md` §2 ③——典拠の無い日付を地図が述べていない）。

## 6. ブラウザで見つけて直したもの——地球の外を押すと、球の裏側に頂点ができていた

一時 spec の最初の版は全部緑で、**ピンが地図に見えていなかった**（スクリーンショットで確認）。押した点 (600, 320) は球の左の黒い空間で、MapLibre の `unproject` は**それでも答える**——10.42°N 70.63°W、球の裏側の縁の点。座標の読み出し（`js/map-readout.js`）も同じ値を出していた。頂点は保存され、測られ、リンクに載り、**誰にも見えず押せない場所に描かれていた**。
⇒ 地図エンジンの契約に `coords.onSurface(pt)` を足した（MapLibre: `_tr` の `isPointOnMapSurface`——球は視点からの光線が球に当たるか、平面は地平線より下か・地形があれば地形メッシュ。MapLibre 自身が点を中心にズームする前に訊く問い。Cesium: pick の光線が地球に当たるか。両方のアダプタと `types/geo-engine.d.ts`、`tests/engine-capability-contract-checks.test.mjs` の REQUIRED）。マイマップは外を押されたら頂点にせず「そこは地球の外です」と述べる。
⚠ **残した観測**（今回の範囲の外、提案として）: 計測ツール（`handleMapClick`）・半径円・座標の読み出しも同じ `e.lngLat` を使っていて、球の脇を押すと裏側に点を置く。Cesium の `unproject` は地球に当たらないと **(0, 0)** を返す（`js/cesium-engine.js`）——どちらも `onSurface` に訊けば直る。
