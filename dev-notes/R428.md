## R428 — **本番検証が、同じ絵に至る 2 本目の道を見つけた**

#R416 は「帯が見えない」の原因を `short: ''` に特定して直した。その**本番検証**が、
**同じ絵が別の原因でも出る**ことと、#R416 が作った 1 行が持つ副作用を見つけた。どちらも
ローカルでは一度も見えていない——本番の視野・本番の被せもの・本番の応答時間が要るからである。

### ① 読めない帯が、読める帯の場所を取っていた

本番実測 (2026-08-24・1440×900): レイキャビクの帯が右上の **Map/Satellite ＋ Flat/Globe/3D の
卓の下**に入り、読者に届いたのは**角丸の箱の切れ端**だった。#R416 が直した空の `text-field` とは
**原因が違うのに絵が同じ**で、報告写真と見分けがつかない。

⚠⚠ **そして「見えない」より悪い。** `declutterNewsBands()` は**他の帯としか**ぶつからないので、
卓の下の帯は衝突判定に勝ち、**場所を確保したまま読めない**。読めたはずの帯はそれに負けて消える。

⇒ 場所を取る前に `elementFromPoint` で「その画素の最上位は canvas か」を訊く。
⚠ **被せものの一覧は持たない。** 手書きの一覧は最初の浮いたカードで古くなる——#R399 が
「手書きの走査対象一覧が欠陥そのもの」として測ったのと同じ形である。
⚠ **これは「上に載っているか」ではなく「上でポインタを取るか」を訊いている。**
`pointer-events:none` の被せものは見えない。今日地図を覆っているものは全部ポインタを取るので
この問いでよいが、**同じ問いではない**ことは書いておく。

⚠ **費用は測った。** `declutterNewsBands` は 44 ピンで**中央値 6.7 ms**（8 回:
10 / 19.2 / 7.7 / 6.7 / 6.4 / 6.6 / 6.3 / 6.5）。moveend と zoomend にしか走らない。
判定するのは**勝った帯だけ**なので、ピンごとではなく 1 回の settle につき 15 回ほどである。

### ② 1 行の右半分だけが 6 秒間英語のまま残った

本番実測 (3 回): 言語を切り替えると scope（すべて / ★ 保存済み）は**即座に**日本語になるのに、
**カテゴリ chip だけが 5,928 / 6,289 / 6,693 ms 英語のまま**残る。理由も測った——切り替えが
`news_events` の再取得を起こし（REQ 3,241 ms → RESP 4,640 ms）、`renderChips()` はその着地の
あとに走る。chip の語は**描画時**に `L(...)` で評価されるので、呼ばれない限り前の言語が残る。

`js/app-body.js` の `setLang()` は「relabel する module のために」`intmap-lang` を投げているのに、
`js/news-events.js` はそれを**聞いていなかった**——この行で唯一聞いていない操作だった。

⚠⚠ **#R416 がこれを見えるようにした。** scope とカテゴリを**同じ 1 行**に並べたので、その 6 秒は
「すべて / ★ 保存済み / All topics / World / Politics & Conflict …」という**半分だけ英語の 1 行**になる。
2 行に分かれていたときは「下の行がまだ古い」だっただけで、同じ欠陥がここまで目に付かなかった。

⚠⚠⚠ **貼り替えであって再描画ではない。** `renderChips()` を呼ぶのが素直に見えるが、件数は
`HOST.globalData` から来る——**言語切替が直前に空にした配列**である。再描画すると
「全カテゴリ 0」だけになり、0 件のカテゴリを出さない規則が残りを全部落とす＝**翻訳する代わりに
行を消す**。だから語だけ差し替え、件数のノードはそのまま付け直す。

### 検査が赤にできることを先に確かめた

⚠⚠⚠ **最初に書いた「埋まった帯は無いこと」の主張は、修正を外しても緑だった。**
spec のカメラでは、たまたまどの帯も卓の下に来ない。**発火しない検査は通った検査と
見分けがつかない**（#R399）。⇒ spec が**被せものを探して**（`elementFromPoint` で走査。
名前で指さない）、実在のピンがその下に来るまでカメラを寄せるようにした。
実測: 修正を外すと **buried 3 件**で赤、戻すと緑。

`tests/r428-checks.test.mjs`（2 本）も **4 通りに変異させて全部赤**を実測した
——判定を消す／判定はするが場所は取らせる（**このラウンドの欠陥そのもの**）／
`intmap-lang` を聞くのをやめる／貼り替えを再描画に戻す。

### 測り方について

⚠⚠ **並行して browser のジョブを 2 本走らせた瞬間に、spec が落ちた**（5,267 ms で failed）。
機械が空いてから 5 回連続で回すと **3,362 / 3,527 / 3,571 / 4,123 / 3,568 ms・5/5 緑**。
#R416 で「点滅する赤は赤の証拠にならない」と書いた同じ罠を、**同じセッションの中でもう一度**
踏みかけた。⇒ **測るときは 1 本だけ走らせる。**

⚠ **`/tmp` を使うな**（memory の常設項目）。退避に `cp … /tmp/…` を使い、python から同じパスが
見えず（MSYS のパス）、続く `rm` が退避ごと消した。⇒ 退避は scratchpad へ。
