## R502 — **動いていた計測は、9言語の第三者一覧のどこにも名前が無かった**

利用者が公開前レビューの結果を持ってきた回。**報告をそのまま前提にせず、主張ごとに実コードで
確かめた**——8 件のうち 5 件は裏が取れ、1 件は**指摘の結論は正しいが理由が逆**だった。
今回手を付けたのは、そのうち**機能にも利用者の契約条件にも干渉しない 2 件**だけ
（範囲は利用者が明示的に絞った。残りは §「やっていないこと」）。

### ① 計測は動いていて、告知は無かった

`index.html` の 10 行目は静的な `<script async src="…googletagmanager.com/gtag/js?id=G-57X5MX0ZPW">`
で、**パースされた瞬間にリクエストが飛ぶ**。Clarity (`x2colhytq7`) は #R193 が起動経路から外して
`requestIdleCallback` に移してあるが、**それは遅らせただけで、門ではない**。同意 UI はどこにも無い。

問題はそこではなかった。`js/legal-text.js` の「4. 第三者 / Third parties」は、Supabase・Google News・
Open-Meteo・OSRM・Valhalla・WorldPop・CelesTrak・GDELT……と**数十社を 9 言語で列挙している**。
その一覧に、**実際に Cookie を置き DOM 再生を録っている 2 社だけが入っていなかった**。
§5 は「Cookie・ローカルストレージ — セッション維持と設定の保存に使用します」の 1 行で、
分析についてひとことも言っていない。

⚠ **欠けていたのは実装ではなく、実装と文書の対応である。** これは重要で、直しかたを決める。

### ② 「消す」ではなく「止めて、戻すときに名指しを強制する」

利用者の指示は **「一旦停止。削除ではない」**。そこで:

- `window.INTMAP_ANALYTICS=false` を 1 つ置き、**GA と Clarity のローダを両方ともその後ろへ**。
  静的タグは動的挿入に変えた——**静的な `<script src>` はフラグでは止められない**（パース時に飛ぶ）。
- **タグ本体・measurement id・#R155 の auth URL スクラブ・#R272 の「credential が URL に在るうちは
  挿入しない」規則は 1 行も消していない。** 戻すのは `true` に書き換える 1 か所だけ。
- `gtag()` / `clarity()` の **queue shim は門の外**に残した。呼ぶ側があっても落ちず、黙って配列に
  溜まる（実測: `js/` と `src/` に呼び出しは 0 件だが、shim を消す理由にはならない）。
- ⚠ **`window.__imScrubAuthUrl=_scrub;` も門の外。** 中に入れると、GA を止めた瞬間にその
  グローバルが消える。検査 ③ が順序で固定してある。

⚠⚠⚠ **そして `tests/r502-checks.test.mjs ④` がフラグとプライバシー本文を結んだ。**
`window.INTMAP_ANALYTICS` が `true` になった瞬間、`js/legal-text.js` に `Google Analytics` と
`Clarity` が無ければゲートが赤くなる。**計測を戻すことと、それを告知することが 1 つの動作になった。**
別々にできるあいだは、また離れる——今回離れていたのがその証拠である。

⚠ CSP のホスト（`www.googletagmanager.com` / `www.clarity.ms` ほか）は**残した**。停止であって
削除ではないので、許可を剥がすと「戻すのは 1 か所」が嘘になる。残存リスクとしての扱いは
`docs/SECURITY-ARCHITECTURE.md` §8 の 1 番（`'unsafe-inline'`/`'unsafe-eval'`）と同じ枠のまま。

### ③ 別件、同じ形——AI が書いた段落が、AI と名乗っていなかった

`js/news-events.js` の該当ブロックのコメントは、こう宣言していた:

> ⚠⚠⚠ **AI が書いたことを隠さない。** 1 文ごとに引用元の媒体を付け、下に**原文の断片**をそのまま置く。

ところが**画面に出る 9 言語の文字列は、1 つも `AI` と言っていなかった。**
出ていたのは `IntMap combined what these outlets published` /「上の段落は…IntMap がまとめたもの
である」で、これは `news_events.summary`——取り込みの `summarise` 段が**LLM に書かせ**、1 文ごとの
根拠が原文に在ることをサーバー側で照合してから保存する段落——についての表示である。

⚠⚠⚠ **隠すつもりが無いことは、隠れていないことの証拠にならない。**
#R488 と同じ形（規則は在り、綴りは在り、当たっていない）で、#R485 の
「見えていることと覆われていないことは別」と同じ根を持つ。

直したこと:

- 注記を 9 言語すべてで **AI / KI / ИИ / IA** を明示する文に差し替えた。
- **畳まれた `<details>`（各文の根拠になった原文）の下から、段落の直下へ移した。**
  要素は 1 つも足していない——`html +=` の順番だけを入れ替え、`.ev-syn .ev-d-note{margin:0}` で
  潰れる下余白を `.ev-syn .ev-ai` で戻した。
- ⚠ 位置引数は 5 つ（en/ja/de/ru/es）しかない。残る fr/ko/zh-Hans/zh-Hant は
  `js/locales/ui.*.js` の **inline table を英語キーで引く**ので、**英語だけ書き換えると 4 言語が
  静かに英語へ落ちる**（#R492 の教訓）。キーと訳文を同じコミットで差し替えてある。
- 検査 ⑤ が 9 言語すべての語を、⑥ が `<details>` より前に在ることを見る。

### やっていないこと（利用者の判断が要る／機能に干渉する）

報告には 8 件あり、上の 2 件以外は**範囲外として明示的に外した**。理由つきで残す:

| 指摘 | 実コードでの確認 | 外した理由 |
|---|---|---|
| OpenAI へ入出力を共有する設定が有効 | **本文が自ら `under a content-sharing arrangement we have enabled` と明言**（`js/legal-text.js`） | OpenAI 側のダッシュボード設定で、こちらから触れない。契約条件に関わる |
| ニュース本文の文単位再掲 | 事実（`gist` は「各媒体が公表した文をそのまま」と自ら表示） | **機能縮小**。§3 の 1 により承認が要る |
| CSP の `unsafe-inline`/`unsafe-eval` | 事実（`index.html` の `script-src`） | 外すとインライン起動コードが動かない。`docs/SECURITY-ARCHITECTURE.md` §8 で追跡済み |
| routing relay の費用上限 | 未検証 | 利用に干渉する |
| 法務文書に運営者名・連絡先が無い | 事実（「Contact us for help.」とあるが宛先が無い——`mailto:` 0 件、運営者名 0 件） | 書く内容が利用者の個人情報 |
| deep tier が赤 | 事実（nightly 2026-08-28） | 別ラウンド規模 |
| 事件地点の精度表示 | 未検証 | UI の追加 |
