## R672 — **扉は直したが、読者はまだ何も見ていなかった——3ラウンド続けて「機構の名前」を測っていた**

〈#R621 の production verification。凡例と us-epa は直っていたが、ポップアップは直っていなかった〉

### 1. ⚠⚠⚠ ポップアップは DOM に出ていて、画面には出ていなかった

#R621 は `GE().popup` という**存在しない扉**を `GE().ui.popup` + `GE().ui.attach` に直し、
**「その扉は実在するか」を測る検査**で緑にした。本番で起きたのはこうである:

- ポップアップは**生成され、挿入され、中身も正しい**
  （`Rotha / 134 nSv/h / 2026/9/10 6:00:00 · H*(10) / Bundesamt für Strahlenschutz (BfS), ODL-Messnetz · DL-DE/BY-2.0`）
- **実測の矩形は 20×16 px。** 閉じるボタンだけ。
- 原因は 1 行——根の要素が `<div class="rad-pop country-popup">` で、
  **`.country-popup{display:none}` は国情報パネルの隠しテンプレート**だった。誰もそれを表示に戻さない。

⚠ **他の機能の class を借りてはいけない。** 借りた先が「既定で隠れている」ことは、
その class の名前からは分からない。`.rad-pop` は自分の箱を持つようにした。

### 2. ⚠⚠ スパークラインは、返ってきた 168 点を 1 点も読めていなかった

`?mode=series` は provider の**記録そのもの**を返す（`radiation-feed/index.ts` の `series: r.records`）。
記録は `{code,name,lat,lon,nsvh,at,quantity,kind}` で、**値の鍵は `nsvh`**。
`v` は**最新値のワイヤ側だけ**の圧縮表現である（7,000 行ぶん払うので短くしてある）。

クライアントは `r.v` を読んでいた ⇒ 全行が null ⇒ `vs.length < 2` が常に真 ⇒ スロットに `''`。
**線も出ず、「履歴は公開されていません」の一文すら出ない。**
——エンドポイントは 168 点を返し続けていた。

### 3. ⚠⚠⚠ 3 ラウンド続けて、検査は「機構の名前」を測っていた

| ラウンド | 検査が測っていたもの | 読者が見たもの |
|---|---|---|
| #R585 | 文字列がソースに**書いてあるか** | 空の凡例 |
| #R621 | 扉が**実在するか** | 20×16 px の閉じるボタン |
| #R672 | ——**結果を測る** | |

⇒ この回の検査は**結果の側**を測る:

1. **出荷している stylesheet が `display:none` と宣言している class を数え上げ**、
   このレイヤーが書く `class="…"` にそれが 1 つも無いことを測る
   ——⚠ **コメントを剥がしてから解析する**。CSS の規則の選択子は直前の `}` から始まるので、
   上に載っているコメントを飲み込み、素の class 一致が発火しない。
   **最初の実行は「`.country-popup` は隠れていない」と報告した。それを隠している当の stylesheet の上で。**
2. **値の鍵を `_shared/radiation-sources.js` の記録ビルダから読み**、
   クライアントがその鍵を読んでいることを測る（手書きの fixture なら `v` を持たせて、
   間違ったクライアントと仲良く緑になれる）。

⚠ **本番で実際に壊れていた 2 つの形をそのまま戻す変異で、それぞれの検査が赤になることを確認した。**
