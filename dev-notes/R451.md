## R451 — **橋は在った。渡る道が無く、渡ろうとすると荷物が消えた**

**#R442 の本番計測で見つかった別件。** #R430 は Atlas に「いま読んでいる出来事」を渡す橋を架けた
——書き手（`js/news-events.js` `openDetail()`）、読み手（`js/atlas-console.js`
`_selectionState()`）、文（`js/atlas-state.js` の `OPEN NEWS ARTICLE` ブロック）の3つが揃って
いる。そのうえで、**通常のサイドバーではこの橋が一度も渡っていなかった。**

### 観測

本番 https://rwmqx7dwb5-arch.github.io/IntMap/ （build R441）で、News の出来事カードの
`.ev-sources` を押して詳細を開く。**800×450 / 1280×720 / 1920×1080 / 375×812 の4視野すべてで**:

- `body` に `im-reading` が付き、`.control-panel` が `display:none` になる
  ⇒ **News / Companies / Countries / Atlas のタブが全部 0×0**（`btn-community` の height=0）。
  読む面から出る操作は「‹ 戻る」だけ。
- 唯一の到達手段である `IntMapConsole.open()` は、通常モードでは `#btn-community` を押す
  ＝`setMode()` を通る。`setMode()` は読む面を離れ、`closeReaderPane()` は
  `window._imReader=null` を書く。

ローカル build（同じコード）で両端を測った:

| 操作 | `window._imReader` | `IntMapConsole.state()` |
|---|---|---|
| 出来事の詳細を開く | title あり・本文 235 字 | — |
| そこから Atlas を開く（通常・1280×800） | **null** | `OPEN NEWS ARTICLE` **行なし** |
| そこから Atlas を開く（通常・375×812） | **null** | 行なし |
| そこから Atlas を開く（**workspace mode**） | 生きている | 行あり |

⇒ **「いま読んでいるものについて Atlas に訊く」という操作そのものが、訊く対象を消していた。**
橋が渡っていたのは workspace mode だけである——そこでは Atlas が別ウィンドウなので
`open()` が早期 return し、`setMode()` を通らない。

### なぜ 15 ラウンド気付かれなかったか

**検査が、読み手と書き手を別々に確かめていたから。**
`tests/r430-checks` は「読み手がまだ `_imReader` を読む」ことと「生きた面がそれを書く」ことを
それぞれ主張する。どちらも真だった。**その2つを繋ぐ利用者の操作を、一度も走らせなかった。**
これは #R430 自身が #R80 について書いたこと——「`_imReader` を手で注入して読み手だけを確かめた」
——と同じ形で、1段上で繰り返されている。

### 直したもの（2つに分けた）

**① 道**。読む面の帯（`.nrp-bar`）が `.nrp-atlas`（「Ask Atlas」）を持つ。
⚠ **帯は #R435 で「同じ綴り」になっただけで、markup は3か所に残っていた**
（`js/article-reader.js` / `js/news-ui.js` `readerBar()` / `js/news-events.js` `openDetail()`）。
そこへ出口を1つ足すには**3回書き写す**しかなく、それは #R443 が測った「同じ語彙を面ごとに写すと
直るのは片方だけ」そのものである。⇒ 帯は `js/article-reader.js` の **`readerBar()` 1本**が組み、
他の2面は呼ぶ。押した先の入口も、**pane への委譲リスナー1本**（面は入ったあと innerHTML を
置き換えるので、要素に張ったリスナーは次の描画で捨てられる）。
⚠ **`IntMapAtlas`（遅延カーネル）が先で `IntMapConsole` は後**——実測 375×812 の初回では
`window.IntMapConsole` は undefined で `window.IntMapAtlas` だけが在る。逆にすると
「デスクトップでは通り、電話では落ちる道」になる。

**② 文脈**。`closeReaderPane(quiet, carryArticle)` が「**面を離れること**」と
「**Atlas の主題を捨てること**」を分ける。運ぶのは **`setMode()` が Atlas へ<b>入る</b>ときだけ**
（`mode==='atlas' && currentMode!==mode`）。Atlas に居て Atlas タブを押すのは**解除**＝離脱なので
捨てる。次のタブ操作が捨てる⇒**主題は、それを開いた会話のあいだだけ生きる。**

⚠⚠ **運ぶことと、黙って残すことは違う。** 運ばれた記事は `onScreen:false` を持ち、
`js/atlas-state.js` の文は「the user is reading this right now」ではなく
**「THE NEWS ARTICLE THE READER BROUGHT TO ATLAS (they had it open, then came here to ask about
it — it is no longer on screen)」**と名乗る（#R340 の produces-observed）。workspace mode では
記事窓と Atlas 窓が同時に在るので、そちらは今までどおり「いま読んでいる」。
代名詞の写像（この記事／この出来事／それ／詳しく・背景・なぜ）は**両方の文が同じように束ねる**。

### 取り上げていないもの

`.control-panel` を読んでいる間も出す、という選択肢は**取らなかった**。#R435 が「一覧の外皮を
伏せて1つの読む面にする」と決めた面であり、詳細画面は iOS の push 詳細ビューである。
⇒ タブ列を戻すのではなく、**その面自身が trailing edge に自分の行き先を持つ**。
CONSTITUTION §5（Atlas から取り上げない）はこれで満たされる——Atlas は増えても減ってもいない。

### 追記 — 本番検証が言ったこと、そして数字の単位が違っていたこと

本番（build **R450**、deployment sha `a940a98`）で実測:

- ビルド印は `window.__imBuild='R450'` / `window.INTMAP_BUILD='2026-08-25-R450'`、コンソール **error 0 件**
- **fr / ko / zh-Hant / zh-Hans の4言語すべてで、英語に落ちた文字列は 1 つも観測されなかった**
  ——レイヤー名 328 件・レイヤー群見出し 37 件・設定ダイアログ 56 件のいずれも英語一致 0 件。
  タブは «Actualités / 뉴스 / 新聞 / 新闻»、`<title>` と `html[lang]` も各言語
- 火山の凡例は «Volcans (Smithsonian GVP)» / «화산 (스미소니언 GVP)» / «火山（史密森尼 GVP）» で生きており、
  **消した旧綴り 2 つは配信物から完全に消えている**（`main.js` と4 chunk すべてで `GVP Holocene` 0 件・`1,215` 0 件）

⚠⚠ **そして、このラウンドが記録した削減サイズは単位が違っていた。** `readFileSync().length` は
**UTF-16 の文字数**であってバイト数ではない。上の①②を実測値に直した。
**「測った」と書くときは、何を測ったのかまで書く**——kB と書いた瞬間に、読む側はバイトだと読む。

⚠ **本番では before/after を測れない。** Pages は再デプロイで旧ハッシュの資産を消すので、
削除前の chunk は取得できない。前の値はソース（`a940a98~1`）から測ったもので、本番の数字ではない。

⚠ 本番検証は、このラウンドの範囲外の英語落ちを 2 種類見つけた（どちらも R450 が触っていないファイル）:
`js/map-ui.js:674,706` と `js/layer-favs.js:68` のハードコードされた `title`（⚠ #R240 の第6面
`i18n-attr-audit.mjs` が 0 と言い続けている＝**JS から代入される属性を見ていない**）と、
言語切替直後だけ英語で出る国名一覧（⚠ 訳は `"United States": "États-Unis"` として**存在し**、
読み手も `LNS.arr(f.name)` で正しい＝#R428 と同じ「`intmap-lang` を聞かない UI」の形）。
どちらも別ラウンドへ送った。

### 検査

  先に見る ③離脱と主題の破棄が別の決定である ④**`setMode`→`closeReaderPane` を実際に実行**して
  主題の寿命を測る ⑤運ばれた記事を「読んでいる」とは言わない。
  **修正前のソースに対して5本とも赤**。
- `tests/r435.spec.js` ④（本物のブラウザ）。タブ列が 0×0 であること・道が視野の中に在り
  素の `<button>` ではないこと・押すと Atlas に着いて `_imReader` が `onScreen:false` で生き、
  `IntMapConsole.state()` がその見出しを読めること・タブを離れると消えること。
  ⚠ **新しい spec ファイルは足していない**——同じ面・同じ試料・同じ起動なので、
  `scripts/test-budget.mjs` の言う「積み増しではなく統合」に従って #R435 の spec に入れた。
  実測 **4.259 s → 5.534 s**（限界 1.275 s）、計上 5→7、総計 4,618→**4,620**。
- ラベルは `js/tool-panel.js` の地図メニューと**同じ英語鍵**（「Ask Atlas」）なので、9言語の訳は
  既に `js/locales/ui.{fr,ko,zh,zh-hans}.js` に在る（実測: `Demander à Atlas` / `Atlas에게 묻기` /
  `詢問 Atlas` / `询问 Atlas`）。新しい訳語は1つも要らなかった。
