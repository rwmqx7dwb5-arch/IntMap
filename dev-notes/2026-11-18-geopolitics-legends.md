〈依頼〉本番検証（build 1be2049）で不合格だった 6 点を根本で直す。push 前に 1440×900・1152×720・375×812 を実際に見る。

## 0. 測った（本番 2026-11-18、指摘のとおり）

3 枚の凡例が同じ位置（x424, y0）に重なり、WGI の凡例とも 28〜74 px 重なる／1152×720 で国連総会の凡例が 1,031 px（下 335 px が切れる）／
凡例が地図の検索ボタンの上に乗る／凡例内リンクが既定の #0000ee／国連総会で国をタップすると一般の国カード／制裁の吹き出しに出典がない。

## 1. 直したもの（原因ごと）

- **凡例の積みが自前の凡例を知らなかった**（1〜3 の原因）。`js/data-layers.js` の `placeLegends` は、凡例を**手で並べた一覧**からしか
  見つけていなかった。一覧にない凡例（波・土地被覆・地政学 3 枚）は積みに入らず、自分の CSS の位置に残っていた。
  ⇒ `discoverLegends` の同じ行で、一覧の順を保ったまま `#map-container` 内の `.data-legend` / `.koppen-legend` を
  **種類で**拾う。これで積みの既存の規則（重ならない・枠に収まる・高すぎれば折りたたむ／スクロール・操作類を避けた原点）がそのまま効く。
  波と土地被覆の凡例も同じ欠陥を持っていて、同時に直る。
- **リンク色**: `.data-legend a` / `.koppen-legend a` をアクセント色（`--primary-color`）に。
- **国連総会の国タップ**: `gp-unv-fill` にクリックを登録し、その国のその決議への投票（記号・日付・題名・総数・出典）を吹き出しで出す。
  `claimClick` で一般の国カードに譲らせる。
- **制裁の吹き出しの出典**: 表示中のリストの発行元とライセンスをカードの末尾に。
- **吹き出しが地図の下へはみ出す**（確かめる途中で見つけた）: Iran の制裁カードは 520 px あり、900 px の地図の中ほどの点から下に開くと
  出典の行ごと枠外に出た。点から見て片側には必ず地図の半分以上があるので、カードを viewport の 46% までにしてスクロールさせる
  （MapLibre の自動の向きが常に収まる側を選べる）。
- **ある行の消灯が別の行の吹き出しを閉じていた**（確かめる途中で見つけた）: パッケージの吹き出しが 1 つの変数で、どの行の `off` も
  それを閉じていた。実測: 国連総会の吹き出しが開いた直後に、遅れて届いた別の行の `off` が消していた（`Element.remove` の呼び出し履歴で
  `layer-pkg-geopolitics off → closePopup`）。⇒ 吹き出しは開いた行のもので、行は自分の吹き出しだけを閉じる。

## 2. 確かめたこと

`tests/geopolitics-layers.spec.js` の 2 件目（ビルド済みのサイト・実ブラウザ）が 3 つの幅それぞれで、表示中の凡例どうしが重ならない・
地図の枠に収まる（はみ出すならスクロールできる）・検索ボタンの中心がボタン自身・凡例のリンクが既定色でないことを測る。
1 件目は、国のタップでその国の投票が出ること、制裁の吹き出しにリストとライセンスが出て枠に収まることを測る。
撮った 3 幅の画面は自分で見た（1152×720 では積みが 2 枚を見出しだけに折りたたみ、375×812 では凡例は「凡例」のトレイに入る）。

## 3. テスト時間の払い方

全体の天井（5,250 s）にちょうど達していたので、天井は動かさずに払った。

- 新しい確かめ（3 幅の積み・国タップ・制裁カードの出典）は別ファイルにせず `tests/geopolitics-layers.spec.js` にまとめた（起動 1 回・層の点灯を共有）。
  1 worker・3 回の実測 12.9 / 13.1 / 13.3 s、最も遅い値で 14 s と記入（10 s から +4 s）。
- `tests/r384-legend.spec.js` を測り直した: 9.0 / 8.1 / 7.4 s（記入は 55 s）。同じ run で `tests/r143.spec.js` が 2.8 s（記入 9 ＝ ×3.21）、
  `tests/r753-account-menu.spec.js` が 1.4 s（記入 2 ＝ ×1.43）だったので、大きいほうの較正で上限 9.0 × 3.21 = 28.9 → 29 s と記入（−26 s）。
  この変更で凡例の積みが拾うカードが増えたあとの測定で、その spec は全件緑。
