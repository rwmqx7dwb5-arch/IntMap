## R393 — **後から作られた行は、現在の値を持って現れる**

#R380（1850 までの拡張の全数監査）の**本番検証**が見つけた。本番の Countries タブを 1860 年で開くと、
見出しは「1860 · real GDP (2011 int$)」なのに一覧はこうだった:

```
1 🇸🇬 Singapore  $501B      ← 今日のシンガポール
2    Russian Empire $435B
3 🇭🇰 Hong Kong  $382B      ← 今日の香港
4    British Raj $300B
5 🇬🇧 United Kingdom of Great Britain and Ireland $147B
```

### 原因は深い時代の仕事ではなかった

`js/countries-ui.js` は国の属性表を**2回に分けて**読む（#R195）。起動時は Natural Earth **110 m**
（177 コード）から作り、**ブラウザが暇になってから** **10 m**（252 コード）へ差し替える。
#R375 は、その2回目が**粗いファイルに無い 75 コードの行を作らない**ために「幾何は答えるのに表が
知らない」コードが 75 件あったことを直した——シンガポールと香港はまさにその 75 件である。

その直しは正しい。ただし**そのパスは起動の 3〜15 秒後に走る**（`requestIdleCallback` / 3 秒 /
携帯と Data Saver では 15 秒）。つまり**時計がすでに過去へ旅していれば、ファイルそのままの
「現在の人口と GDP」を持った行が、過去の年の下に現れる**。

### なぜ 1960 年より前だけ、直らないまま残るのか

`js/time-countries.js` の重ね合わせは2段になっている:

```
phase 1  restore(); overlay(y, 空のWB); repaint();          ← Maddison だけ・ローカル・即時
phase 2  data = (y>=1960) ? await fetchYear(y) : null;
         if(data){ overlay(y, data); repaint(); }            ← 世界銀行が届いてから
```

**1960 年以上なら phase 2 が数秒後にもう一度上書きするので、たまたま直る。**
`y < 1960` では `data` は `null` で、**phase 2 が存在しない**。だから 1850–1959 のどの年でも、
遅れて現れた行は**永遠に現在のまま**になる。1960 年より下は #R349 が開いた範囲を丸ごと含む。

### 直し方——行を作った側が、画面の年へ引き込む

`js/time-countries.js` に `reapply()` を足した。画面に出ている年をもう一度重ね合わせるだけで、
**時計が現在なら `false` を返す**ので呼び出し側は年を知らなくてよい。世界銀行の値はその年に
一度でも取れていれば `yearCache` にあり、1960 年より下では**構造上ひとつも無い**——つまり
「直す機会が二度と来ない」範囲でこそ、この呼び出しが唯一の機会になる。

呼ぶのは行を作った当人（`js/countries-ui.js` の `upgrade`）で、**行を作ったときだけ**
（`if(added)`）。既存行の enrich（面積・人口密度・bbox）は年に依存しないので呼ばない。

### ⚠ そして、それだけでは半分だった

`snapshotBase()` は `if(base) return;` ——**一度きり**だった。スナップショットは「現在へ戻す」ための
控えなので、**行が現れる前に取られた控えにはその行が無い**。引き込むだけ直すと、今度は
**現在に戻したときにその行だけ空になる**（実測: 検査①の後半が赤くなる）。
⇒ **追加式**にした。コードごとに**初めて見たとき**に控えを取り、すでに控えのあるコードは
二度と取り直さない（取り直すと、重ね合わせ済みの値を「現在」として控えてしまう）。

### 検証

`tests/r393-checks.test.mjs`（3本・`test:checks` に登録）。⚠ **出荷モジュールを走らせる**——
`js/time-countries.js` は本物の ES module なので、スタブの `window` と2行の表を渡して実際に
1860 へ旅させ、**アップグレードと同じやり方で行を足し**、読み手が見るものを訊く。

| 検査 | 何を訊くか | 赤にできるか（実測） |
|---|---|---|
| ① | 遅れて現れた行が、その年の値になる／現在へ戻すと現在に戻る | 追加式スナップショットを戻す→後半が赤／`reapply` の輸出を外す→赤 |
| ② | 時計が現在のとき `reapply()` は `false` を返し、何も触らない | 輸出を外す→赤 |
| ③ | 行を作った側が実際に呼んでいる（`codeOnly` で散文を除いて読む） | 呼び出しを外す→赤 |

ブラウザでの実測（本番の再現手順そのまま——読み込み→1860→Countries タブ→細かいファイルが
着くまで待つ）: 修正後は **1 ロシア帝国 $435B / 2 英領インド $300B / 3 イギリス $147B /
4 アメリカ $140B / 5 フランス第二帝政 $112B / 6 オーストリア帝国 $105B**——
シンガポールも香港も居ない。
