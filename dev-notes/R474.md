## R474 — **markup が星を1つ出している見出しに、3言語の訳がもう1つ星を持っていた**

#R466 の production verification 中に見つかった、そのラウンドとは無関係の欠陥。

### 1. 何が出ていたか

本番（`https://rwmqx7dwb5-arch.github.io/IntMap/`・build R466/R467）のレイヤー欄で、
「お気に入り」の見出しが **ru / es / de の3言語だけ星が二重**だった。ライブ DOM から読んだ値:

```
#layer-fav-section > .layer-fav-title  →  "⭐ ★ Favoriten"
```

| 言語 | 見出し | | 言語 | 見出し |
|---|---|---|---|---|
| ru | `⭐ ★ Избранное` | | en | `⭐ Favorite layers` |
| es | `⭐ ★ Favoritos` | | ja | `⭐ お気に入りレイヤー` |
| de | `⭐ ★ Favoriten` | | zh-Hans | `⭐ 常用图层` |

**描画の不具合ではない。** 星を出しているのは `index.html` の

```html
<div class="layer-fav-title">⭐ <span data-i18n="favLayers">Favorite layers</span></div>
```

で、`js/locales/ui.{de,es,ru}.js` の `favLayers` が **`"★ Favoriten"` のように自前の星をもう1つ**
持っていた。9言語中6言語は最初から正しく、**3行のデータ**が違っていただけである。

### 2. なぜ、どの計器も緑だったのか

**理由は2つあり、どちらも「その計器が何を測っているか」の話である。**

⚠⚠⚠ **① 2つの星は同じ文字ではない。**

```
markup   ⭐  U+2B50  WHITE MEDIUM STAR
locale   ★  U+2605  BLACK STAR
```

だから「訳が markup の文字を繰り返していないか」を問う比較は、**出荷されたバイトに対して緑になる。**
読み手には星が2つ見えていて、計器には別々の文字が見えていた。

⚠⚠⚠ **② `scripts/i18n-*.mjs` はどれも「訳されているか」を測る計器である。**
`"★ Избранное"` は**正しいロシア語訳**なので、被覆の面から見て欠けは1つも無い。
**壊れていたのは言葉ではなく、訳が装飾を持っていたこと**で、その装飾は markup のものだった
——`favLayers` はこの1か所でしか使われていない。

### 3. 直したもの

`js/locales/ui.{de,es,ru}.js` の `favLayers` から **`★ ` の2文字だけ**を削った。

```
de  "★ Favoriten"  →  "Favoriten"
es  "★ Favoritos"  →  "Favoritos"
ru  "★ Избранное"  →  "Избранное"
```

**訳語は1文字も変えていない。** `js/locales/ui.zh-hans.js` は生成物だが、そこの `favLayers` は
`"常用图层"` で星を持っていないので、再生成は要らなかった。

⚠ 全 keyed 表（420鍵 × 9言語）を走査した実測: **英語が持たない装飾を訳が持っている行は、
この3行しか無かった**（修正後は 0）。

### 4. 門 — 比較ではなく「ゼロの天井」

`tests/r474-checks.test.mjs`（`npm run test:checks` ＝ **毎 push 走る**）が置く規則:

> **markup が `data-i18n` の隣に装飾を出しているなら、その鍵はどの言語でも装飾を1つも持ってはならない。**

⚠⚠ **「同じ文字を繰り返していないこと」ではない**——それが緑になったのが今回の原因だから。
装飾を**1つも許さない**なら、どの星でも、どの絵文字でも、比較を経由せずに捕まる。

⚠⚠ **宇宙は markup から導出する。ここに一覧を書かない。** 今日の該当は6鍵——
🌐 `aiTranslateTitles` / 📐 `measureMenuBtn` / 📷 `mScreenshot` / 🔗 `shareLinkBtn` /
⭐ `favLayers` / 🖼 `commAddImage`——で、7本目の装飾つき見出しは**誰も一覧に足さなくても**
その日から守られる。装飾は「翻訳される span の隣の text node」に居るので、そこを読む。

⚠⚠ **検査が発火することを証明できる形にした**（#R465 の形）:
③ が**出荷された3つの文字列そのもの**を検出器に通し、④ が `⭐ ≠ ★` を名指して
「なぜ規則が『同じ文字か』ではないのか」をテスト自身に持たせている。

### 5. 読み手の側 — spec を新設せず、#R251 の掃引に相乗りさせた

9言語ぶん**画面の文字を数える**ほうは `tests/r251-langs.spec.js` の **③** として入った。
お気に入りを1つ付け、①の掃引が言語を切り替えたその状態で見出しを読み、星を数える。

⚠⚠ **単独の spec として書いたら 10.9 秒だった。** 内訳は9回の言語切替が1回あたり約1.1秒で、
**切替そのものが費用**（locale の先読みをしても変わらなかった）。core の天井は 30 秒ちょうどで
空きは約5秒しか無い（`scripts/test-budget.mjs`）。そして `tests/r251-langs.spec.js` は
**すでに起動済みのアプリで全言語を切り替えている**——この主張に必要なものが全部そこに在った。
#R451 と同じ判断で相乗りにした結果、**実測の増分は約 0.5 秒**（星を1つ付ける 0.38 秒＋
9回の `textContent` 読み出し）。天井は測った分だけ動かした（4,629 → 4,630、entry 66 → 67）。

⚠ **代償も書いておく**: `tests/r251-langs.spec.js` は deep tier なので、この ③ は
**merge を止めない**（nightly・dispatch・`npm run test:deep` で走る）。毎 push を守るのは
§4 の node 検査のほうで、**この欠陥がこの形で戻る経路はそちらが塞いでいる**。

⚠ **「位置」ではなく「文字」で測る。** `#layer-fav-section` の親 `#layer-dropdown` は
**#R296 以降デスクトップで `display:none`**（クラシック dropdown は右サイドバーに一本化された）
なので、この見出しに**レイアウト箱があることを条件にすると、星ではなく容器の配線を主張する検査**
になる。代わりに、この要素自身の規則が効いていること——お気に入りが1つ付いたら `.has-favs` が
付いて自分の `display` が `block` になること——を確かめ、9言語ぶんは文字を読む。

⚠ **`IntMapLang.keyed(code)` は英語を prototype に持つ**（`js/lang-registry.js`）。
行を持たない言語ではこの比較が「英語と英語」になって何も主張しないので、
`_ui[code]` の**その言語自身の行**とも突き合わせる。

⚠ 主張は「星がちょうど1つ」であって「★ が無い」ではない。**markup が星を落とした場合（0個）も
落ちる。** 見出しの星は「在って1つ」が仕様である。

### 6. 途中で一度、アプリが文字を落としているように見えた——原因は自分の正規表現だった

⚠⚠ 相乗りの1回目の実行が `es: "⭐ Favorito"`（`own` は `"Favoritos"`）と
`fr: "⭐ Calque  favori"`（`own` は `"Calques favoris"`）で赤くなった。
**s だけが空白に化けていて、s を含まない7言語は無症状**——いかにもアプリ側の欠陥に見える形である。

原因は挿入コードのほうだった。`node -e "…"` を bash の二重引用符で括ったため
`/\\s+/` が `/\s+/` になり、それが JS の文字列リテラルの中で **`/s+/`**——
**文字の `s` にマッチする正規表現**——に潰れて、`textContent` の `s` を空白へ置換していた。

⚠ MutationObserver を張って本番の画面走査を再現し、**書き換えている者が居ない**ことを先に
確かめたので、容疑者が自分に戻ってきた。
⇒ **正規表現を含む差し込みをシェル経由で書かない。** `.txt` に書いて `readFileSync` で読むか、
編集ツールで直接書く（既知の罠。#R458 / #R460 が同じ形を記録している）。

### 8. 直していないこと

⚠ **この見出しに到達できる経路が狭いこと自体は、このラウンドの主題ではない。**
`#layer-dropdown` はデスクトップで `display:none`（#R296）、電話では `body.m-lyr-tiles` が
`#layer-fav-section` を `display:none !important` にする（#R236）ので、この見出しが実際に
画面へ出るのは**その中間の状態**である。依頼は「星が二重である」ことなので、そこは変えていない。
