〈依頼〉歴史地図にある「粗い直線的な国境・境界」を、歴史的事実をもとに IntMap 独自に高精度化する。幾何学的・歴史的な精度は
妥協しない（根拠の無い区間を精密に見せない・線でなかった境界を線にしない）。性能は落とさない。外部への書き込みは相談。
並行セッション（歴史地図のカバレッジ拡張）からの追加条件: 精密な線を改悪しない／区間単位・出典付き・取り外せる上書き／
省略・平滑化・補完をしない／確定できる事実は確定して描く。

## 0. 測った——粗いのはどこか

描かれる国境（`data/border-coast.js` の run）のうち、25 km を超え、子午線にも緯線にも沿わない辺の長さの割合:

| 年 | 全体 | 記録ごと |
|---|---|---|
| −1000 | 85.3% | Cliopatria 76% / 枚 86% |
| 500 | 81.0% | Cliopatria 77% / 枚 83% |
| 1500 | 77.3% | Cliopatria 70% / 枚 83% |
| 1750 | 42.9% | OHM 22% / Cliopatria 64% / 枚 63% |
| 1900 | 21.6% | CShapes 19% / OHM 遅い記録 65% / Cliopatria 74% |
| 2000 | 14.2% | CShapes 14% |

CShapes と OHM の長い辺の多くは本当に直線の国境（北緯 49 度線・東経 129 度線・サハラの条約線）。粗いのは Cliopatria と枚で、
1689 年より前は線の 4 分の 3 が弦。

- **Cliopatria の頂点は近代の線をなぞっていない**: CShapes の線から 50 m 以内の頂点は 0.6%（同じ頂点を無作為にずらすと 0.3%）。
  手描きなので、「近代の線に吸着させる」は根拠にならない。
- **Cliopatria の位置誤差**（精密な記録と同じ日付で比べ、海岸から 30 km 以上内陸の頂点）: 中央値 4.1〜6.0 km、75 パーセンタイル
  1750 年 18.1・1800 年 18.5・1850 年 13.5・1900 年 10.0・1950 年 7.0 km（`--measure`）。
- **川に沿う割合は対照とほぼ同じ**（川から 5 km 以内: Cliopatria 7.3〜12.6%、ずらした対照 6.5〜11.4%）。粗い記録が川を
  なぞっているわけではない——川に沿っていたことは、記録ではなく史料に訊くしかない。

## 1. 作った: 史料が述べる区間だけを引き直す（`data/hist-courses.js`）

- **事実** `scripts/histcourse/courses.json`: 区間（地物上の 2 点）・期間（その地物が境界だった期間。政体の存続期間ではない）・
  政体の QID・開いて確かめた出典 2 本以上・例外（対岸の橋頭堡）。描かないもの（否定・未確定・現代の線では置けない）も
  `notDrawn` に研究の判定と理由つきで 100 件残した。
- **形**は OpenStreetMap の川の `main_stream`・城壁の頂点そのもの（簡略化も丸めもしない・ODbL 1.0・出典行を `js/reference-data.js` に足し、
  `imtb-ln-src` の帰属表示にも足した）。関係のメンバーから漏れた同じ川の way（ドニエストル川の Novodnistrovsk ダムの 1.6 km）は、
  関係の英語名で同じ川の way を訊いて補う。城壁は「区間のあいだの隙間 ≤ 0.4 km を直線でつなぐ」ことだけを許し、つないだ箇所を
  出荷物に書く（ハドリアヌスの長城: 7 か所、最大 0.359 km、渡河点）。
- **差し替える辺**（`scripts/build-hist-courses.mjs`）: 事実の期間に描かれる Cliopatria の行の QID がその事実の政体である環の、
  描かれる run の中で、すべての頂点と 1 km ごとの辺上の点が地物から 13.5 km（上の 75 パーセンタイルの中央値）以内にあり、
  地物への射影が一方向に進み、地物の上で 13.5 km 以上を覆う範囲。上位の記録（CShapes・OHM・遅い OHM）の線上の頂点
  （Cliopatria が切られた辺）は動かさず、例外地点の手前まで地物に沿って止まる。各頂点は自分の射影に最も近い地物の頂点に置く。
- **事実の期間の間だけ効く**: 環は時代をまたいで共有される（Cliopatria の行の境と事実の期間の境はめったに一致しない）。
  初版は「環を使う行の期間が丸ごと事実の期間に入ること」を求め、ほとんどの区間で何も動かなかった（隣の環の 1 年のずれ——
  «Gothia» 270–308 対 ローマの撤退 271——で全部落ちる）。そこで差し替えに事実の期間を持たせ、読み手が時計の日付で絞る
  （`js/border-coast.js` `courseEpoch`・`js/time-borders.js` の線のメモと合成のキーを「事実の期間の境」ごとに分けた）。
- **1 つの境界は 1 本の線**: 同じ 2 頂点の辺を描く環（Cliopatria の隣国と、Cliopatria に沿って切られた年別の枚）には同じ頂点で
  差し替えを運ぶ。実測（初版を地図で見た）: 300 年のローマ帝国の環と «Gothia» の環が鉄門の弦を共有し、ローマ側だけを差し替えた
  ので川と弦が並んで描かれた。運べない組み合わせが残れば両方とも元の線に戻す（今回はゼロ）。
- **読み手**: `js/border-coast.js` の `ringLines` が印の run の中の範囲を地物の頂点で置き換える（`spliceRun`）。線だけが変わり、
  塗り・クリック・名前・日付は元の記録のまま。両側の政体が差し替えられるところは同じ頂点を通るので継ぎ目に段差が出ない。
  ファイルが無ければ従来どおり（取り外せる）。`js/boot-stage.js` に `phone:'need'`（Cliopatria の線を初めて描くときに読む・0.33 MB）。

ニーダーラーンシュタイン、カイザーアウクスト対岸、ミーニョ河口とグアディアナ河口（中洲・砂州の帰属が後代）。

**描かなかったもの**（`notDrawn` の主な理由）:
- **帯であって線ではない**: 明＝朝鮮の鴨緑江下流（緩衝地帯と係争中の中洲）、豆満江（六鎮の外に住む藩胡）、マムルーク＝イル・ハン朝の
  ユーフラテス、オスマン＝ハプスブルクのドナウ（要塞の帯）、アヴァール・フン、ムーズ川（「線の束」）。
- **河道が当時から 1 km 以上動いた・現代の線では置けない**: ライン川上流平野（トゥッラ以前の網状河道）・下流（3 km の蛇行帯）・
  デルタ（ローマ期の国境はオウデ・レイン経由だが残る水路が当時の河道と示す出典が無い）、ドナウのシュトラウビング盆地・ウィーン・
  シゲトケズ・ゲメンツ・バルタ・デルタ、ドニエプル（ダム湖に沈んだ網状河道）、アラス（ダム湖とそこで引き直された直線）、
  アルグン（OSM の主流が 3 か所 1.3〜5.4 km 途切れ、1911 年条約自身が河道の相違を記す）、ローヌ上流（1410 年の河道変化の判例）。
- **出典が足りない**: ナルヴァ川（学術書 1 本のみ。第 2 の出典を開けていない）、レイタ川（条約自身が「川と一致するところだけ」）、
  タヤ川、ストゥレジ川（左岸のラホール領の位置不明）、スヘルデ川・ソーヌ川。
- **OSM が線として持っていない**: アントニヌスの長城、上ゲルマニア＝ラエティア・リーメス（遺跡範囲としてだけある）。

## 2. 作った: 海岸線の写しの帯を記録ごとに測る（`scripts/build-border-coast.mjs`）

`INLAND_KM = 6` は CShapes と OHM で測った値で、自身の失効条件に「帯は記録の海岸の位置誤差より上でなければならない」とある。
手描きの Cliopatria にも同じ 6 km が当たっていて、日本・バリ・マン島などの粗い海岸線が国境として描かれていた。
同じ二つ目の測り方を記録ごとに走らせる `--sweep <global> <年>` を足した。

- **Cliopatria**（17 年）: 描かれる長さは 6→8→10 km で 2 km あたり 7〜10 千 km ずつ減り（西暦 0 年: 110,548 → 103,180 → 96,018）、
  そこから緩む（12 km 91,875・15 km 90,138・20 km 89,440）。10 km までに沈黙するのは島か記録の誤差より小さい沿岸の断片だけ
  （鎌倉・室町幕府、バリ、マン島、中山・南山、黒海沿岸のフン帝国の残片 2 環 8 点、1612〜1689 年のマギンダナオの断片 0.2°、
  イギリス植民帝国の拠点）。12 km でアマルフィ共和国と仏領インド（陸の国境を持つ）が消える。⇒ **10 km**。
- **年別の枚**（紀元前 3000 年からの全枚）: 8 km ですでに 1492 年の枚の陸の隣人を持つ沿岸の民（アコマック・ナウセット・
  クロアタン・ルミ…）が消える ⇒ **6 km のまま**。
- `RECORD_INLAND_KM = { __HISTCLIO: 10 }`。印の各セットが自分の帯を名乗り（6 km 以外のとき `inlandKm`）、`--check` は各束を
  その束の帯で再導出する。

|---|---|---|---|
| 0 | 110,673 → 96,126 | 82,147 → 72,229 | 0 |
| 100 | 112,626 → 98,087 | 83,232 → 73,422 | 152 |
| 300 | 109,325 → 94,300 | 83,134 → 72,823 | 452 |
| 1000 | 205,930 → 187,429 | 151,524 → 139,076 | 0 |

| 1600 | 269,781 → 247,708 | 193,027 → 177,363 | 1,103 |

**正直に書く**: 史料で確定できた区間が置き換えたのは Cliopatria の粗い弦のごく一部（1500 年で 0.8%）。前近代の国境の大半は
帯であって線ではなく、線だった区間でも河道が当時から動いていれば描けない——それを描かないのはこの作業の規則そのものである。
弦の量を大きく減らしたのは海岸線の写しの帯（各年 7〜12%）。

## 4. 測ったが、この PR ではしていない

- **OHM の 1689 年より前の関係を Cliopatria の上に置く**: 索引の 1,372 関係（1,367 に形）。粗い辺の割合は全体 15.3%
  （Cliopatria 74%）。ただし関係自身が「境界線の出典が要る」（`fixme:s`）と述べるものが 302、出典タグの無いものが 672。
  出典を持つ関係が面で覆うのは 500 年 4.5・800 年 11.2・1000 年 10.1・1500 年 5.5・1650 年 7.4 Mkm²、粗い辺 9〜25%。
  1689 年の床は「帯で 1 記録を選ぶ」頃の世界判定で、合成になった今はその理由が無い。別の作業として扱う（最終報告で提案）。

## 5. 検査

- `npm run check:bordercoast` が `scripts/build-hist-courses.mjs --check` も走らせる: 事実の形式・出典 2 本・期間・QID・例外、
  出荷された区間の線が事実の両端から始まり終わること、束・印・上位の記録の sha256、差し替えの完全な再導出。
- `tests/hist-border-refine-checks.test.mjs`（新設・11 本）: 誤差内の弦が地物の頂点で置き換わる（補間なし）／誤差の外・辺の途中で
  離れる弦・誤差より短い区間は動かない／上位の記録の線上の頂点と例外は動かない／描かれない run は差し替えない／読み手が
  run に差し込み、両側が同じ頂点を共有し、ファイルが無ければ元どおり／地物の経路は自身の頂点だけを通る／事実の要件／
  Cliopatria と、それに沿って切られた枚以外は差し替えない／同じ辺を描く隣の環が同じ地物の頂点を描く／事実の期間外と日付の無いときは元の線／出荷物の再導出。
