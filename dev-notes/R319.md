## R319 — **簡体字の読者に台湾表記が出ていた。字体の変換器は、語彙を変換しない**

> 「簡体字ロケール `js/locales/ui.zh-hans.js` は `js/locales/ui.zh.js`（繁体）から
> `scripts/zh-hans.mjs` が生成しています。その `WORDS` 変換表に 2 語が抜けていて、
> 簡体字の読者に**台湾表記**が出ています。」

### 症状——生成物の中に、生成器が知らない語が2つ

| 出ていた語（簡体字ファイル） | 大陸標準 | 件数 |
|---|---|---|
| `纽西兰` | **新西兰** | `ui.zh-hans.js` **6件** ＋ `pages.zh-hans.js` **1件** |
| `玻里尼西亚` | **波利尼西亚** | `ui.zh-hans.js` **2件** |

出ていた場所は**地域名だけではない**。`"Australia & New Zealand"`（#R313 追記2 が Atlas の
チップに出荷した22の地域名の1つ）・`"Polynesia"`・`"French Polynesia"` に加えて、
**警報レイヤーの説明文4か所**（「俄罗斯、印度、纽西兰、马来西亚、印尼、南非与墨西哥…」）と、
sources ページの MetService の行に出ていた。つまりこの欠落は **#R313 追記2 より前からあり、
そのラウンドが1文字も触っていない文にも出ていた**。

### 原因——#R251 が字体を OpenCC に渡したとき、語彙は渡していない（そして渡してはいけない）

`scripts/zh-hans.mjs` は2層でできている。

1. **`WORDS`** — この企画が1語ずつ選んだ**台湾語→大陸語**の表。**繁体のテキストに**、長いものから当てる。
2. **OpenCC `tw → cn`** — **字体**（正字→簡体字）だけ。

#R251 の注記が明記しているとおり、②は **`twp` ではない**。`twp` は語彙も変換するので、①が
`檔案 → 文件` と正しく直した語を OpenCC が台湾語と読み、`文件 → 文档` に上書きしてしまう
（実測され、`tests/r224 ④` が捕まえた）。**一方が語彙を持ち、他方が字体を持つ**——この分離は正しい。

その帰結が今回の穴である。**`tw` は字体しか変換しないので、外名（exonym）は `WORDS` に
書かない限り台湾表記のまま通り抜ける。** しかも `紐西蘭` の3文字はどれも字体変換の対象で、
`紐→纽`・`蘭→兰` はきちんと起きる。だから出てくるのは**「簡体字で書かれた台湾語」**＝`纽西兰` で、
**字体を見る検査には完全に正しく見える**。`玻里尼西亞 → 玻里尼西亚` も同じ形。

⚠ **`WORDS` には地名が1件も無かった。** 表の区分は `/* computing & UI */` と `/* map & science */`
の2つだけで、後者も `圖磚`・`圖資`・`公尺`・`太空人` のような**普通名詞**しか持っていない。
**固有名詞という区分がそもそも存在しないので、この種の語は増えるたびに黙って通る。**

### 直したこと

`WORDS` に `/* place names */` の区分を作り、2語を足した。**右辺は表の約束どおり繁体で書く**
（字体は後段の OpenCC が当てる。ここは語彙だけを述べる場所である）。

```js
  /* place names */
  ['玻里尼西亞', '波利尼西亞'], ['紐西蘭', '新西蘭'],
```

`node scripts/zh-hans.mjs` で再生成。**変わったのは9行だけ**で、その9行が
**この2語の置換以外の差分をまったく含まないことを、行の目視ではなく等式で確かめた**——

```
旧.replaceAll('纽西兰','新西兰').replaceAll('玻里尼西亚','波利尼西亚')  ===  新
  js/locales/ui.zh-hans.js     true   (8行 / 302,214 文字で前後不変)
  js/locales/pages.zh-hans.js  true   (1行 /  53,494 文字で前後不変)
```

置換した語はどちらも文字数が同じなので、**長さが変わっていないこと自体は証拠にならない**。
証拠は上の等式のほうで、これは「意図しない語が置換されていない」を**全文について**述べている。

⚠ **`pages.zh-hans.js` も同じスクリプトの生成物で、こちらの差分はゼロではなかった。**
sources ページの MetService の行に `纽西兰` が1件あり、**同じ種類の修正なので残した**
（差分がゼロなら戻す約束だったが、ゼロではなかった）。

⚠ **このラウンドが飛んでいる間に #R313 追記2 が merge され、`紐西蘭` が1件増えた。** rebase は
`ui.zh.js` と `ui.zh-hans.js` の両方を競合なく併合したので、**生成物だけが黙って古くなった**
（`node scripts/zh-hans.mjs --check` が out of date で捕まえた）。増えていたのは `atlas-examples.js`
由来の inline キー `"Australia and New Zealand"` ——**このラウンドが塞いでいるまさにその穴が、
塞いでいる最中にもう1件を生んでいた**。再生成して 6+1 件・9行になった。

### 残した観察——`澳洲` はこの表に無い

`"Australia & New Zealand"` の訳は今回 `澳洲与新西兰` になった。`澳洲` は台湾でより一般的で、
大陸の正式な国名は `澳大利亚` である（UN M49 の中国語名も「澳大利亚和新西兰」）。
**今回は依頼された2語だけを直しており、`澳洲` は変えていない。** 同じ区分に足すべきか、
大陸でも通じる用法として残すかは語彙の判断なので、**勝手に広げず記録だけ残す**。
