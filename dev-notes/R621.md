## R621 — **#R585 の凡例は本番で空で、観測局のポップアップは一度も開いていなかった**

〈#R585 の production verification。ローカルの検査は全部緑、CI も全部緑、コンソールにもエラー無し〉

### 1. ⚠⚠⚠ 出ていなかったのは、レイヤーが存在する理由そのものだった

本番で `#data-legend-imrad-obs` の箱は出る。中身は **`innerHTML` の長さ 0**。
色スケールも、どの観測網が答えたかの一覧も、そして4つの注意文——
**「50〜200 nSv/h はほぼ全世界で通常の自然放射線量」「降雨だけで最大3倍」「大半は未検証」
「1局が高いことは放出の証拠にならない」——が、1つも表示されていなかった。**
読者には**放射線の点だけが、注意書き無しで**見えていた。

原因は 1 行の形:

```js
S(L(LA('50–200 nSv/h is normal…', '50〜200 nSv/h は…', …)))
```

**`pick()` は位置引数を取る。** `arguments[0]` を英語鍵として他言語を引く。
`pickArgs()` が作るのは**配列**なので、それを渡すと**配列がそのまま返る**。
その配列が `.split('{n}')` に届いて TypeError になり、**囲みの `try/catch` が飲んだ**ので
`key.innerHTML = …` に一度も到達しなかった。

### 2. ⚠⚠⚠ ポップアップは一度も開いていなかった

`GE().popup({lngLat, html})` は**存在しない扉**である。レンダラ契約は
`GE().ui.popup(options)` を返し、`GE().ui.attach(...)` が地図に載せる
（`js/app-body.js`・`js/atlas-console.js`・`js/beta-overlays.js` の全呼び出し側がその形）。
この回は 1 呼び出しの形を**発明し**、`undefined` への呼び出しになり、`try/catch` が飲んだ。
結果、**値も時刻も量も出典もライセンスも履歴も、そして 720 局ある「検出器の下限未満」の説明も、
一度も画面に出ていない。**

### 3. ⚠⚠⚠ 検査が見えなかったのは「不十分」だからではない——**そう作られていた**

| stub | 実物 |
|---|---|
| `pick: () => (v) => Array.isArray(v) ? v[0] : v` | 位置引数を取り、**配列は配列のまま返す** |
| 手書きのレンダラ double | `popup` は**トップレベルに存在しない**（`ui.popup`） |

**言語の stub は、バグを通り道で直していた。** テストの中では文字列に見え、ブラウザでは配列だった。
レンダラの stub は手書きなので、**そもそも存在しない扉**をいくらでも持たせられる。
⚠ **実物より高機能な fixture は、その欠陥を原理的に見られない**（#R552 と同じ。今度は 2 か所で同時に）。

⇒ `tests/r621-checks.test.mjs` は:

1. **本物の `js/lang-registry.js`** を読み込んで凡例を組み立てさせ、**`innerHTML` が実際に書かれ、
   注意文が入っている**ことを測る
2. **出荷している `js/geo-engine.js` を実際に import して公開面を数え上げ**、レイヤーが名指す
   `GE().x` / `GE().x.y` が全部実在することを測る
   ——⚠ AST では届かない: `window.IntMapGeoEngine = (function(){…})()` の IIFE は**呼び出し式**を
   返すので、構文解析は工場をモデル化しないと何も分からない。**#R505 の答えがここにも効く**
3. `L(LA(…))` という形そのものを禁じる（3 ファイルを走査）

⚠ **コメントは剥がしてから測る。** 最初の実行は、**欠陥を説明した私のコメントの中の**
`GE().popup` を拾って赤くなった。理由を書いた文が、理由を守る検査に落とされてはならない。

⚠ **本番の欠陥 2 件をそのまま戻す変異で、実際に赤になることを確認した**
（A: `GE().ui.attach(GE().ui.popup(` を `GE().popup(` へ戻す → 検査①が赤／
B: 注意文を `L(LA(…))` に戻す → 検査②③が赤）。

### 4. ⚠⚠ 空白の国は「安全な国」と読まれる

`us-epa` の 28 本の chunk は**本番で全部 502 `upstream_unreachable`**。
`radnet.epa.gov` 自体はデスクトップから 200 / 567 KB で読める——**Supabase の egress から届かない**
（1.6 秒で失敗＝タイムアウトではなく接続失敗）。コードでは直せない。

直せるのは**振る舞いのほう**だった。最初の版は 28 回 `catch(()=>{})` で握り潰し、読者には
**空のアメリカと、理由を何も言わない凡例**が残っていた。⇒ **最初の失敗でその出典の掃引を打ち切り**、
`read:false` / `reason:'unreachable'` を立てて**凡例が「取得できず」と言う**。
