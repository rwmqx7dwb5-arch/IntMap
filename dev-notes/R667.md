## R667 — **拒否は「どこですか」と訊いていた——渡された地名が解決できなかったときにも**

> #R663 が実測して残した 2 件。どちらも同じ 1 文
> 「東北沖でM9の地震が起きたときの津波の伝播をシミュレーションして見せて」の上にある。

### 1. ⚠⚠⚠ 1 つの `null` が、2 つの別の状態を意味していた

`geocode('東北沖（日本海溝）')` は解決できない。**それは正しい**——#R515 の名前一致の床が、
問い合わせと合っていない候補を捨てる。問題はその次にある。

```js
if(!ll) return R(false, warn('⚠ '+L('Where? Give an epicenter (place, or lng/lat).', …)));
```

**これは「何も渡されていない」相手に訊く質問である。** 地名を渡した Atlas はその質問に答えた
——地名を言い換えて、7 回。手数の予算が尽きて終わった。**Atlas は訊かれたことに答えていた。**

⚠ **そして、これは 1 か所の話ではなかった**（実測）:

| 数えたもの | 件数 |
|---|---|
| dispatch の `geocode(` 呼び出し | **50**（39 case） |
| 場所が決まらないときに拒否する case | **32** |
| 「渡されていない」と「解決できなかった」を**別の文言で区別している** case | **0** |
| 共有ヘルパ | **無し** |

`geocode()` 自身が **`null` しか返さない**——何を問い合わせたかも、なぜ外したかも返さない。
だから 32 の呼び出し側は、区別しようにも材料を持っていなかった。

**⇒ 直したのは 32 の文ではなく、区別の持ち主が居ないこと。** `whereMiss(sentence, place)` を
`geocode()` の隣に置いた（その区別を知っているのはその関数だから）。

- 場所が渡されていなければ、**呼び出し側の文をそのまま返す**。今読める拒否は 1 つも変わらない。
- 渡されていて解決できなかったなら、**その名前を名指して**言う——
  「「東北沖（日本海溝）」は地名として解決できませんでした。経緯度で指定するか、地名辞典にある場所で
  指定してください。」

### 2. ⚠⚠⚠ そして、座標があっても走らなかった——**活性化との競合**

```js
function openPublic(o){ … RT.activate('sim.tsunami',o||{}); return true; }
```

`RT.activate` は `load(name).then(…)` である。**この関数は promise を捨てて同期の `true` を
返していた。** dispatch はその直後に `setHours` → `run` → `showMaximum` → `showContours` →
`play` を並べる。実測（`open({lng:141,lat:37,…,run:false})` の**直後**に `state()`）:

| いつ | `open` | `epi` |
|---|---|---|
| 直後 | **false** | **前回の [143, 38.3]** |
| 2.5 秒後 | true | [141, 37] |

`run()` は**まだこの出来事を採用していないモジュール**に届き、`build()` は
`lastErr='no epicenter'` で戻る——**呼び出しは「完了」と報告され、地図には何も出ない。**

⇒ **runtime が返すものをそのまま返す。** ⚠ **promise は truthy** なので `if(open(…))` と読む
既存の呼び出し側は 1 つも変わらず、待ちたい側だけが待てるようになる。dispatch は `await` する。
`run:false` を渡すこと自体は正しい（#R204: scope は solve が始まる前に決まっていなければならない）
——間違っていたのは、**モジュールが存在するのを待たなかったこと**。

### 3. ⚠⚠ 新しい文の鍵を、危うく連結で作るところだった

最初の版は `L('“'+place+'” could not be resolved…', …)` だった。**5 言語では正しく動く。**
`pick()` は fr / ko / zh-Hant / zh-Hans を **`inline[code][引数0]`** から引くので、
**連結した鍵はどの表にも当たらず、4 言語が英語のまま全ゲート緑**になる（#R548 の形）。

⇒ 鍵は **literal**、地名は **`{n}`** で運ぶ。検査は綴りを読むのではなく、
**9 言語を実際に評価して**それぞれが英語と異なることを確かめる。

### 4. まだ直していないもの

- **群 A の 14 case は、場所が渡されていないときに拒否しない**——`geocode('')` が
  「直前の場所または地図中心」を返すので、**未指定が成功として答えられる**（#R278/#R299 が
  同じ形を 2 回、1 件ずつ直した跡がコメントに残っている）。今回の `whereMiss` は
  「解決できなかった」側だけを直しており、こちらは別の欠陥である。
