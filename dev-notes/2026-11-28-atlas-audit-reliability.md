## 完了判定と会話の継続

必要な成果物は対象 ID と操作の受領証で照合する。別の方法の成功は同じ対象の不足だけを解消する。
検証役の無応答や内部メモは、確認された不足を取り消さない。地図を描くと宣言した後の文章の言い換えは進展に数えない。
計画を引き継ぐときは対象・期間・入力版を照合し、改訂の影響を受けない手順は個別の対象範囲で再利用できる。
サーバージョブが端末に残す操作は実行版で記録し、条件を改訂したときは改訂された操作を一度適用する。

## 地理集計と数値照合

人口集計は明示された図形を探し、その対象が存在する場合だけ集計する。WorldPop に送る形はポリゴンの交差で分割し、線上に追加した頂点で形を変えない。
地図には人口を取得できた範囲を表示し、取得できたタイル数、集計面積、出典を返す。部分的に取得した場合は、ターンにも未達が伝わる。
標高順位では対象全体を分割して測定し、候補数と実測数を記録する。地震は地点ごとの球面検索で範囲を覆う。
複数の調査結果は符号付きの値と尺度を保存して比較し、換算できない値は保留する。地物の同定では外部 ID を優先する。

## 成果物・来歴・検索証拠

ブラウザ委譲とサーバージョブは全件の GIS 成果物を参照で引き継ぐ。派生結果に出典と版を保持し、同一ラウンドの依存呼び出しは参照元から実行する。
ブラウザ子 AI は資料を非表示でデータ登録できる。実行環境のデータ形式・取得範囲・演算の対応状況を計画時に照合する。
登録した GIS の説明とラスターのバンド情報は既存の共有 API から読み、人口の集計範囲には既存の強調表示オブジェクトと同じ ID を付ける。この 3 件の参照を共有窓口台帳に反映した。
地図の評価は名前・形状・出典・作成者を同じ地物に結び付ける。計測線の両端を読み返せるようにし、日付変更線をまたぐ線の代表点は線に沿って求める。
ウェブ検索は全文と検索言語をキーに使い、取得し直した証拠を別の版として保持する。添付は選択した文書区間・比較写真を優先し、受理した範囲を返す。
画像を再読して答えを撤回した場合はその判断を採用する。意味検索の初期登録は一時障害の後に同じタブで再試行する。

## 暦日と計測

年月日の実在と和暦の有効期間を検証し、未来日は利用者の暦日で判定してから時計を設定する。
推論強度の比較には、既存の Atlas 評価器で同一の課題を選び、表示された最初の使える結果の時刻と、確認できた成果物数および費用を記録する。強度見積もりと独立検証の費用は応答から取り込む。

## 回帰検証

外部モデルを使わず、同じ原因を持つ別の対象・形状・版・暦日を含む対照試験を追加した。
起動時に使う地物の端点・クリック記録を小さな共有モジュールに置き、常時読み込む地図ツール本体を Atlas の遅延バンドルから参照する経路を外した。
`main` の CI の実測と同じ起動リクエスト 12 件を維持した。gzip は約 13.4 KiB 増えた。
起動側には既存の地物一覧への来歴・端点の接続と、描画を伴わない取り込みの入口が加わる。標高・地震クエリと暦日の検証にも対応する遅延チャンクの増分がある。
