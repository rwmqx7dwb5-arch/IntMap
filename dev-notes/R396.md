## R396 — **1か所直しても、同じ事実を書いた場所が3つ残っていた**

#R372 が `CLAUDE.md` §11.2 の `pwsh -File scripts/backup-usb.ps1` を、このマシンで実際に動く形
（`powershell -NoProfile -ExecutionPolicy Bypass -File …`）へ直した。**PowerShell 7 はこのマシンに
入っていない**——`Get-Command pwsh` は CommandNotFoundException、`C:\Program Files\PowerShell` も
`WindowsApps\pwsh.exe` も不在、`$PSVersionTable.PSVersion` は **5.1.26100.9168**。つまり
「終了処理の最後の1歩」は、**書いてあるとおりに実行すると必ず失敗する**状態だった。

⚠⚠⚠ **だが同じコマンドを案内している場所が、ほかに3つ残っていた。**

| 場所 | 何を案内していたか |
|---|---|
| `.claude/skills/intmap-round/SKILL.md` §7 | ラウンドの終了処理の工程そのもの |
| `scripts/backup-usb.ps1` の USAGE | 3行すべて |
| `scripts/worktree.mjs` | `done` のたびに印字するヒント |

**1か所だけ直しても、読者はそちらを読む。** `/intmap-round` を読んで手順どおりに進む次のセッションは、
`CLAUDE.md` ではなく SKILL.md の行を打つ。⇒ 4か所すべてを実測に合わせた。
スクリプト自身は 5.1 で完動する（`::new()` は 5.0 以降・PS7 専用構文なし。実測 `RESULT ok`・
2,693 ファイル・差分ゼロ）。

⚠ **記録のみ**: `-WhatIf` は書き込みプローブ（`.intmap-write-probe-*.tmp`）を USB に残し、
続く検証がそれを「余分」と数えて **`RESULT failed`** で終わる。通常の同期経路では起きない
（実バックアップがそのファイルを削除して差分ゼロに戻す）ので未修正。
