## R538 — **言語レイヤーは色の鍵しか持っておらず、言語の同一性を持っていなかった**

> 「言語レイヤー改善・拡張報告書」（Phase 1: Identity を直す）
> 「最終的には現在の 国 → 主要言語 → 色 というモデルから、地理的位置 ↔ 言語 ↔ 方言 ↔ 語派 ↔ 語族 ↔ 系統樹 ↔
> 文字体系 ↔ 社会的地位 ↔ 存続状態 ↔ 言語構造 を一つの言語レイヤー内で探索できるモデルへ発展させる。」

### 1. ⚠⚠⚠ 真因——認識できなかった言語は「不明」ではなく「無かったこと」になっていた

`scripts/build-culture.mjs` は Factbook の「Languages」欄を **119 本の正規表現の表**（`LANG`）で ISO 639-1 タグに
変えていた。表に無い言語は**捨てられ**、残ったものの中の最大値が `top` になった。出荷中のファイルで実測:

| 国 | 出荷されていた `top` | Factbook の 1 行目 |
|---|---|---|
| ブルキナファソ | Fula 7.8% | **Mossi 52.9%** |
| ナミビア | Afrikaans 9.4% | **Oshiwambo languages 49.7%** |
| モザンビーク | Portuguese 16.6% | **Makhuwa 26.1%** |

⚠ **これはデータの欠落ではなく、欠落を欠落として報告しない設計だった。** モーリシャスの Mauritian Creole と
セーシェルの Seychellois Creole は**どちらも `ht`（ハイチ・クレオール）**、ブルンジの Kirundi は**キニヤルワンダ語**、
Mandarin / Yue / Wu / Min Nan / Hakka / Gan は**`zh` 1 つ**、Persian / Dari / Tajik は**`fa` 1 つ**。

⚠⚠⚠ **そしてテスト 3,136 本と 13 本のソース側ゲートが全部緑だった。** `tests/r266` は「≥180 か国あるか」
「`top` の異なる値が ≥60 あるか」を、`tests/r271` は「色が重複しないか」を訊いていた——**どれも欠陥のある形について
真**である。⚠ **`build-culture.mjs` には `--check` が無く、言語データを検証するゲートは 1 本も存在しなかった。**

### 2. ⚠⚠⚠ もう一つの真因——「最初に列挙された言語」を「主要言語」と呼んでいた

Factbook が割合を出さない国では、`(lt.split(/[,;(]/)[0])` ——**最初の区切りまでの文字列**——を `top` にしていた。
その結果ケニア = English、ナイジェリア = English、DRC = French、チャド = French。**これは統計的な結論ではなく、
公用語である。** 凡例には「各国は最大シェアのグループで色分けしています」と書いてあった。実測: **204 か国中 107 か国**
（半分以上）がこの経路だった。

⇒ **出典が割合を公表していないなら、こちらも公表しない。** その国は `top:null` になり、地図では専用の色
（`NO_SHARE`）に塗られ、凡例が「割合の公表なし · 204 か国、うち 107 か国」と言い、ポップアップが
「この国について出典は割合を公表していない」と言う。**出典が挙げている言語は消えていない**——位置づけつきで
ポップアップに出る（ナイジェリア: English = 公用語、Hausa・Yoruba・Igbo・Fula）。

### 3. 正本を Glottolog にした——言語に同一性を与える

`scripts/build-language.mjs`（新）が Glottolog CLDF（CC BY 4.0）と Factbook から 2 つのファイルを書く。

- **`data/language.json`** — 国ごとに `top` / `pct` / `shareType` / `mix` / **`listed`（出典が挙げた順）** /
  **`roles`（位置づけ）** / **`unnamed`（出典が名指していない割合）** / `y` / `src`、＋使っている **360 言語**の
  名前・ISO 639-3・9 言語ぶんの訳。
- **`data/language-tree.json`** — Glottolog の分類全体 **12,895 languoid**（族・言語・国が指す標準／親・
  ISO 639-3・カテゴリ・**AES 存続状態**）。**地図と系統樹は 1 つのモデルの 2 つの表示**になった。
  ⚠ 726 kB あるので**レイヤーを入れたときにだけ**取りに行く（起動費用に載せない）。

⚠ **`crp`「Creoles & pidgins」というバケツは消えた**——タグがクレオールを名指せなかったから存在した括りで、
いまはそれぞれが自分の languoid を持つ。`LANG_FIX` の 14 件は**捨てずに Glottocode へ付け替えた**（`Intl.DisplayNames`
はいまも Gilbertese や Tok Pisin を 5 言語で名指せない）。

### 4. ⚠⚠⚠ 名前の解決は「規則」か「理由を書いた判断」だけ——推測はビルドを落とす

Factbook の 487 個の語句を Glottocode に解決する。`scripts/lib/glottolog.mjs` の**明示された規則**:

1. **主名（族）** — 「Arabic」「Albanian」「Uzbek」は Glottolog の**群ノードの正式名**で、Factbook もその括りで
   言っている。**国の記録が枝を指してよい**——モデルに段があるのはそのため。
2. **主名（言語）** → 3. **別名（言語）** → 4. **別名（族）** → 5-6. **標準（dialect）** — 旧ユーゴの 4 標準はここ。
7. **国** — Glottolog は languoid ごとに国を持つ。赤道ギニアの Fang とカメルーンの Fang は別の言語。
8. **最小共通祖先** — 候補が 1 つのものの変種で、その名前が訊かれた名前と一致するとき（Quechua → Quechuan）。
9. **ISO 639-3 マクロ言語** — 祖先ノードが**マクロ言語コードを持つ 45 ノードの 1 つ**なら、それが出典の数えている
   段である（Fulani → Fula `ful`、Tamacheq → Tuareg `tmh`、Aymara → `aym`）。
10. **語順** — 「Bokmal Norwegian」対「Norwegian Bokmål」。11. **バントゥ語類接頭辞** — Sekalanga → Kalanga。
12. **綴りの Dice 類似**（bigram・下限 0.78・2 位との差 0.06・**国が分かるときだけ**）— Sembukushu → Mbukushu。

規則で決まらなかった **63 件**は `data/language-aliases.json` に**理由を書いて**結んだ（`ignore` 7 件も同様——
「Gurage」は South Ethiopic の**2 つの枝**にまたがるので単一のノードが無い、等）。⚠ **どちらでもない名前は
`process.exitCode = 1`。** 139 件 → 0 件。

### 5. ⚠⚠ ゲートを書き直したその日に、BCMS が退行を見せた

Glottolog は **「Croatian」も「Serbian」も言語 `sout1528` の別名**として持ち、言語の段は標準の段より上位に
当たる。台帳を書く前の実測で、**クロアチアの Croatian 95.2% と Serbian 1.2% が黙って 1 つの 96.4% になっていた**
——#R268〜#R273 が 4 ラウンドかけて分けたものが、識別子を替えた瞬間に戻っていた。台帳で 4 標準
（`serb1264` / `croa1245` / `bosn1245` / `mont1282`）へ結んで解決。⚠ 系統樹の上では 4 つとも `sout1528` の
**子孫**であって直接の子ではない（間に Eastern Herzegovinian Shtokavian がある）——**「親か」ではなく「子孫か」を
訊くのが正しい関係**で、書き直した検査はそれを訊いている。

### 6. ⚠⚠ リベリアの 20% は、新しいテストが見つけた

「English 20% (official) and 27 indigenous languages」を「組み合わせ」と解して share を `unnamed` に落とし、
リベリアが**主要言語なし**になっていた。⇒ **名前が 1 つしか解決しないなら、share はその言語のもの**
（2 つ以上あって初めて分けられない）。「Gilaki and Mazandarani」は 2 言語なので従来どおり分けない。

### 7. ゲートと検査——「形」ではなく「正しいか」を訊く

**`npm run check:languages`**（`scripts/build-language.mjs --check`・オフライン・`npm test` と CI の両方）:

- **`top` が最大の実測シェア「である」こと**（見えるだけでは足りない）——ブルキナファソを捕まえたはずの検査。
- 実測が無い国は `top:null` かつ `shareType:'listed'` で、出典の挙げた言語は残っていること。
- 全 Glottocode が系統樹に存在し名前を持つこと／系統樹が木であること（親が解決し・循環なし・重複なし）。
- 台帳の全行が実在の languoid を指し、**理由が書かれていること**（`ignore` も同じ）。

`tests/r538-checks.test.mjs` 7 本。⚠ **①は「出典が印刷した最大の数は、主要言語の share か `unnamed` の
どちらかで説明がつく」という関係**を 204 か国について訊く——ガーナのように「other 31.2%」が最大の国
（Akan 30.8% ＝ Asante 16 + Fante 11.6 + Akyem 3.2 の合算）でも、シエラレオネのように**括弧の中にしか %
が無い**国でも正しく判定する。

⚠ **綴りを固定していた既存アサーション 5 本は、綴りではなく関係を訊く形に書き直した**（#R488 / #R494 の形）。
`tests/r273` は `const FAM_BCMS={ sr:0, cnr:1, bs:2, hr:3, sh:4 }` という**もう存在しないモデル**を固定していた。
