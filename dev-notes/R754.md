## R754 — Atlas は「IntMap に伝播シミュレーターは無い」と答えていた。有る。#R575 から有る

〈#R747 §6 の 1 番目。本番実測 2026-09-16・build R746・ログイン済み〉

### 1. 実測

質問: 「Simulate a pandemic starting in Lagos and show me day 60.」
結果: **7 steps / 43.8s / stopped=answered / 操作 0 件**。回答:

> I can create a clearly labeled illustrative public-health scenario from Lagos, but **IntMap does
> not currently provide an epidemiological transmission simulator** that can calculate and map a
> defensible "day 60" pandemic spread.

前半は正直で、**後半は自分の製品について誤り**だった。`js/pandemic-model.js` は #R575 以来の
種を取る確率的 SEIR メタ個体群エンジンで、R0・潜伏と感染期・免疫の減衰・接種・政策段階を持つ。

### 2. なぜ模型はそう答えたのか——カタログが言及していなかった

パンデミックについて planner に渡っていたのは block 06 の長い 1 行の中の 1 句
`{"type":"playground","mode":"pandemic"}`「Playground のゲームを開く」**だけ**。
**種を置く・日数を進める・その日の状態を読む入口は 1 つも説明されていなかった。**
説明されていない能力について「無い」と答えるのは、**規則に忠実な模型ほどそうする**。
⚠ これは [[intmap-prompt-that-hid-the-tools-in-hand]] のより厳しい形である——
あちらは「手の中にある道具を『直接呼べない、探せ』と書いた」、こちらは**一度も書かなかった**。

### 3. engine は回せた。世界が作れなかった

#R575 は数理を DOM クロージャから出した。**残り半分が残っていた**——どの Natural Earth の行が
人の住む場所か、人口と接続はどうか、誰が統治するか。それは `_pgPandemic` の
`ensureCountries` コールバックの中にしか無く、**そのパネル以外の誰も到達できなかった**。

⇒ `js/pandemic-world.js`。⚠ **パネルと Atlas は同じ world オブジェクトを受け取る。**
別々に作れば、Atlas が報告する数と読者が画面で見る流行は**同じ名前の別物**になる
（[[intmap-contract-is-not-implementation]] が測った形そのもの）。
⚠ **2 段階は仕様である。** 行は即座に解決し、パネルはそこから設定画面を描く。`ready` は 4 表が
settle してから解決し、**それが「走らせてよい」の意味**——移動行列は `createPandemicModel` で
凍るので、表が揃う前に始めた走行は種から再現できない（#R673）。1 本の promise に潰すと、
パネルの「世界はこれ、接続を準備中」が**空白の待ち**に変わる＝ refactor に紛れた UI の退行。

### 4. 能力は 2 本（計算と描画）

`sim.pandemicRun` は走らせて**状態を返す**（世界の合計＋国ごとの累計感染・死者・現感染者・
到達日・国境段階）。**地図には何も約束しない。** `map.pandemicDay` が描く。
⚠ 1 本にまとめると、**描画を約束した能力が描かなかった回を観測器が `not_rendered` と呼ぶ**
——#R736/#R737 の 21 手、#R742 の 207 中 52 件。#R743 が GIS で確立した形。

⚠⚠ **観測器は塗った側に訊く。** `paintNow()` は手書きのソース id 一覧で、**その直上のコメントが
「ここに足すな、塗る側が宣言しろ」と書いている**（#R735 が `nlq-fac-src` で払った代償）。
なので `js/pandemic-atlas.js` の `painted()` が自分の canvas を地図から読み、観測器がそれを呼ぶ。
⚠ **差分でなく「今」を測る**——`factions`・`isochrone` と同じ補正で、同じ日を 2 度描いても失敗に
ならない。⚠ **読めないことは空ではない**（null を `not_rendered` にしない）。

### 5. 宣言が 4 つの入力を落としていて、その真上のコメントが「一致する」と主張していた

`P` は `inp.vaccineEfficacy` / `inp.vaccineMonths` / `inp.vaccineImmunityLifelong` /
`inp.vaccinateUnreached` を読む。`PANDEMIC_PARAMS` はそのどれも述べていなかった。
**主張は測定ではない** ⇒ ソースから `inp.<key>` を数え上げ、**18 = 18 を両方向で**測る。
どちらの向きも欠陥である——未宣言の入力は呼び出し側に差し出せず、
誰も読まない宣言は**何もしないパラメータ**である。

### 6. 既定値は主張である——そして 4 つ目の出典

呼び出し側が 2 つ指定し 16 個をこのファイルが供給する run を、そのまま報告すると
**IntMap の既定値を読者の口に入れる**（#R675）。`describePandemicParams` が 1 つずつ出典を付ける。

⚠⚠⚠ **出典は 4 種類あり、4 つ目がこの企画が繰り返し学び直しているものだった。**
`caller` / `preset:<プリセット>.<欄>` / `scenario:<名>` までは自明。4 つ目は
**上流が述べていない欄を指すポインタ**——`immunity.lifelong` は麻疹にしか無いので、covid の
`false` を `preset:covid.immunity.lifelong` と報告すると、**そのプリセットがしていない発言を
帰属させる**ことになる（[[intmap-data-must-not-claim-an-author-it-lacks]]）。
⇒ `preset-silent:` を分け、**沈黙を沈黙として**報告する。検査は**両方向**——
`preset:` は実在する欄を、`preset-silent:` は**実在しない**欄を指していなければならない
（さもなくば 2 つは互換のラベルで、区別は意味を失う）。

### 7. 拒否は丸めない

範囲外の値は**クランプせず拒否**し、拒否が**その変数自身の範囲**（`paramBounds`）を運ぶ。
丸めると「誰も頼んでいない数で成功した run」を、頼まれたかのように報告することになる（#R743）。
未知の鍵は**全鍵**を、enum 違反は**その enum の値**を添えて返す——1 回の誤りが 1 回の訂正になる。

### 8. 開始地点

国コード・国名・地名・座標。**地名は同梱の gazetteer で点に解決し、その点を含む国を点内包判定で
決める**——ジオコーダの第一候補をそのまま国にしない（[[intmap-store-refused-its-own-key]] は
ドイツがベルギーに、日本がベナンになった回）。⚠ **どう決めたかは回答が述べる**
（「Lagos → Nigeria」）。黙って変換して「Nigeria」と報告すると、読者が異議を唱えられない段が
1 つ隠れる。⚠ `country` / `origin` / `place` は **1 か所で読む**
（[[intmap-two-readers-one-field-list]]——欄の一覧が 2 つあると片方にしか無い欄は蒸発する）。

定義ごと 365 行を消した**。`tests/r670-checks ②`（「扉の内側から publish しているか」）が落ちて

`npm run check:static` が split-scope 12 件として名指した。
**どちらも「コメントを書いている最中にコードを食う」という、この回が直していた形と同じ家族**

### 10. 検査

`tests/r754-pandemic-atlas-checks.test.mjs` **10 本**。⚠ **名前は欠陥を述べ、到達した答えを述べない**
（[[intmap-restate-the-defect-not-the-fix]]——#R520 が「1 国 1 点」と書いて、次の欠陥を 187 ラウンド守った）。
⑩ は**継ぎ目そのもの**——`js/pandemic-world.js` が実際に作った world を `js/pandemic-model.js` に

⚠ **Playwright の spec は 1 本も足していない**——`check:testbudget` は suite 81.3 分 / 天井 81.3 分で

### 14. CI が、ローカルで緑だった 2 つの予算を落とした——rebase が原因
