## 1. 直したもの（どれも事例ではなく、それを生んだ構造）

1. **本番の Edge を全部配備し直した**（`node scripts/supabase-deploy.mjs --all`）。再測定で 20/20 一致。
2. **`IntMapSafe.url()` の結果を、それ自体で属性に入れて無害にした**（`index.html`）。許可したスキームの
   値の `" ' < > \`` と空白を %エンコードする。ブラウザの URL パーサが施すのと同じ符号化なので、指す先は
   変わらない（日本語の URL は触らない）。9 か所を 1 つずつ `html()` で包むのではなく、全呼び出し元が
   受け取る側で直した——次に `url()` 単独で書かれる 10 か所目も同じく無害になる。`html(url())` は二重に
   符号化されない（`%22` は `html()` を通っても `%22`）。index.html の行数は変えていない。
3. **`tle-refresh.yml`**: merge に成功したら `gh workflow run deploy.yml --ref main`（workflow_dispatch は
   GITHUB_TOKEN でも起動できる例外）。起動できなければ赤。#773 は手で deploy を起動して本番へ出した。
   検査は「GITHUB_TOKEN で main に着地する workflow は deploy を起動する」を workflow 全部に対して述べる。
4. **`scripts/probe-relay-ladder.mjs`**: 記事の段は本文をページと同じ `looksLikeArticle` で判定する。
   `ARTICLE_RULE.type` は中継が**上流に**要求するもので、読み手が中継に要求するものではない。
   本番で `RESULT degraded 8/10`（残る 2 行は CelesTrak の 502 と GDELT の 429＝上流）で、Wikipedia が `yes`。
5. **`tests/r410-late.spec.js`**: 段ごとの上限を 1 つの表にし、テスト全体の上限をその和から導く。
   本当に止まった段は、その段の上限でその段の文面で落ちる。ローカルで 9.1 秒で一覧に到達し緑。
6. **`scripts/i18n-sink-literal-audit.mjs`（新規）を `check:i18n` の門に入れた**。通知の関数は名前
   （`…toast`/`…Toast`）で**発見**する。4 か所は en + jp にした。
7. **`scripts/ledger-claims.mjs`（新規）＋ doc-facts の `ledger` 規則**: 台帳の木の**全行**に、行の種類で
   規則を付ける——ワイルドカードの行が述べる本数は glob の件数、ふつうの行は実在、「全件」と書いた
   ディレクトリは実体を全部挙げる。場所は木の根がリポジトリの最上位にある block でだけ決める
   （`railways/` のように節の見出しが `data/` を与えている block は推測しない）。毎回増える tests の
   本数は、書くたびに並行 PR が同じ行で衝突するので書かないことにした（`ls` が答える）。
8. **`check:static` の資産の存在検査**を、手で並べた 2 ページからルートの全 `*.html` の発見に変えた。
9. `Architecture.md` の pgTAP の内訳に能力ベクトルと SECURITY DEFINER の呼び出し権限を足した。

## 2. 直さなかったもの（理由）

- **dependabot の major 3 本**（vite 8：起動時のモジュールが 306→1,700・`esbuild` が消える／maplibre-gl 6：
  default export が無い・#R158 から意図して固定／Turf 7：起動費用の天井）と **supabase-js 2.117**
  （起動時 +95 kB とパスキー UI の出現）は、それぞれ移行と製品判断を含むので最終報告で提案する。
- **secret 3 種の登録**は秘密値の本人入力なので利用者の作業（前日と同じ）。
- `docs/FILES.md` の `shakemap.js` の global が自身ではなく `lazy-modules.js` から代入される件は、事実として
  誤りではないので触らない。
