## R416 — **帯は消えていたのではなく、中身が無かった。地図は出来事を一度も開いていなかった**

依頼は 2 つ。「ニュースのUIが分かりにくいから根本的に整理して。また、地図へのマッピングは
出来事ごと単位で行うように。」——そして作業中に届いたスクリーンショットが
「そして、このありさま。帯が見えない」。

### 着手前に測ったこと

**「出来事ごと単位で行うように」は、既に半分実現していた。** #R386 以降、出来事経路では
`HOST.globalData` が Event の項目に差し替わり、ピンを組む loop はその上を歩く——つまり
**1 Event ＝ 1 地物にはなっていた**。依頼を「記事単位を出来事単位に変える」と読んで着手して
いたら、既にそうなっている実装を作り直していた。

欠けていたのは **地物が「自分が何の出来事か」を言っていないこと**である。9 つの property は
`fid / mapped / ptype / title / name / short / publisher / link / pubDate` で、
`publicId` も `sourceCount` も `category` も無い。だから地図から出来事へ戻る鍵が存在せず、
ピンのクリックは**代表記事の外部 URL を開く**しかできなかった。実測: `openDetail` の
呼び出し元はサイドバーのカードにある `.ev-sources` ボタン**ただ 1 つ**で、地図側からの参照は
**0 件**。地図は出来事を一度も開いていない。

### ① 白い箱の正体 — 空文字は「短い文字」ではなく別の描画経路だった

`js/news-events.js` が Event の項目を組むとき `short: ''` を固定していた。帯の層
（`news-labels`）は `text-field: ['get','short']` を読む。この層は `icon-text-fit:'both'` で、
**合わせるべき文字が 0 なら合わせようが無く、ピルのスプライトが素の 40×30 のまま描かれる**。
報告された「中身の無い白い箱」はそれである。

実測（ローカル・実ブラウザ・1440×900・欧州 z4.2）:

| | 実測 |
|---|---|
| 画面に出た帯 | 46 |
| うち `short` が空 | **46（100%）** |
| 同じ地物の `name` | `Norway` / `Kongsberg` / `United Kingdom` / `Middlesbrough`（**正しく入っている**） |

⇒ **データではなく、レイヤーが読む欄だけが空だった。**

規則は `js/news-context.js` の `analyzeContext()` の中にあり、**出来事経路はその関数を一度も
呼ばない**。だから空だった。⇒ 規則を `js/map-typography.js` の `bandText()` 1 本に出し、
記事経路もピン builder もそこを読む。⚠ **置き場所は `bandBox()` の隣である**——同じ 1 つの帯に
ついて「何を書くか」と「どれだけ場所を取るか」を別々のファイルが答えると、必ずどちらかが
古くなる。⚠ ついでに `…` は**実際に切ったときだけ**付くようにした（旧規則は 5 語の見出しにも
付けていたので、完全な見出しが「途中で切れている」と主張していた）。

実測（同じ視点・修正後）: 帯 **45 本すべてに文字**・空 **0**。

### ② 同じ loop が 2 つあり、だから欠落も 2 か所にあった

ピンの地物を組む loop は `js/news-feed.js`（生きている経路）と `js/news-ui.js` の
`aiRefreshNewsPins()` に**1 バイト違わず 2 つ**あった。⇒ `newsFeatureOf()` 1 本に畳み、
そこに Event の身元を積む: `ev` / `evId` / `evSources` / `evArticles` / `evCat`。

⚠ **`ev` は文字列 `'1'` / `''` である。** boolean の `false` は style expression の `match` で
「property が無い」と区別できない——#R409 が「ケースの無い `match` が 5 本中 4 本だけ入れた」
として同じ形を実測している。

### ③ ピンの行き先を出来事へ

`js/news-events.js` に `openByPublicId()` を足し（`items` は private のまま・見つからなければ
`false` を返して呼び出し側が落ちられる）、点と帯の**両方**の click を 1 本の
`_openNewsFeature()` に通した。出来事なら詳細、記事なら今までどおり外部記事。

⚠ **タブはトグルである。** 開いている News に `setMode('news')` を打つと、詳細を描く面ごと
閉じる（#R402 が「helper が開閉を交互にしていた」として実測した形）。だから **News に居ない
ときだけ**切り替える。

実測: 欧州 z4.2 でピンを 1 つクリック → `.ev-detail` が描かれ、`IntMapNewsEvents.selected()`
が**クリックした地物の `evId` と一致**（`emt77fwtaa05caa221d`）。外部タブは開かない。

### ④ 押すと 200/200 の出来事が太平洋へ散るトグルが、既定の面に残っていた

`Subject location / Publisher`。Event は `pubLoc` を**構造上必ず `null`** にする
（`js/news-events.js`）ので、publisher 枝は全件が `hashLocFromString()` の擬似座標へ落ちる。

実測（本番データ・200 件）:

| モード | 座標を持つ | `mapped=true` | 標本 |
|---|---|---|---|
| Subject | 200 | 200 | Ottawa (−75.7, 45.4) / Tehran (51.4, 35.7) |
| **Publisher** | 200 | **0** | NPR **(144.9, −2.0)** パプアニューギニア沖 / AP News **(163.8, 23.4)** 太平洋 |

**実在の場所を捏造した座標に置き換えるだけの操作は、モードではない。** 利用者の指示で撤去
（`docs/NEWS-EVENTS.md` の決定 9 を決定 16 が取り消す）。撤去は 5 ファイル——`index.html`
（markup）・`js/app-body.js`（状態・`applyPinMode` の枝・セッション保存・AI ボタンの銘）・
`js/news-ui.js`（同期と AI ロケータの publisher 半分）・`js/atlas-console.js`（`pinmode-*` の
`clickId`）・`js/widget-defs-map.js`（`map.news` の `by` 設定）。

### ⑤ 上の 3 行 — 同じ語が 1 画面で 2 つの軸を指していた

| 行 | 中身 | 問題 |
|---|---|---|
| 1 | 検索欄 | — |
| 2 | `All / ★ Saved` ＋ `Subject location / Publisher` | 2 つの `.ios-segment` が `flex:1 1 0` で 400px を割るので、**両方のラベルが切れる**（`Subject l…` / `Publisher…`） |
| 3 | カテゴリ chips（先頭が `All 200`） | 2 行目の `All` と**同じ語・違う軸** |

⇒ **1 行**にした（検索を除く）。scope（`すべて` / `★ 保存済み`）が左に固定、カテゴリがその右へ
横スクロール。カテゴリの先頭は `All topics / 全カテゴリ` に改名した。

⚠ **同じ行に置くなら、選択の見た目は分けなければならない。** 両方を「選択＝青塗り」にすると
**1 つの操作で 2 つ選ばれている**ように読める。scope はアプリのセグメント外皮（受け皿の中で
選択側が持ち上がる。`.lang-btn` と同じ）、カテゴリは平たいピルのまま。
⚠ 切れていたラベルは幅ではなく**レイアウトの結果**だったので、トグルの撤去で原因ごと消えた。
⚠ `★ 保存済み` には件数を載せた（0 のときは載せない——`★ 保存 0` は空の一覧へ誘う）。
⚠ カードの地名チップを 1 行にクランプした（`Brooklyn-Queens Expressway` が 2 行に折り返して
カードの頭を崩していた。全文は `title` と詳細に残る）。

### 測り方で外したこと

⚠⚠ **`project()` は地図コンテナ基準で、`elementFromPoint()` はページ基準である。**
混ぜたまま 3 回クリック検証を外し、3 回とも「ハンドラが動いていない」と読みかけた。実際に
押していたのは Köppen 凡例の DOM で、サイドバー幅 400px ぶんずれていた。⇒ canvas の
`getBoundingClientRect()` を足したら一発で通った。**「動かない」の前に、押した場所が何かを
`elementFromPoint` に訊く。**

⚠⚠ **Bash の heredoc がバックスラッシュを潰す**（#R390 と同じ）。`'\n'` が実改行になって
構文エラーになった。⇒ `chr(92)` で組むか、ソースは Write ツールで書く。

⚠⚠ **`io.open(read)` は universal-newlines、`io.open(write, newline='')` は無変換。**
読みだけ既定のまま書き戻したので、CRLF の 6 ファイルが LF に化け、`git diff --stat` が
**614 行**に膨れた（本当の変更は 40 行）。CRLF へ戻して解消。**diff の行数が変更の大きさと
合わないときは、まず行末を疑う。**
