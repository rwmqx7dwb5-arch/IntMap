---
title: Atlas の地図表示・原図・作業結果の根拠を引き継ぐ
date: 2026-11-29
newsen: Atlas checks the final map view, keeps the source legend and accuracy record with reconstructed layers, and can resume jobs from completed work.
newsjp: Atlas が最終画面の表示を確認し、復元レイヤーに原図の凡例と精度を残し、処理済みの成果を引き継いで再開できるようにしました。
---

全画面のレンダラー照会と描画フレームの差分を使う。Chromium の MapLibre で、フィルターを通った 11 番目だけの点と、輪郭が覆われて内側だけ見える面を確認した。不透明度 0 は別の理由として返す。撮影中にカメラが移動しても、撮影フレームの座標と範囲が画像に付く。

分類 ID と名称・色を一つの凡例で管理し、資料にある区分を一つのデータセットとして描く。合成した 19 区分で、凡例の区分・色、登録地物がない区分、未分類の地物を照合した。原図の変換・位置精度・位置を検証した点数をレイヤーから参照できる。

公開ページの通信から一般の JSON を見つけた場合は、匿名 GET で受信し検査できたものの構造を照合する。分類された地理ファイルの参照と検査できなかった件数を返す。稼働監視の起動に必要な設定を公開 URL の定義に絞り、HTTP 照会前の失敗と通信失敗を区別する。

未納の成果物を依頼に結び付け、通信や予算で止まった場合も既存の出力を引き継ぐ。永続ジョブの端末適用、
明細の取得失敗と費用の確定状態を記録する。起動後に表示カードが増えても、同じジョブの監視は共有する。

最新の main を含めた Vite ビルドで、遅延 JavaScript の gzip は 5,378.1 kB から 5,416.2 kB（+38.2 kB）になった。表示の観測・再開を扱う Atlas コンソール、描画履歴を保持する実行系、永続ジョブの成果表、数値と出典の照合、原図の分類抽出を追加したため。計測値が既存の上限を超えた6項目だけを `perf-budget.mjs --update` で更新した。初期読み込みの上限は変更していない。
