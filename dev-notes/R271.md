### ② 「凡例内はまだ単に『セルビア語』のまま」は、3回目で**パレット**のことだった

→ **パレットは繰り返さずに続く。** 手で選んだ30色を使い切ったら**黄金角 137.508°**（巡回の中で連続する値が

### ⑤ 新しい水源が他の場所の水を消していたのは、水を消す関数がその経路にあったから

`onClick` の水源モードは、押した点が作業矩形の外なら `rebuildAround` → `build()` を呼ぶ。その `build()` の
中に `resetSim()` がある——状態ベクトルを捨て、全水源の `_fed` を 0 に戻し、時計を 0 にする。
**別の場所を1回押しただけで、画面上の洪水が全部 t=0 からやり直しになる。**
#R261 は**彫った地形**についてこの形をすでに直している（新しい格子へ再標本化する）。**水はその残り半分**だった。

直し方は「水を再標本化する」ではなく「**作り直さない**」。盆地は設計上すでに作業矩形の外へ伸びており
（#R267「盆地はこの格子を延長するのであって2つ目を始めるのではない」）、`growBasin` は
`sim.grow` が既存の水深を**そのまま新しい格子へ運ぶ**。だから矩形の外に置かれた水源は**盆地を広げて届く**。

実測（本番と同じビルド・甲府盆地）:

| | 湿潤セル | 時計 | 盆地 | 作業矩形 |
|---|---|---|---|---|
| 1つ目を置いて1時間進めた | 67 | 3,600 s | 384×216（39.9 km） | — |
| **11.7 km 外**に2つ目を置いた直後 | **70** | **3,600 s** | **513×216（53.3 km）**・grow 1・void 0 | **bbox 不変** |

⚠ **Atlas の `addSource()` も同じ経路に載せた。** それまでは盆地の外に置かれても**押し込んで solve するだけ**で、
`feedSim` がそのセルを見つけられず**黙って何も起きなかった**——#R255 の `brush()`、#R258 の `addLevee`、
#R268 のリセットと同じ「呼ばれていない1行」の4回目である。
⚠ 予算 `basinMaxCells()` を超える距離のときだけ、従来どおり `rebuildAround`（＝本当にやり直し）に落ちる。

### 追記2 — **フィリピンが増えた（「最初に見た区域が使い物にならない」は「このフィードは使えない」ではない）**

「対応国も増やせ」に対して、この回の本文は **DWD（独）と MET Norway（諾）** を足したが、
**その2つはどちらも既に MeteoAlarm 経由で対応していた国**である——単位が細かくなっただけで、

| Tropical Cyclone Alert | 8件・`<area>` は PAR の矩形1枚のみ |
| **General Flood Advisory** | **43件**・17地域・**`<area>` は州ごと**で `<polygon>` と `<geocode>` 付き |
