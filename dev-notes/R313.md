### 3.「風レイヤーの凡例に、パーティクルをオンオフできるトグルを付けて。」

このレイヤーは1つの場から**色ラスタと粒子の2つ**を描くのに、両方が `on` 1つに束ねられていた——
**アニメーションを止める唯一の手段が「レイヤーごと消す」＝色も失う**ことだった。

`partsOn`（鍵 `intmap_wind_parts`・**既定オン**）と `_applyParts()` を足した。
⚠ **キャンバスを隠すだけでは「オフ」ではない**——`display:none` の裏で `step()` が rAF を
要求し続けるなら、誰にも見えないものの計算が回り続ける。ループごと止め、`clearTrails()` で
残像を消す（#R284 の点滅の逆向き）。

⚠ スイッチは**凡例の中**（#R16：1レイヤー専用の操作はレイヤー欄に置かない）。凡例本体は
毎回 `innerHTML` ごと差し替わるので、チェック状態は**描画のたびモジュールから読み直す**。

**実測**: 凡例のチェックを外すと `Wind.particles()` = false ／ `#wind-canvas` が `display:none`

### 4.「AtlasのThinkingとかSearchingとかのUI、ChatGPTと同じグラフィックにしてください。
（実際にChatGPTのサイト見て、実装してください。）」

**実際に見た。** chatgpt.com は design system を同一オリジンで配っているので、
`/cdn/assets/root-*.css` を fetch して `.loading-shimmer` の生規則を読んだ。

**スピナーでもドット3つでもない。ラベル自身が動く：**

- 文字はグラデーションを**グリフの形に切り抜いて**塗る（`background-clip:text` ＋ 透明な text-fill）
  ので、語の横に別の要素が無い
- グラデーションは 基準色 → 帯 → 帯 → 基準色 で、**帯は 40％〜60％**
- 帯の幅は要素の **50％**（`background-size:50% 200%`・`no-repeat`）で、
  **`-100%` から `250%` へ 2秒 linear infinite**

⚠ **帯の色はハイライトではなく背景寄りである。** 向こうは light `#ffffffbf` / dark `#0009`——
どちらも**文字の後ろのページへ向かう**色なので、語を横切るのは**光ではなく褪せ**である。
両テーマで同じ「明るくする帯」にすると、**手法だけ同じで効果が別物**になる。IntMap 側は同じ2つの
アルファをテーマブロックで持つ（`--atl-shimmer-band`）。`prefers-reduced-motion` では止め、
**text-fill を `currentColor` に戻す**（透明のまま止めると語が消える）。

⚠ **ラベルの無い裸のドットが6か所あった**（弾道の再実行・軌道プロファイル・放射線の設定変更・
`localPlan` の決定論パス・AI 不可時のローカル実行・`runDirect`）。残せば**1つの状態に2つの
グラフィック**が居続けるので、全部 `stageDots('think')` にした——ChatGPT も語を出す。
`.atl-stage` は**「まだ作業中の泡」の印でもある**ので、取り消し走査の綴りも一緒に移した。

### 検証で分かったこと

⚠ **ローカルのプレビューでは地図スタイルが最後まで読み込まれない**（基図の CDN が届かない）。
`GE.ready()` が false のあいだ **`fitBounds` は例外も投げずに何もしない**（`jumpTo` は効く）ので、
**EU の自動移動はローカルでは原理的に確認できない**——`__imap.fitBounds` を直接叩いても動かない
ことまで確かめた。果の値と `arrive()` の可否は測れるので測り、**カメラが実際に動くことは本番で
確認する**。同じ理由で `document.hidden` が true になり、**CSS アニメーションの時計が進まない**
（`getAnimations()` は `running` を返すが `currentTime` は 0 のまま）ので、シマーの掃引そのものも
本番で見る。計算できる部分——両テーマの帯の値、`background-clip:text` が実際に採用されたこと、
`background-size`・`animation` の計算値——はローカルで確認済み。
