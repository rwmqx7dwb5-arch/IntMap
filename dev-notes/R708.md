## R708 — 年選択の巨大DOMと、終了した地図の保持を解消

人口・GDPの凡例はマスター時計の下限から現在まで全年を列挙し、各125,026個のoptionを起動時に生成していた。さらに時計の購読が削除済み凡例を保持した。修正前のローカルChromiumではGC後も約301万DOMノードが残る。選べる年は減らさず、数値入力と現在ボタンへ変更。共有購読は接続中の欄を発見して同期する。

地理ゲームの回答地図は全閉鎖経路で破棄。Cesiumはビューの時計購読・定期処理・地形キャッシュ登録を解除し、除去したマーカー・ポップアップのイベントも解除する。制御した実行回帰ではpopup100回の除去後に残る購読が400件から0件になった。

ケッペンは期間変更・携帯での終了時に作業キャンバスの16 MiBの領域を即座に返し、旧画像の遅延完了による再保持を防ぐ。解像度、地形の精度、表示レイヤー、更新周期、キャッシュ予算は変更していない。

同じ起動手順・5秒待機・GC後のローカルChromium比較（1回ずつ）:

| 計測 | desktop 前→後 | iPhone相当設定 前→後 |
|---|---|---|
| CDP DOMノード | 3,015,533 → 11,724 | 3,015,373 → 11,533 |
| 接続中の要素 | 255,382 → 5,086 | 255,125 → 4,830 |
| 年入力欄が準備されるまで | 2,712 → 533 ms | 2,796 → 587 ms |
| JSヒープ | 201.67 → 105.82 MiB | 55.04 → 52.89 MiB |

DOMノードは約99.6%減。これはアプリ全体の起動完了時間や総メモリの計測ではない。DOMのネイティブ領域はJSヒープ値に含まれず、スマホはChromiumのエミュレーションでSafari実機ではない。年入力の実イベントで-122999と現在への復帰を両設定で確認。画像は外部通信遮断下で凡例を強制表示したコンポーネント確認。
