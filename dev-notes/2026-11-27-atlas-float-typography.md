利用者の発注書のうち、Atlas パネルの見た目と表示部品。

## 変えたこと
- **グローは文字の形だけ**: フローティング時、利用者自身のメッセージの吹き出し（グラデーション矩形）を背景オフでは外し、回答と同じ白文字＋text-shadow に統一。入力欄・時計の文字も面の色に合わせた text-shadow を持つ。矩形の背景や box-shadow でグローを代用しない。
- **フロストグラス背景のスイッチ**（既存の「背景」ボタン）: 背景オン時は不透明度を 58% → 34%、角丸を 22px → 14px（少し四角く）。オン時はグローをオフ。
- **組版**: `.atl-md` の行間 1.62 → 1.7（フローティングは 1.75）、段落間 1.5em → 1.35em、リスト前後 .6/1.15em、項目間 .3em → .42em（ゆるい箇条書き .7em）。モデルの書式は縛らない（CSS のみ）。
- **撤去**: 回答下の「Atlas が地図に描いたもの／説明の図 1」チップ行（`artifacts`/`artifactsHtml`/`focusArt` と CSS）。同じ図形は地図上と Objects で見られ、出典があるものは出典リストに載る。出典を述べていない図形の「Atlas が作図 — 出典は記録されていません」行も出さない（出典を名乗らない行は出典ではない）。ツールが `provenance kind 'figure'` を述べたときの行は残る。
- **改名**: 回答下の「当時の地図」ボタン → 「この回答の表示に戻す」（カメラ・年代・重ねた図形を回答時点へ戻す能力は残す）。歴史地図の「当時」と紛らわしかったため。

## 引き継ぎ（消したものの役目）
- 図形への移動: Objects からの選択。図形の出典: 出典リスト（述べたものだけ）。
- 回帰: `tests/atlas-float-typography-checks.test.mjs`、`tests/atlas-answer-sources-checks.test.mjs`（④⑥⑦を改訂）。

## i18n の床を下げた理由
撤去したチップ行と改名したボタンの訳文（de/es/ru の位置引数 2 行、fr/ko/zh/zh-hans の inline 2 行と、それを引く到達不能な ui 行）は、画面から消えた文言のもの。`i18n-dead-key-codemod --write` で消し、`tests/i18n-coverage-floor.json` を `--update-floor` で更新（残る言語の訳を減らしたのではなく、表示する文言そのものが無くなった）。
