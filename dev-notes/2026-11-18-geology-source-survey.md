date: 2026-11-18

〈依頼〉 Atlas の地図説明が「糸魚川静岡構造線」を実形状で描けるよう、産総研 地質調査総合センターのデータを
`resolveShape` の梯子の典拠として足す（OpenStreetMap には構造線もフォッサマグナの面も無い）。
**結論: 名前で引けて実形状を返し、商用で使える典拠が 2026-11-18 時点で無いので、コードは足していない。**
名前の一覧を手で書いて地質図の線へ結ぶのは `no-ad-hoc-hardcoding.md` が禁じる形なので、それもしない。

## 0. 測った（2026-11-18）

**20万分の1日本シームレス地質図 V2**（https://gbank.gsj.jp/seamless/）
- 規約: 政府標準利用規約 2.0（CC BY 4.0 互換）。gsj.jp/license/license.html に「商用利用も可能」。申請不要・出典表記必須
  （例「産総研地質調査総合センター，20万分の1日本シームレス地質図V2（地質図更新日：2026年5月10日），https://gbank.gsj.jp/seamless/」）。
  「シームレス地質図」は登録商標。
- Web API 1.3.1: タイルは**ラスタ PNG だけ**（layer `l`＝地質境界・`f`＝断層、z10–13）。`legend.json?point=` は点の年代・岩相を
  返すだけで形を返さない。名前検索は無い。CORS は `Access-Control-Allow-Origin: *`。
- ベクタは `seamlessV2.zip`（267,527,356 B）だけ。中の `seamlessV2_line.dbf` を全件読んだ: **546,099 本、欄は
  `Major_Code` / `Legend_J` / `Legend_E` / `styleidx` / `MERGE_SRC` / `Shape_Leng`**。`Legend_J` は
  境界 330,298・実在断層 170,881・海岸線 29,119・伏在断層 9,518・推定断層 5,837・撓曲 419・図郭 27 の**線種だけ**で、
  断層にも構造線にも**名前が無い**（`MERGE_SRC` は処理経路の 2 値）。面の凡例も年代×岩相で、地域名の単元を持たない。

**活断層データベース**（名前付きの断層帯を持つ産総研の典拠）
- https://gbank.gsj.jp/activefault/ は「メンテナンス中」。gsj.jp のお知らせ: 2026-10-22 からセキュリティ予防措置で
  gbank.gsj.jp を一部停止、シームレス地質図は 11-02 に再開、活断層 DB は再開の告知なし。

**J-SHIS（防災科研）**——比較のため
- `fltinfo` API は `ltename`（例「中央構造線断層帯（五条谷区間）」）を返すが、引く鍵は**断層コード**で、形は
  地震動予測用の**震源断層面の矩形**（地表のトレースではない）。構造線の線として描けば別物で代用することになる。
  規約（/agreement 第5条）は加工物の頒布を認めるが、販売には「申請が必要になる場合」があり、API 出力が対象かは書かれていない。

## 1. 否定された見立て

- 「シームレス地質図の断層レイヤに構造線の名前が付いている」——付いていない（上の全件集計）。
- 「Web API で名前から線を引ける」——API にベクタも名前検索も無い。

## 2. 次の人のための事実

- 活断層 DB が再開したら、その規約・API（名前で断層帯を引けるか・形式・CORS）を一次資料で確かめ直す。
  「上流に無い」は今日の観測であって永久の事実ではない（`historical-verification.md` §5）。
- 名前の無いシームレス地質図でも「この範囲の断層・地質境界を描く」能力は作れる（名前でなく範囲で引く）。
  これは今回の依頼の外なので手を付けていない。
