## R425 — **一覧が隠していたのは「その国家が持っていた土地」ではなく「いつか持つことになる土地」だった**

依頼は本番（builds R415 / R416）で測った食い違いから来ている。「1938 年と 1939 年、歴史地図は
ラトビア・エストニア・リトアニアを描いているのに、Countries 一覧にその行が無い。現在に戻すと
3 行とも在る。」——境界も測られていた: **1938-06 と 1939-09** では era レイヤーが 3 国を
`_same=1` かつ `_modName="Latvia"` 等で描く（＝**ラベル経路は 3 国を現代名の現存国だと正しく
判定している**）のに一覧に行が無い。**1940-08 と 1941-06** では地図からも消えてソ連に吸収され、
そちらは正しい。

### 再現

`js/history.js` の `histStates` を素の node で走らせ、`apply(date)` の後に `_histHidden` が
立っている符号を数えた（`countryStats` は各コード 1 行のスタブ）。

| 日付 | LVA | EST | LTU | MDA | FIN | POL |
|---|---|---|---|---|---|---|
| 1930-01-01 | ✗ | ✗ | ✗ | ✗ | ✓ | ✓ |
| **1938-06-01** | **✗** | **✗** | **✗** | ✗ | ✓ | ✓ |
| **1939-09-01** | **✗** | **✗** | **✗** | ✗ | ✓ | ✓ |
| 1941-06-01 | ✗ | ✗ | ✗ | ✗ | ✓ | ✓ |
| 1991-10-01 | ✗ | ✗ | ✗ | ✗ | ✓ | ✓ |
| 現在 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

### 原因——`succ` は「territory の一覧」であって「保有期間」ではなかった

`SUN` の行は `from:'1922-12-30'` で、`succ` に 15 の現代国を持つ。`apply()` は

```js
S.succ.forEach(c=>{ if(countryStats[c]){ countryStats[c]._histHidden=true; hidden.add(c); } });
```

——**`succ` の全部を、その国家の存続期間の全部にわたって**隠していた。ソ連がバルト三国を
併合したのは 1940 年なので、**1922 年から 17 年ぶん、実在していた 3 つの国が一覧から消えていた。**

⚠⚠⚠ **同じ表が、フィンランドとポーランドについては偶然正しかった。** 3 国と同じ年に
ロシア帝国から離れたこの 2 国が 1938 年に並んでいるのは、`RUE` が 1917 年で切れていて
`SUN` が 2 国を名指していないから、ただそれだけである。**レジストリはこの違いを判断して
いなかった**——正しい答えと間違った答えが、同じ 1 つの規則から出ていた。

⚠⚠⚠ **#R380 は 1 段上で同じ規則を書いている**——«each era bound is the polity's OWN start
date, not the window's»。オーストリア＝ハンガリーと朝鮮について**国家の**下限を直したもので、
**後継国の段には降りていなかった。後継国の下限も、その後継国自身のものである。**

⚠ これは #R410 とは**別の機構**である。#R410 は `js/time-borders.js` の `tagSame` が era 名を
一手前の年で解決していた問題で、**ラベル側**の欠陥だった。今回はラベル側が正しく、**一覧側に
その国家が存在しない**。

### 直し方——`held` と、`succAt()` という 1 つの式

`succ` の各要素が自分の窓を持てるようにした。

```js
held:{ LTU:['1940-06-02','1991-09-05'], LVA:['1940-06-02','1991-09-05'], EST:['1940-06-02','1991-09-05'] },
```

窓を宣言しない後継国は今までどおり（＝国家の存続期間そのもの）。読み手は 1 つの式に畳んだ:

```js
function succAt(S,date){ … }   /* その日にこの国家が実際に保有していた後継国 */
```

⚠⚠ **同じ事実の読み手が 3 か所にあった。** `apply()` の隠蔽、`agg()` の集計、そして
`js/time-borders.js` `tagSame` の `_cov`（「この年この国家が覆っている後継国」——era 改名を
吸収済みの国に二重掛けしないための集合。コメント自身が「一覧が同じ理由で行を隠す」と書いて
いた）。**同じ事実を別々の規則で読む**のは #R410 が 1 ラウンド費やした形なので、3 つとも
`succAt()` を呼ぶ。`resolveHist` の「隠れている現代国を吸収した国家」の逆引きも同じ式にした。

### 日付は自分で選ばなかった——そしてそれが正解だった

⚠⚠⚠ 最初に書こうとしたのは **Wikipedia の併合日**（リトアニア 1940-08-03・ラトビア 08-05・
エストニア 08-06）だった。**それは間違いになるところだった。** この年に地図が描く国境は
`data/cshapes.js`（CShapes 2.0・1886 年以降のこのアプリ自身の国境出典）で、CShapes は
**3 国とも 1940-06-01 で終え、3 国とも 1991-09-06 で再開する**（後者は USSR 国家評議会が
3 国の独立を承認した日）。一覧が 8 月・地図が 6 月で切り替われば、**6〜8 月の 3 か月は
「地図と一覧が別のことを言う」状態**——#R410 が 1 ラウンド費やしたのと同じ形になる。

⇒ 窓の両端は **地図が読むのと同じファイル**から取り、検査 ② が同じファイルから引き直す。

⚠⚠ **そして窓は、その span の「補集合」である。** #R421 が `csFC` を日単位にした結果、CShapes の
終了日が**内包**であることが効くようになった——ラトビアは **1940-06-01 まで描かれ**、ソ連自身の
ポリゴンが形を変えるのは **1940-06-02**。つまりソ連が保有していたのは `1940-06-02` からで、
`1940-06-01` からではない。同じく 3 国が再び描かれるのは 1991-09-06 なので、保有の最終日は
**1991-09-05**。⚠ **rebase で R421 が入るまで、この 1 日は見えなかった**（July-1 標本では
どちらの端も年の中に落ちない）。⇒ 窓は `[1940-06-02, 1991-09-05]`、検査 ② は
「`from` の前日に終わり `to` の翌日に再開する polity」を探す。**どちらの端を 1 日ずらしても ② が赤**。

実測: CShapes で「1940-06-01 に終わり 1991-09-06 に再開する」polity は **ちょうど 3 つ**
（Estonia / Latvia / Lithuania）で、その間に span を 1 つも持たない。**変異ハーネスで併合日に
差し替えると ② が赤**になる。

⚠⚠ **窓を持たせてはいけない後継国がある。** モルドバは 1922〜1940 年もソ連領ではなかったが、
CShapes に **1991-08-25 より前のモルドバは無い**——ベッサラビアはルーマニア領で、モルドバは
**独立国でも無かった**。窓を与えれば 1938 年の一覧に存在しない国が並ぶ。窓は
「この後継国はそのとき**自分の国**だった」の意であって、「この国家がその土地を持っていなかった」
の意ではない。表のコメントにそう書いた。

### その窓を、一覧は見ていなかった——年が変わらない限り

⚠⚠⚠ 窓を入れたあと、実際のブラウザで測って**半分しか届いていなかった**ことが分かった。

```
1940-03-01 → 1940-08-01   LVA:✓ EST:✓ LTU:✓   ← 窓を越えたのに何も起きない
1937-01-01 → 1940-08-01   LVA:✗ EST:✗ LTU:✗   ← 同じ日付。年をまたいだから効いた
```

`js/time-countries.js` の時計リスナに **`if(y===curYear) return;`**（同じ年なら年次データは
変わらないので何もしない）があり、**その早期返却がレジストリの再適用ごと飛ばしていた**。
年次データ（Maddison / HDI / 世界銀行）については正しい——しかしレジストリは
**年ではなく瞬間で鍵されている**。しかもこれは今回の窓だけの話では無い——
**レジストリの存続期間は元々全部が実の日付**である（オーストリア＝ハンガリーは
1918-11-11、ソ連は 1991-12-26）。実測: 修正前は **1918-10-01 → 1918-12-01 で一覧が
「オーストリア＝ハンガリー」のまま**だった——解体から 3 週間後である。

⚠ **#R421 が時計を日単位にし、国境はそれに従ったが、このオーバーレイは従っていなかった。**
`shownYear` の横に #R421 自身が「瞬間から derive されるので、下の国境が日精度になっても
これは『画面に出ている年』に答える」と書いている。その境界が、年の途中に境を持つ
窓を入れた瞬間に問題になった。

⇒ 年次データのスキップはそのままにし、**日に依存する半分だけ**を `applyHist()` にして
両方から呼ぶ。同じ年でも `curWhen` （最後に適用した瞬間）が動いていれば再適用して再描画する。
ネットワークは 1 バイトも増えない。

実測（ビルド済み bundle ・修正後）:

| 日付 | LVA | EST | LTU | ソ連 | A＝H |
|---|---|---|---|---|---|
| 1940-03-01 | ✓ | ✓ | ✓ | ✓ | ✗ |
| **1940-06-01** | **✓** | **✓** | **✓** | ✓ | ✗ |
| **1940-06-02** | **✗** | **✗** | **✗** | ✓ | ✗ |
| 1940-08-01 | ✗ | ✗ | ✗ | ✓ | ✗ |
| 1940-05-01 | ✓ | ✓ | ✓ | ✓ | ✗ |
| 1918-10-01 | ✓ | ✓ | ✓ | ✗ | **✓** |
| 1918-12-01 | ✓ | ✓ | ✓ | ✗ | **✗** |

年をまたぎない移動でも**境の両側の 1 日**が分かれ、到着した日付が同じなら
**どの年から来ても同じ世界**になった。オーストリア＝ハンガリーの 3 週間も同じ変更で消えている。

### 触っていないもの（推定ではなく実測して残した）

`js/stats-compare.js` は `S.succ` を 8 か所で読む（`_madMap` / `_histMadVal` /
`_histAddLatest` / `_histAddSeries`）が、**窓の影響を受けない**ことを測ってから残した:
`_histMadVal` は `M.has('SUN',year)` が真なら合算せず Maddison を直接使い、
**`data/maddison.json` の SUN で欠けているのは 1941–1945 の 5 年だけ**——いずれも窓の内側で、
窓ありの集合と全集合が一致する。WB 経路は 1960 年以降しか値を持たないので同じく内側。
`_madMap` は取得対象を広げるだけの上位集合。

⚠ 調査中に **`js/stats-compare.js:221` に #R380 と同じ形の未修正欠陥**を見つけた
（`_histMini()` が `S.name.en` / `S.name.jp` を読むが `name` はタプル＝配列なので `undefined`、
`cName()` を通ると **「—」**。19 行すべて該当。#R380 は `js/history.js` だけを直し、
`tests/r380-checks ⑨` の走査対象も `js/history.js` だけだった）。**今回の依頼の範囲外なので
直していない**——別件として起票した。
