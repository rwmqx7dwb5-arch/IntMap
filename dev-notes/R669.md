## R669 — **上流が持っていないものと、こちらが粗く持っていたもの——歴史区分の欠落は 3 つとも別の原因だった**

> 「歴史的地方区分の境界線のcoverageがくそ。全時代、全地域で完璧に網羅しろ。日本は北半分の令制国が全滅。
> ふざけんじゃねーよ。クリックしたときのハイライト線が線に比べて解像度が低い。」

前半は #R604 が同じ言葉で受け取った報告の**残り**で、後半はその回が直さずに残した半分だった。
測ってみると欠落は 1 つではなく **3 つの別々の原因**で、うち 2 つはこちらの欠陥、1 つは上流の空白だった。

### ⚠⚠⚠ ① クリックのハイライトは、線とは別の記録から描かれていた

#R604 は era の**線**を束から OpenHistoricalMap のベクタタイル（原寸）へ移した。理由は
「束は解像度を 1 つしか持てないが、地図は 20 持つ」。**クリックだけが束に残った。**

| | 伊豆国（OHM relation 2687374） |
|---|---|
| 上流（Overpass `out geom`） | **2,800 頂点** / 周長 787 km / 平均間隔 281 m |
| 出荷している束（DP 0.02°・小数3桁） | **29 頂点** |

同じ画面の同じ瞬間に、**100 倍粗い形が、アクセント色で「あなたが触ったのはこれです」と言っていた。**

⚠ **直し方は「束を細かくする」ではない。** #R604 が値段を測っている——0.008°・小数4桁で第1級だけ 15.5 MB、
しかも**それでも解像度は 1 つ**。クリックが違うのは、それが **1 件を名指す**ことだ。1 件なら丸ごと取れる。

- feats の**列 10 に OHM の relation id** を持たせた（`scripts/build-hist-admin1.mjs`）。
  ⚠ **名前で訊かない。**「伊豆国という名前のもの」を上流に訊くのは #R515 が禁じたやり方で、
  relation 2687374 は別の単位を返しようがない。
- クリックで `relation(id:N);out geom;` を 1 本。**実測 148 KB / 789 ms**、単位ごとにセッション 1 回だけ（memo は 24 件で打ち切る——
  148 KB の形をページの寿命ぶん全部抱えるのは、キャッシュの名前をした漏れである）。
- **粗い形はタップの瞬間に出す。** 真の形が届いたら**同じ source を差し替える**（レイヤーを増やさない・間に消さない）。
  届かなければ粗いままが残る＝この回の前と同じ。

**`js/ohm-rings.js` を作った**——「OHM の relation → GeoJSON ポリゴン」の**唯一の持ち主**。
順序も向きもばらばらな member way を 1 本のリングに閉じ、内側のリングを穴にする規則は、
これまで `scripts/build-hist-admin1.mjs` の中だけにあった。クリックが同じことを必要とした以上、
2 つ目を書けば**片方を触った日に答えが 2 つになる**。build は vm でこのファイルを評価する
（`scripts/build-whs.mjs` が `js/lang-registry.js` を読むのと同じやり方）。
⚠ **面積の下限は既定 0 で、下限を渡すのは build だけ。** 小片は 25 MB の束から落とす価値があり、
**読者が今タップした 1 単位から落とす価値は決して無い**——そこでは小片がその単位そのものかもしれない。

### ⚠⚠⚠ ② 日付の無い記録を捨てていた。理由として書いてあったことが、13 件すべてについて偽だった

`scripts/build-hist-admin1.mjs` は `!start_date && !end_date` の relation を `continue` していて、
そこには「それは `ref-admin1` がライブのタイルから描く**現行の**単位だから」と書いてあった。

実測（2026-09-10）、落ちていたのは **13 件**で、そのうち 1 件も現行の第1級単位ではない:
**安房国・壱岐国**（1871 年に廃止された令制国）、**東海道・山陰道・西海道**（それらが属した道）、
Ziemia Płocka、Ziemia Wyszogrodzka、Stockholm、Dahme-Spreewald、Bodenwerder、Столінскі раён ほか。

⚠ **しかも線は前から描かれていた。** `js/hist-scale.js` の `ohmFilter` は `start_decdate` を持たないタイル地物を
**全日付で通す**——「期間を述べていない記録は、どの期間からも排除できない」から、意図的にそうしてある。
つまりこの `continue` は**単位を地図から消してはいなかった**。消していたのは
**その単位が何であるかを地図が言う能力**——ラベルも、クリックの答えも、件数も。

開いた端はもともと下で処理されている（`w.s || [SINCE-200,…]` / `w.e || [9999,…]`）ので、
日付の無い記録は**両端が開いた記録**というだけのこと。それが上流の言っていることでもある。

### ⚠⚠ ③ `boundary=administrative` という**綴り**を要求していた

| OHM の relation（admin_level 3–6） | 件数 |
|---|---|
| 全部 | 28,211 |
| `boundary=administrative` | 27,662 |
| それ以外 | 549 |

549 のうち **538 は別種のもの**が level 欄を借りているだけで、正しくこのレイヤーの管轄外
（religious_administration 431・census 79・statistical 18・election・disputed）。
**残り 11 は、タグが無いだけの第1級区分**だった——**直隸 Chihli**（admin_level 4・1644–1911）、
CdZ-Gebiet Elsaß、Augustan Italian provinces。
`type=boundary` に level があって competing な `boundary` 値が無いなら、それは**書き手が語を書かなかった行政境界**である。

②と③で **feats 4,679 → 4,820**（第2級は 22,708）。

### ⚠⚠⚠ ④ 令制国 15 国は、こちらの欠陥ではなかった——OHM に **relation として存在しない**

名前が「国」で終わる admin_level 3–4 の relation は、OHM に**ちょうど 53 件**。
欠けているのは **陸奥・出羽・信濃・越後・上野・下野・美濃・飛騨・若狭・越前・加賀・能登・越中・佐渡・隠岐**
——**東山道と北陸道の全部**、つまり畿内と東海道の海沿いを除く北と東の全部。
⚠ **OSM 本体も 53 件**で、しかも欠けている場所が 1 つだけ違う（OSM は隠岐があり近江が無い／OHM はその逆）。
**両方の和集合でも 54/68。**

68 国そろうデータセットは 2 つあり、**どちらも public リポジトリから配れない**:

| | 中身 | ライセンス |
|---|---|---|
| CODH 旧国・旧郡境界データセット | 85 単位・陸中だけで 24,584 頂点 | **CC BY-NC 4.0**（上流の人間文化研究機構から継承。非商用は下流で緩められない） |
| Harvard Dataverse "Japan Tokugawa GIS" | 68＋松前・WGS84 | Dataverse のメタデータは **CC0**、同梱 README は「非商用の学術目的のみ」、別 README は **CC BY-NC-SA**。**自分と矛盾するライセンスは、再配布の根拠にならない** |

GitHub 上の写しは、測った限り全部このどちらかに行き着く。

**そこで導出した**（利用者の指示: 「高精度ポリゴンを自作しろ。」）。`scripts/build-hist-kuni.mjs` → `data/hist-kuni.js`。

- **範囲**は Asukana/Ryoseikoku_20230626_TSV（**CC0 1.0**）の **663 枚の z10 タイル**（256×256 の整数コード）。
  **1 セル = 経度 0.001373°（36N で約 112 m）**——**OHM 自身が伊豆国を描く平均間隔 281 m より細かく**、
  出荷している束の 0.02° より 16 倍細かい。セル境界を厳密に辿り（近似も閾値も無い。**四角形の集合の境界は
  単位線分の集合そのもの**）、共線を潰し、半セルの Douglas–Peucker で階段を落とす。
  ⚠ **73 の領域を 1 回のグリッド走査で辿る。** 2.24 億セルを国ごとに舐めれば 73 周になる。
- **名前**は **Wikidata（CC0）**。令制国クラス Q860290 の座標（P625）が領域の中に落ちたものを採る。
  ⚠ **ラスタ自身の年（1868）に有効なものだけ**（P571/P576）。これを入れないと **諏方国**（721–731）の座標が
  信濃の領域に入っていて、**11 世紀前に消えた国の名前で信濃国が描かれた**（実測）。同じ 1 つの規則が、
  1869 年の分割が作った 7 国（陸中・陸前・岩代・磐城・羽前・羽後と 2 つ目の陸奥）もまとめて外す。
- ⚠⚠ **1 つの国が複数のラスタコードのことがある。** このラスタは本州の北端（現在の青森県）を陸奥の残りと
  別コードにしている。**コードごとに 1 国**と決めた最初の版は、**陸奥国を 40.45°N で止め、青森県を空白のまま描いた**
  ——この回が答えるべき苦情そのもの。なので**先に解決してから、解決先ごとに束ねる**。
  ここには「その 2 つは陸奥だ」と書いた行は無い: 片方に陸奥国自身の座標があり、もう片方に青森県があり、
  **青森県が Wikidata で「1869 年の陸奥国を継いだ」と述べ、その 1869 年の陸奥国が「古典的な陸奥国を継いだ」と述べる**。
  1 ホップ、記録に訊いた結果。
- ⚠ **OHM が既に持つ単位は出さない。** 判定は 15 個の名前の一覧ではなく **`data/hist-admin1.js` との join**
  （これで 50 単位が落ちた）。**上流に越後国が登録された日、この build は何も編集せずに出すのをやめる。**
  手で書いた 15 個の一覧なら、その日から二重に描き続ける。
- 出せなかったコード（build が印字する）: 2（種子島・屋久島）・37・59（安房。OHM が持つ）・70（蝦夷地）・
  71（千島）・89（伊豆諸島）・90（琉球）——令制国でないか、OHM が既に持つ国のもの。

結果 **15 単位・6,425 リング・82,199 頂点・1.67 MB**。

**描画**: これらは **relation id が null**——「タイルが運びようがない」ということが**行に既に書いてある**。
新しい `imta-gap-line`（source `imta-gap-src`）がその線を**タイルの生死に関係なく**描く
（束の線 `imta-line` はタイルが死んだときだけ立つ、という #R604 の規則はそのまま。
⚠ **タイルが生きていることが束の線を隠す理由であり、まさにそれが、この 15 国を一緒に隠してはならない理由**）。
塗りは `imta-line` / `imta-vt-line` と**同一**——どの供給が答えたかがスタイルの差として見えてはならない（#R212）。
束は `_D` に**追記**する: 横に置けば第2の epoch index・第2のラベル層・第2のクリック経路・第2の件数、
つまり**互いに食い違える場所が 4 つ**できる。

### ⚠⚠ ⑤ ビルドのキャッシュは、relation の**位置**で鍵を作っていた

`g<先頭id>-<長さ>.json`。**relation を 1 件足すと以降のバッチ境界が全部 1 つずれ、
4,699/4,776 件を持っていたディスクキャッシュが丸ごと迷子になる**——実測 **3.4 GB・Overpass 約 40 分**が、
18 件のために。relation のジオメトリは**その relation についての事実**なので、その id で置く（`rel/<id>.json`）。
既存のバッチは起動時に 1 度だけ展開して置き換える（実測 4,699 件を再鍵付け、追加の取得は **27 バッチだけ**）。

### 検査

- **`tests/r669-checks.test.mjs`（13 件）**。`js/ohm-rings.js` を **vm で評価する**（#R505: ソースを読む検査は
  関数が何を返すか見られない）——ばらばらの way が 1 本のリングに閉じること、内側のリングが穴になること、
  outer/inner 以外の role が面に入らないこと、**面積下限が既定 0** であること、

  ほかに束の全行に relation id があること、**安房国・壱岐国が両端開放で入っていること**、
  クリックが id で訊くこと、粗い形→鋭い形が**同じ source の差し替え**であること。

  「最後にビルドした機械でだけ緑」＝ゲートが無いのと同じになる。**出荷したバイトの不変条件**
  （relation id が null・9 言語の名前・リングが閉じる・**hist-admin1 と 1 件も重ならない**＝二重に描かない・
  1 単位 100 頂点以上）は常に走り、ラスタからの再導出はラスタがある機械でだけ走る。**どちらが走ったかを印字する。**
  `scripts/test-parallel.mjs` と `.github/workflows/ci.yml` の両方に登録した（#R381 の「呼び手のいない `check:*`」を作らない）。
- **`data/border-coast.js` を再生成した**（束が変わったので）。リング **25,506 → 40,117**

  この 2.1 kB を遅延させると「タップしたが、まだ読み込まれていない」という失敗の形が 1 つ増える。
