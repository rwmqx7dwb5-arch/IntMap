## R492 — **返答は読むものだったが、読みながら引けるものではなかった**

依頼は Atlas の返答の中に置く3つの小機能だった——数値にホバーで単位変換、日時にホバーで
ローカル時刻、略語にホバーで正式名称と意味。3つとも「本文のある綴りを見つけて印を付ける」
仕事なので、**壊れ方も3つとも同じ形**をしている: 見つけすぎるか、見つけたものを読み違えるか、
付けた印が消えるか。

### ① 印は「描いたあとの DOM」ではなく「描く前の文字列」に入る

最初に決めるべきはここだった。`js/atlas-console.js` の `_atlCompose(ai)` は、吹き出しの
`innerHTML` を `ai.__atlResults` の HTML 文字列から**毎回まるごと組み直す**——ツールを N 件
使ったターンでは **N+1 回**（`runActions` の末尾とターン終了時の2か所から呼ばれ、`_runOne` が
アクションごとに `runActions` を呼ぶ）。したがって「返答が描かれたら DOM を歩いて span を巻く」
実装は、**次のアクションが終わった瞬間に消える**。

そこで一手は `mdMini`（`js/atlas-reply.js`）の中、**プレースホルダ復元の直前**に立っている。
その位置には2つの性質がある——

1. コードブロック・数式・GFM 表は、その時点でまだ **PUA の 1 トークン**である。だから
   「`\`10,000 ft\`` と書かれたコード片を換算してしまう」は**起こりようがない**。
2. 本文は完成した HTML なので、`annotateAtlasHTML` はソースを `<…>` と「それ以外」に割り、
   **テキストの側だけ**を書き換える。見出しの `style="font-size:1.3em;margin:1.05em 0 .3em"` は
   属性の中なので走査に入らない（入っていたら `1.3 em` `1.05 em` `.3 em` が全部「量」に見える）。
   `<a>` と `<code>` の**中身**も飛ばす——リンクの表示文字とコードの中の数字は散文ではない。

⚠ **表のセルだけは例外で、`_atlCellFmt` が同じ設定オブジェクトを受け取って自分で通す。**
上の 1 の裏返しで、最後の走査から見ると表は 1 トークンであり、そこに手が届かないからである。

### ② 数の区切り記号は表で決められない

`10.000` は英語で **10**、ドイツ語で **10000**。どちらも正しいので、「ピリオドは小数点」と
書いた表はどちらかの言語で必ず間違える。区切りは `Intl.NumberFormat(locale).formatToParts()`
に訊き、**その約束に合わない綴りは注釈しない**（`parseQuantityNumber` が `null` を返す）。
英語の `10 000` と英語の `1,5` はどちらも読まずに素通りする。**誤った換算は、換算しない
ことよりずっと悪い**——読者はカードに出た数を確かめない。

実測（`tests/r492-checks.test.mjs` ④）: 同じ 8 文字 `10.000 ft` が、英語で `≈ 3.05 m`、
ドイツ語で `3.048 m`。どちらもその読者にとって正しい。

### ③ 曖昧な綴りは、1つ許すたびに正しい注釈より多くの誤りを出す

語彙から**意図的に外した**もの: 裸の `in`（英語の前置詞——「1 in 5 households」）、裸の `NM`
（ナノメートルと海里）、裸の `M`（地震のマグニチュード。`m` は小文字だけがメートル）、`g`
（グラムと重力加速度）、`t`（トンの系が3つある）。加えて、通貨記号の直後の数は入口の後読みで
落とす——`$5m` は 5 メートルではない。略語は**その返答での初出 1 回だけ**印が付く
（`seen` は `mdMini` 1 回ぶんの設定オブジェクトの中にあり、返答をまたがない）。

### ④ 丸めたことを隠さない

`10,000 ft` は `3,048 m` **ちょうど**、`68°F` は `20 °C` **ちょうど**、`120 miles` は
`≈ 193 km`。表示桁で丸めた値が元の値と一致しないときだけ `≈` が付く。依頼文は「120 miles →
193 km」と書いていたが、193.12128 を 193 と書くのは丸めである。**印が事実を1つ増やすなら、
その事実は正確でなければならない。**

### ⑤ `title` 属性は使わない

ネイティブのツールチップは 1 秒待たされ、体裁を選べず、タッチでは出ない。そして `title=` は
i18n の属性監査（`scripts/i18n-attr-audit.mjs`）が読む面でもある。代わりに `data-atl-note` /
`data-atl-sub` を印に焼き、`document.body` に置いた 1 枚を document レベルの
`pointerover` / `click` で出す。CSS は **`#atlas-panel` で囲わない**——同じ返答が浮動パネル・
サイドバータブ・ワークスペース窓の3面に出るので、コードブロックや表の規則と同じ扱いにする。

### ⑥ 単位の綴り表は「未翻訳の組」に見える。だが翻訳したら壊れる

`npm run check:docs` が最初に赤で返したのはこれだった——`scripts/i18n-pair-audit.mjs`（第12の形・
「隣接データ枠に置かれた翻訳の組」）が `js/atlas-annotate.js` に **19 件**を数え、`Architecture.md`
§10.1 の OPEN GAP がそれを名指していない、と。

⚠ **OPEN GAP に足すのは間違いだった。** あの register が言っているのは「fr/ko/zh で英語に落ちる
新しい fallback」であり、単位の綴り（`マイル` `Meilen` `英里`…）は**画面に出る文ではない**——
返答の中の綴りを**照合する入力**である。読者が見るのは換算後の「数＋単位記号」（`193 km`・`20 °C`）で、
それは9言語で同じ。register に足せば、**文書に嘘を1行書いて天井を1つ上げる**ことになる。

⚠ **正しい答えはリポジトリが既に持っていた。** `js/newsgeo.js` の首都名・媒体名の表は
`iso2|alias;alias;…` と**パックして** `@i18n-entity-data` を宣言している——「これは照合語であって
アプリが書いた文ではない」を**注釈ではなく構文で**言う仕組みで、監査は宣言を鵜呑みにせず
「行が非言語的な鍵（座標・ISO・ティッカー・ドメイン、あるいはパック文字列の `|`）を持つか」を
検証する。単位表を `U('mi|mi;mile;miles;マイル;…', 'km', 1.609344)` の形に畳むと、17 件が
**免除**として数えられ、`js/reference-data.js` の 143 件はそのまま 143 件で残る（天井は動かない）。

### ⑦ 綴りを固定していた2つの検査が、正しい変更で赤くなった

`_atlCellFmt` は引数を1つ増やし（設定オブジェクト）、`_atlBuildTable` も同じ理由で増えた。
`tests/r156 #2` と `tests/r159 #1` はその**綴り**を固定していたので落ちた。どちらも守っている
性質（GFM 表の構築子が在ること・セルの `**bold**` が平文に落ちること）は1ミリも変わっていないので、
**同じ性質を新しい綴りで固定し直した**（#R435 / #R488 と同じ形の逆側——今回は綴りが変わって
検査が正しく赤くなった側である）。
### ⑧ 起動費用は 1 バイトも増えていない

`npm run check:perf` の実測（#R491 の上に rebase したあとの数字）: **eager raw 0.0 kB /
requests 0 / modules 0**。増えたのは async だけ——`atlas-console` **+37.5 kB**（注釈モジュールと
語彙・略語 34 語）、`ui.fr` **+8.3 kB** / `ui.ko` **+7.4 kB** / `ui.zh` **+6.8 kB** /
`ui.zh-hans` **+6.9 kB**（68 本の訳）。**Atlas を一度も開かない読者は 1 バイトも受け取らない。**
天井は `--update` で記録し直した（eager 側は raw −467 B・gzip −101 B・brotli −149 B の**減**で、
ratchet は下向きにも動くのでそれも書き戻す。requests と modules は完全一致のまま）。

### ⑨ 「js/ の module は top-level 宣言を持ってはならない」に畳み込む

最初は語彙も正規表現も module のトップに置いていた。`tests/r175 ③` が正しく赤で返した——
**未 export の top-level 宣言は禁止**（それが classic script なら global だったもの）で、しかも
**誰も import しない export も禁止**（それは死んだ枝）。両方を同時に満たす形は 1 つしかない:
公開するのは 2 つだけ（`ATLAS_ANNOTATE_CSS` は `js/atlas-styles.js` が、`makeAtlasAnnotate` は
`js/atlas-reply.js` が名前で import する）、残りはその 1 つのファクトリの中に閉じる。
⚠ ファクトリは `makeAtlasReply` の**中で** 1 回呼ぶ——`js/atlas-reply.js` も同じ規則の下にいる。

### ⑩ `@i18n-entity-data` は「話題」ではなく「字句」である

表の直上に印を置いたあと、**その上の日本語の散文でも同じ字句を引用した**（「`@i18n-entity-data`。
理由は表の直上」）。`scripts/i18n-pair-audit.mjs` は印をコメント本文に対して当て、**印より後ろの
最初の宣言**を持ち主にする。つまり散文の引用は 2 つ目の印になり、持ち主は直後の `const U` に
なって、座標も ISO コードも持たないその宣言は正しく `misapplied` として拒否された
（実測: 印 2 件 → 41 行目の印が 45 行目の `const U` を指す）。**印は綴り直さず、意味だけを書く。**

### 検査

`tests/r492-checks.test.mjs` — 依頼の3例そのもの（①）、換算定数が SI の定義であることと往復
（①b）、時刻の4つの綴りと「ずれが無ければ何も言わない」（②）、帯名の無い時刻は放置（②b）、
略語の初出 1 回と 9 言語の両フィールド（③・③b）、ロケール準拠の数の読みと**読めない綴りの拒否**
（④）、タグ／リンク／コードに入らないこと（⑤）、**一手の位置を `js/atlas-reply.js` の本文から
読み出して**復元より前だと確かめること（⑥）、CSS がモバイルブロックの外で無スコープなこと
とテンプレートリテラルが 1 つも無いこと（⑥b・CONSTITUTION §2 の罠は「バッククォート」ではなく
「テンプレートリテラルの中の CSS」なので、**そもそも 1 つも無い**ことを構文木から確かめる）、
意図した「見つけない」（⑦）、台帳と試験一覧（⑧）。

⚠ **ブラウザでも実測した**（`npm run build` → `http://127.0.0.1:4492`）。実際の bundle の
`IntMapAtlasDebug.mdMini` に航空・地震・海洋の混ざった 1 通を通し、`.atl-chat` に入れて数えた:
**16 個の印**（うち表のセル 4・`<code>` の中 0）、CSS は注入済み、`text-decoration` は
`underline dotted rgba(128,128,128,0.34)` / `cursor:help`。`pointerover` を投げると `.atl-antip` が
`document.body` に 1 枚でき、`z-index:20000`・見出し「Exclusive Economic Zone」・説明 1 文・
印の 8px 上・左端 8px でビューポート内にクランプ、印に `title` 属性は無い。離れると `on` が外れる。
