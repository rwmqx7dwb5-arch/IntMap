## R722 — モデルを選ぶ権利は口座のもので、モデルの名前は上流のもの

〈依頼は 2 つ。「model を terra から sol に変えたい」と、「わたしのアカウントに関しては、
設定画面からモデルを自由に変えられるように。私に関しては、GPT 6 Astra も利用可能に」〉

### 1. ⚠⚠⚠ 切り替える前に測ったら、切り替え先が存在しなかった

本番の鍵で OpenAI に直接訊いた（一時的な `ai-diag` を置いて、同じラウンドで消した）:

| モデル | `/v1/responses` |
|---|---|
| `gpt-6-astra` | **200** |
| `gpt-5.6-luna` | **200** |
| `gpt-5.6-sol` | **403** `Project proj_… does not have access to model` |
| `gpt-5.6-terra` | **403** 同じ |

⚠ **`AI_MODEL` は 2026-07-21 から `gpt-5.6-terra` のままで、それは 403 を返し続けていた。**
つまり #R150 が「Terra に切り替えた」と書いた日から今日まで、**本番の Atlas に答えていたのは
fallback の Luna** であって、`Architecture.md` の「現行 `gpt-5.6-terra`」は**設定の値としては
正しく、答えているモデルとしては誤り**だった。fallback が仕事をしていたので誰も気づかない。

その場で切り替えれば 403 → 403 で Atlas が全滅するので、**いったん止めて権限を取ってもらった**。
権限が付いたあと、同じ経路で測り直して 4 つとも 200:

| モデル | この proxy 経由（`meta.model`） |
|---|---|
| `gpt-5.6-sol` | 200 |
| `gpt-5.6-terra` | 200 |
| `gpt-5.6-luna` | 200 |
| `gpt-6-astra` | 200 |

⇒ 依頼どおり **既定 `gpt-5.6-sol`・fallback `gpt-5.6-terra`**。secret も同時に更新し、
本番で `meta.model=gpt-5.6-sol` / `modelChosenBy=server` を確認した。

### 1b. 3 つの検査が「モデルを変えること」を落第させた

r147 ⑨・r150 ⑨・r151 ⑨ が **id を綴りで持っていた**ので、`AI_MODEL` が変えられるために存在する
まさにその値を変えると、この回と無関係な 3 本が赤くなる（#R515 の形）。⇒ **id の検査は 1 本に集め**
（r722 ⑦）、残りは**モデルが変わっても成り立つ事実**に述べ直した（既定がある・fallback は既定と
**別のモデル**である・fallback は model_not_found でしか使わない）。
そして r722 ⑦ は **#R150 が持てなかった検査**そのものである——`Architecture.md` が「現行」と書く
モデルを、出荷している定数と突き合わせる。⚠ 同じ理由で **app shell はモデル id を 1 つも書かない**
（r150 ⑨ を述べ直した。`js/legal-text.js` の古い綴りもここで落とした）。

### 2. モデルの一覧を書き留めない

選ばせるには「何があるか」を言う必要がある。これを**この リポジトリに書くと、書いた日の写真**に
なる（#R707）——そして写真が落とすのは、**開発者がパネルを開いた理由である新しいモデル**である。

⇒ `op:"models"` が各プロバイダの目録を訊く。Gemini は `supportedGenerationMethods` を**公表して
いる**ので「これは文に答えられるか」は読める事実として読む。OpenAI は能力欄を持たず、しかも
**プロジェクトが呼べないモデルまで列挙する**（上の実測: sol と terra は一覧に載っていて 403）。
⇒ **一覧は一覧として出し、呼べなかったらプロバイダの 403 をそのまま見せる。**

### 3. 選ぶ権利は口座のもの——ブラウザの自己申告ではない

`js/ai-core.js` の `aiDev()` は `localStorage` で誰でも立てられる（`js/auth-ui.js` が
「何の権限も与えない」と明記している）。**描くものを決めてよいが、走るものを決めさせない。**
サーバは `isDev`（`DEV_USER_IDS` の `auth.users.id`）で決め直し、開発者でなければ
`model` / `provider` を**黙って落とす**（「あなたは開発者ではない」と答えるのは探す相手に
手がかりを渡すだけ）。⚠ その `DEV_USER_IDS` は**そもそも未設定だった**ので設定した——
開発者口座は今日まで無料枠 10/日の扱いで動いていた。

### 4. 選んだモデルはフォールバックしない

403 の再試行は「**誰も特定のモデルを頼んでいない**」ときの正解で、プロジェクトが権限を失った
モデルが全読者の Atlas を殺さないためにある。試している本人が名指したモデルを黙って差し替えると、
**画面は走っていないモデルの名前を出す**。⇒ 名指しのときだけ抑止し、`meta.modelChosenBy` が
「developer」か「server」かを言う。

### 5. どこまで効くか

その口座が行う**全ての** AI 呼び出し（回答・語注・画像読み・地名解決）。
**無人の cron は口座を持たないので `AI_MODEL` のまま**（利用者の判断: 読者に見えないところで
高価なモデルを大量に消費させない）。
