〈依頼〉共通のイベントバスが無い。`CustomEvent` が点在し、綴りは `intmap:` と `intmap-` の 2 系統、
購読者も見えない。宣言表と `emit` / `on` / `once` を持つ `js/bus.js` を足し、既存の発行・購読を
全数発見して bus に寄せる（名前は変えない・挙動も変えない）。宣言に無い名前を使う新しいコードを
落とす門を足す。

## 0. 測った——移行前の姿（HEAD `b7978872`）

- イベントは **15 種**。投げるファイル **16**、聞くファイル **65**（`git grep` と acorn の発見が一致）。
- 綴り `intmap:…` は 2 種（`intmap:shakemap`・`intmap:ai-limit`）、残り 13 種は `intmap-…`。
- **`intmap-theme` は `js/space-sky.js` が聞いているのに、js/・src/・ページのどこも投げていない。**
  その読み手は一度も走らない。⇒ テーマを書く唯一の場所 `js/theme-sky.js` の `_applyThemeBody` が、`data-theme` が
  実際に変わったときだけ `bus.emit('intmap-theme')` するようにした（applyTheme は idle・基図の切替・設定保存の
  たびに再実行されるので、属性が変わらない再実行は変化ではない）。表は `from: ['js/theme-sky.js']` になり `orphan` は消えた
  （門 ③ が「聞かれて投げられない」と `orphan` の有無を一致させる）。`js/space-sky.js` の `data-theme` の
  MutationObserver は残っている——両方が `schedule` を呼ぶが rAF 1 つに畳まれる。
- 投げても誰も聞かないもの: `intmap-ecmwf`・`intmap:shakemap`・`intmap-newsgeo-world-ready`
  （ページ側の観測・spec のための合図として残す）。

## 1. 決めたこと

正本は `DECISIONS.md`「IntMap 自身のイベントは 1 つの宣言表に書き、配信は window のままにする」と
`docs/architecture/03-files.md`「イベントの結び方」。要点だけ:

- 配信は `window.dispatchEvent` のまま。payload が無ければ `Event`、あれば `CustomEvent`
  ——素の呼び出しが投げていた型と同じ。
- 正規名は `intmap-…`。`intmap:…` は別名で、`emit` は全綴りを 1 回ずつ投げ、`on` は自分の写しを捨てる。
  ⚠ **これで `intmap-shakemap` という window イベントが 1 つ増えた**（`js/shakemap.js` は bus に移った
  ので正規名と別名の両方を投げる）。聞いている読み手は 0。
- 宣言に無い名前は node と開発サーバで例外、本番 build（`import.meta.env.PROD`）は警告して通す。

## 2. 移したもの・残したもの

移した: 52 ファイル（`import * as bus from './bus.js'`。`window.addEventListener(name, fn)` →
`bus.on(name, fn)`、`{ once: true }` → `bus.once`、`window.dispatchEvent(new …Event(name, { detail }))`
→ `bus.emit(name, detail)`。外側の `try{}` はそのまま）。書き換えは acorn の位置で行い、手で並べていない。
`js/data-layers.js` は行数が減る一方の台帳（`scripts/layer-packages.mjs`）があるので import を既存の行に
並べた。`js/hist-places.js` は `removeEventListener` の対だったので `bus.on` が返す `off` を使う。

残した（表の `pending` と `WHY`）:

| 理由 | ファイル |
|---|---|
| `parallel` 並行作業との衝突を避ける | `js/map-ui.js` |
| `pinned` node の検査がソースの綴りを読む | ai-core・app-body（lang・sidebar-resize）・atlas-controls・compare（lang）・dash-extended・i18n-late・keyboard-shortcuts・layer-favs・mobile-ui（sidebar-resize）・news-events・news-sources・routing-ui・satellite・seismic・sims・supporter・time-borders（hist-identity）・workspace・world-packs |
| `script` node の検査が本文を classic script として評価する（import が立たない） | gazetteer・time-admin1 |
| `cycle` bus.js が import する持ち主（`MAP_ANSWER_EVENT`） | mobile-sheet |
| `scope` runtime の scope（`A.on`）が解除を持つ | radiation-layer |
| `injected` 呼び手が渡した window で聞く | layer-time-kernel |

⚠ 試して戻したもの: gazetteer・time-admin1・news-sources・mobile-ui の sidebar-resize は一度移して
対象の検査が赤になった（`new Function` で本文を評価／`asClassicScript`／綴りの固定）ので戻した。
`pinned` の列は、検査の側を評価に変えれば移せる。

## 3. 門

`tests/event-bus-checks.test.mjs`。一覧を持たず、場所をソースから発見して表と両向きに照合する
（宣言に無い名前・使われない宣言・`from` と `pending` の食い違い・payload の鍵）。わざと
`js/sidebar-style.js` に宣言の無い `intmap-foo` の発行と素の `intmap-units` の購読を足すと ① と ③ が
赤になることを確かめた（戻してある）。bus 自体は評価して配信・解除・once・別名の両向きを測る。
⚠ 接頭辞の無い名前を `new Event` で投げる新しいイベントは見えない（限界として門の冒頭に書いた）。

  `node scripts/perf-budget.mjs --update` でその 2 行だけ上げた。

  `EVENTS` の宣言表と `emit`/`on`/`once`）を切り出すと 5,612 字・単独 brotli 2,018 B。宣言表の `means` と

- `scripts/check-split-scope.mjs` の `walk` に `MetaProperty` の腕を足した。`import.meta` の 2 つの
  Identifier（`import`・`meta`）を参照として歩き、失われた closure 変数と誤報していた。
