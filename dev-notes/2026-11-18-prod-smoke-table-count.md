---
title: 配信後の smoke が数える表を、手書きの数ではなく配った js/tables.js から導く
date: 2026-11-18
---

〈依頼〉2026-11-17 の一括依頼の本番検証で見つかった、main の CI の赤。

- 本番配備の run は Build と Deploy が成功し、配信後の smoke `tests/prod-smoke.spec.js`（#R167）だけが
  「表は 25 個」で赤だった。本番は 24 個。Countries の値と年の作業で `LIFE` と `INTERNET` が抜け、`STAT_SOURCES` が
  足された——意図した変更で、部分配備ではない。
- 数は「部分配備を捕まえる」ために意図して手書きだったが、配信後にしか走らない（NEVER tier）ので、表を足し引きする PR の
  どの段からも見えず、毎回 main を赤くしてから直されていた（27 → 25 → 24）。
- 期待値を、その run がチェックアウトしている（＝配った）`js/tables.js` を Node で import して得た表の名前の集合にした。
  数ではなく名前の集合なので、欠けたときは「どの表が無いか」が出る。部分配備を捕まえる力は同じ。
  本番に対して単独で走らせて緑を確認。
