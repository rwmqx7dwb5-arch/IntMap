### 2. 場所は導出であって、綴りではない

`scripts/agent-memory.mjs`:

- 原本は `git rev-parse --git-common-dir` の親（`master-sync.mjs` と同じ導出）。
  だから **worktree からでも原本からでも同じ 1 か所**を指し、チェックアウトが動けば追従する。
- Claude Code の鍵は「絶対パスの非英数字を `-` に置換」。組み立てるので、
  **追跡ファイルにマシン固有の絶対パスが 1 つも増えない**——むしろ `AGENTS.md` §1 からは
  **消えた**（そこに書いてあった `~/.claude/projects/C--…/memory/` が `--path` の呼び出しになった）。
- `.codex/hooks.json` の `SessionStart` がこれを走らせ、`.codex/config.toml` の **C-7** が
  「学んだことは同じ場所へ書く」を要求する（Codex 自身の `/memories` にだけ書くと、また写しが 2 つになる）。

### 3. ⚠⚠ 切るときに黙って切らない／無いことは文にする

索引は 43 KB ある。hook には長さの上限があるので、**切る可能性が最初から在る**——
#R694 が「固定幅の窓は、本文が長いほど見なくなる」を実測した直後なので、同じ形を作らない:

- `--budget` は**落とした文字数**と**続きの読み方**（索引の絶対パス）を印字する。
- **場所を先に書く。** host がさらに切っても、戻り道だけは残る。
- メモリが無いマシンでは「無い」と**文で**言う（#R589）。空の出力は
  「まだ空」と「壊れている」を区別できない。
