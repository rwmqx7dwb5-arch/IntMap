# 現状仕様書の 18 章を事実を落とさずに縮める

`docs/architecture/` の 18 章は「今どうなっているか」の現状仕様書（`AGENTS.md` §9：変更履歴ではない）だが、
合計 1,129,644 B（案内図を含む）に育ち、主題の章を開いても通読できない大きさになっていた。恒久方針
`.agents/rules/substance-over-form.md` に従い、昨日の恒久指示（190 → 139 KB）・`DECISIONS.md`（203 → 115 KB）と同じやり方で
書き直した。物差しは「消したあと何が同じだけ働いているか」。

目標の半分（約 550 KB）には届かなかった。残りの 150 KB は、各章が持つ識別子（関数・ファイル・欄・拒否コード）と
不変条件そのもので、`docs/MAP-LAYERS.md`・`docs/GIS-CORE.md`・`docs/NEWS-EVENTS.md` などとの重複は既に消してある
（測った: 7.3 の凡例の配置、7.3f〜7.3i、8.1 の共有・絵葉書・引用、2.1 の Atlas のターンの規則は他の文書に無い）。
それを削るのは本質的な削除になるので止めた。13・14・18 と案内図は元から短く、手順と表なので触らなかった。

## 消した種類

- **経緯の物語**——「以前は…だった」「実測で N 回」「本番で〜が起きていた」の段落。不変条件の根拠になる数値は
  1 行で残した（例: 1885/1886 の政体数、天井の数、閾値と由来の定数名）。
- **他の文書が正本の事実の写し**——GIS カーネルの各規則（`docs/GIS-CORE.md`）、気象の読み込みの規則
  （`docs/MAP-LAYERS.md` §7.10）、出来事基盤の段（`docs/NEWS-EVENTS.md`）は、名前と要点を残してリンクにした。
- **同じ規則の言い換えと ⚠ の多重**。
- **理由の長い説明**——「なぜそうなっているか」は `DECISIONS.md` の仕事なので、仕組みを理解するのに要る 1 句だけ残した。

## 壊していないもの

- 章の見出しと節番号は全部同じ（`arch-split`・`section-refs` が緑）。読みやすさのために 4 章（05・07）に番号の無い
  `####`／`###` の小見出しを足したが、番号の空間は変わらない。
- `check:docs` が章から照合する事実（能力数・system prompt の本数と内訳・Edge Function の名簿と本数・表の数・CSP の
  directive 数と CDN 数・relay-guard を共有する本数・i18n の OPEN GAP・束の環の数・シート数・単位数など）はすべて
  残り、緑のまま。規則は 1 つも緩めていない。
- 検査が文言で読む文（1885/1886 の継ぎ目の政体数、`AI_MODEL` の現行モデルとフォールバックの梯子、§3 の台帳の文）は、
  事実ごと残した。一度これらを縮めて赤になり（`tests/chronos-claims-checks.test.mjs` ④・
  `tests/atlas-ai-proxy-models-checks.test.mjs` R722 ⑦・`tests/architecture-by-subject-checks.test.mjs`）、元の形に戻した。

## 作業のしかた（次に同じことをする人へ）

- 章ごとに書き直し、そのたびに `npm run check:docs` を回した。
- 仕様を読む検査が文字列と正規表現で何を固定しているかは、検査ファイルの文字列リテラルと正規表現リテラルを
  acorn で取り出し、元の仕様では当たって今は当たらないものを列挙して確かめた（偶然の一致——コメントやデータの
  中の綴り——は個別に読んで外した）。
