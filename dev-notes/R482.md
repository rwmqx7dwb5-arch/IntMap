## R482 — **降水レーダーの「Zoom Level Not Supported」は、200 で返ってくる絵だった**

依頼は1行だった。**「降水レーダー（実時間）レイヤーはある程度以上ズームしたら zoom level not
supported と透かしがなりますが、それが出ないようにしてください。」**

### 何が起きていたか

RainViewer の無料タイルキャッシュに、同じ1コマ（`/v2/radar/8013c75e85b9`）を各ズームで問い合わせた。
隣り合う2枚を並べているのは、**同じバイト列が返り始めた瞬間**を見るため。

```
tilecache.rainviewer.com  /256/{z}/{x}/{y}/4/1_1.png   （東京・2026-08-28）
  z4   200   4,656 B / 334 B      違う ＝ 本物
  z6   200  13,067 B / 1,216 B    違う ＝ 本物
  z7   200   8,765 B / 2,101 B    違う ＝ 本物
  z8   200   1,370 B / 1,370 B    ★ 同一ハッシュ 2cc6649e
  z9…z15                          ★ すべて同じ 1,370 B / 2cc6649e
```

その 1,370 B を展開すると、灰色の角丸の板に **「Zoom Level Not Supported」** と書いてある。
`/512/` でも同じ（3,269 B / 6227f878）。ニューヨーク・ロンドン・マイアミ・シドニーでも同じで、
**カバレッジの穴ではなくサーバ全体のズーム上限**である。

一方 `js/data-layers.js` はこう書いていた。

```js
addRaster("radar", tiles, 12);        // ← ラスターソースの maxzoom
```

**12 は、データが終わる場所より5段先**である。だから読者が z8 を跨いだ瞬間、MapLibre は
律儀に z8…z12 を要求し、灰色の板を5段ぶん受け取って地図に敷いた。z13 以降はその板を引き伸ばす。

### なぜ計器が1つも鳴らなかったか

⚠⚠⚠ **#R479（CARTO の「API KEY REQUIRED」）と同じ形である。** 通信は成功していて、失敗は
**画像の中に焼き込まれている**。`fetch` は 200、`onerror` は発火せず、コンソールは静かで、
タイル数を数える計器は「全部届いた」と言う。**ネットワークを見る検査はこの欠陥に対して永久に緑**
であり、実際 #R276 でこのレイヤーをループに作り直したときも、以後のどのラウンドも気づかなかった。

捕まえられるものは1つしかない——**このリポジトリが z8 以上を要求する綴りを持っているかどうか**。
それは静的に読める。だから天井に名前を与えた。

```js
const RV_MAX_Z = 7;   /* deepest zoom the free tile cache serves radar at (measured) */
…
addRaster("radar", tiles, RV_MAX_Z);
```

### なぜ「z7 より上でレイヤーを隠す」ではないのか

⚠⚠ **隠すと、依頼された状態にならない。** 読者が求めたのは「透かしを出さないこと」であって
「レーダーが消えること」ではない。`maxzoom` を実測値まで**下げる**と、MapLibre も Cesium も
**z7 のタイルを引き伸ばして**（overzoom）描き続けるので、雨の場はどのズームでも画面に残る。

⚠ **引き伸ばしが足すのはぼけであって誤りではない。** RainViewer の無料モザイクは元々 ~2 km/px、
z7 は赤道で ~1.2 km/px ＝ **既にネイティブ解像度**である。天井を高くしても無料枠に存在しない
解像度は買えない。買えるのは灰色の板だけ（#R433 の形——閾値を上げるのは defect の再導入）。

### 検査（`tests/r482-checks.test.mjs`・5件）

| # | 見ているもの |
|---|---|
| ① | `RV_MAX_Z` が**1か所でだけ**宣言され、実測の天井（7）以下である |
| ② | レーダーのラスターが**直書きの数字ではなく**その定数で作られる |
| ②b | `addRaster` の三番目の引数が本当にソースの `maxzoom` に届く（届かなければ①②は緑のまま z8 が飛ぶ） |
| ③ | 出荷されていた綴り（三番目の引数が 12）に対して②が**実際に発火する**（#R465 の形） |
| ④ | 凡例サムネイル（`js/layer-previews.js`・固定 z4）も天井の内側に居る——ここが z8 になれば、地図が直っても**レイヤーパネルの絵**が灰色の板になる |

### 触っていないもの

⚠ **Cesium は1行も要らなかった。** `js/cesium-layers.js` は `cfg.maxzoom` をそのまま
`maximumLevel` に渡すので、同じ定数が両エンジンに効く。⚠ **配色番号・コマ送り・凡例・
`setSourceTiles` による差し替え**（#R276）は無傷。
