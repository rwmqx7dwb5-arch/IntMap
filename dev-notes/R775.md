## 2. ⚠⚠⚠ 指標名の解決が、同じターンの中で 2 度拒んだ

同じターンで:

```
data.rank {metric:"名目GDP（現在価格米ドル）"}  → unknown_metric / failed
data.rank {metric:"gdp"}                      → ok
data.rank {metric:"名目GDP"}                  → unknown_metric / failed   ← 二度目
```

`js/atlas-metrics.js` は **#R740・#R741・#R760 が 3 回直した場所**である。今回通り抜けたのは
**語順**だった: `gdp` は自分を「GDP（名目）」と名乗るので正規化すると `gdp名目`、問い合わせ
「名目GDP」は `名目gdp`。**どちらも他方を含まない。** そのうえ #R741 の部分一致は
「問い合わせが名前の一部か」の**一方向しか訊いていない**ので、名前＋修飾（"nominal GDP,
current US$"）は短いラベルの部分列になりようがなく、永久に外れる。

⇒ 含有を**両方向**訊く。**そして #R741 の一意性規則がそれを安全にしている**——
`gdp` は「名目gdp」の中にあり `gdppc` は無いので、答える指標はちょうど 1 つ。

⚠⚠⚠ **最初の実装は自分の検査に落第した。** 「長さ 3 以上で含まれていれば」と書いたら、
`tell me about the demographics of the world` が **`dem` → 民主主義指数**に解決された。
#R741 が書いた規則（**推測は、それが置き換える拒否より悪い**）を、その修正自身が破っていた。
⇒ **語境界は元の文字列で見る**（`_mmap` が剥ぎ取り前の位置を保つ）。「名目GDP」は字種の
変わり目で区切られるので通り、`demographics` の中の `dem` は通らない。
**最長が勝ち、同じ長さが 2 つあればやはり拒む**ので `GDP per capita, current US$` は `gdppc`。

## 4. ⚠⚠⚠ Atlas は、いま自分が描いたものを片付けていた

実測、同じセッションで 4 回:

| 問い | 起きたこと |
|---|---|
| 1900 年の日本の行政区分を地図に出して | 1900 年の境界を描いた**あと、最後の 2 操作で `Country borders` と `State / province borders` を off** にした。読者の最終画面に 1900 年の境界は 1 本も無い |
| GDP 上位 10 か国をコロプレスで | 上位 10 を塗った**あと `map.clearAll` を自分で呼んで**消し、別の順位だけを残した |
| 時価総額上位 10 社の本社をプロット | 7 操作のうち **4 件が「既に空の地図」の片付け**（`clearAll` → `clear/already_clear` → `clear/already_clear` → `clearHighlights/already_there`）。本社は 1 つも置かれなかった |
| 地中海に面している国を全部選択して数えて | 22 か国を塗り、**消して描き直すのを 3 回**繰り返し、最後は空の地図 |

**機構は壊れていない。** `js/atlas-persona.js` の `workspace` 段落は毎ターン届いていて、
「**前の問い**のために出したものが、いまの問いの役に立たないなら片付けろ」と言っている。
**#R742 はこの同じ理由でレイヤーに出自の印を付けた。そこで止まっていた。**
ハイライト・色分け・ピン・多角形・線・半径・計測は、モデルには**ただの件数**として届いていた——
だから「**前の**問い」は、Atlas には答えようのない問いだった。

⇒ #R742 の機構をそのまま延長する。`recordOperation` に届く操作は turnId を持ち、turnId は
Atlas の経路にしか無いので、**前の観測に無くていま在る描画は、その操作の最中に現れた**。

- `paintOrigin`（描画の種類 → turn）を `layerOrigin` の隣に置く
- **種類の一覧は手で並べない**——`paintKeysNow()` が公開済みの `atlas` 節を走査するので、
  後から増えた描画も名前を書き足さずに印が付く（#R742 が同じ理由で書かなかったもの）
- プロンプトに `[YOU drew this · turn N · THIS turn / N turn(s) ago]`
- ⚠ **`userPins` には印を付けない**——読者自身のピンであり、台帳が持っていない作者を
  主張してはならない（[[intmap-data-must-not-claim-an-author-it-lacks]]）
- ⚠ **台帳は記録するだけで、何も消さず何も残さない**（`CONSTITUTION.md` §5）

**そして、何も無いときは「何も無い」と述べる。** 上の各行は自分の描画が在るときしか出ないので、
**空の地図は 1 文も生まなかった**。地図を自分の作業場だと言われている読み手にとって、
**行が出ないことは記述ではない**。4 つの別々の片付け呼びは、どれも「やることがありません」と
答えを返した——**訊かなくてよかった問い**である。

## 6b. ⚠⚠⚠ 同じ形がパンデミックの引数にもあった

「Run a pandemic scenario with border closures enabled」——`sim.pandemicRun` が
**`params-rejected` で 6 回連続で拒まれ、そのあと 4 回実行された**（同じ能力を 1 ターンに 10 回、
13 tool callで step_budget）。読者に見えたのは `⚠ borderClosures: unknown …` だけ。

**語彙は既に拒否文に入っていた**——`checkPandemicParams` は未知の鍵に対して
`accepts: Object.keys(PANDEMIC_PARAMS)` を返し、`paramRefusal` がそれを刷っている（その直上の
註が「拒否が語彙を運ぶのは 1 回の間違った呼びを 1 回の正しい呼びにするため」と書いている）。
欠けていたのは **#R760 が指標について名づけた `meta.permanent`** だった。それが無いと
`js/atlas-agent.js` の台帳は**引数そのもの**を鍵にするので、持っていない引数の言い換えは
毎回**新しい要求**に見え、探索を止めるはずの註が 1 度も付かない。

⚠ **永続にするのは「鍵が未知」の場合だけ。** 範囲外・数値でない・値が違うは**値の話**で、
別の値は本当に別の要求であり成功しうる——そこを永続と宣言するのは、**動くものを諦めろと告げること**である。
⚠ `preset-unknown` は未知の指標と同じ形なので永続（拒否文が全プリセットを数え上げている）。
⚠ **これは何も拒む機構ではない**——`permanent` は 2 度目に註を付けるだけで、呼びはそのまま走る
（`CONSTITUTION.md` §5）。

## 6c. ⚠⚠ 起動費用の天井を 1 行だけ動かした。その内訳

`check:perf` が `atlas-executor` チャンクで赤くなった。**天井を上げる前に 2 つやった**:

1. **毎ターンプロンプトに載る文字列を詰めた**——最小化で落ちないのは文字列であり、
   それはバイトだけでなく**毎回の token** でもある。
2. ⚠⚠⚠ **同じ判断が 2 か所にあったのを直した**——「何も描かれていない」の判定を
   `at.highlightCountries && at.pins && …` と**種類を手で並べた長い述語**で書いていたが、
   それは台帳側の `paintKeysNow()` が持っている規則の**写し**である。この回が消しているのと同じ形
   （#R515）を、その修正自身が書いていた⇒ `drawnKeys(at)` **1 つ**にし、台帳もプロンプトも
   それを訊く。（⚠ `tool` と `userPins` の除外も 1 か所になった。）

それでも 349 B 足りなかったので、**`tests/perf-baseline.json` の `atlas-executor` 1 行だけ**を
実測値 **46,930 → 49,327 B** へ更新した。⚠ **`--update` は全項目を書き戻す**ので使っていない
（[[intmap-perf-budget-tolerances]]）。

**内訳を分けて述べる**——この 2,397 B は全部がこの回のものではない。
`tests/perf-baseline.json` の最終更新は **#R765** で、#R766〜#R772 の 5 ラウンドが天井を
更新せずに許容幅（`GROW.abs` 2,048 B）を食っており、main の時点で既に **約 844 B** 超えていた。
残りの **約 1,553 B** がこの回の台帳（`paintOrigin` / `drawnKeys` / `observePaints` / `paintMark`）である。
⚠ このチャンクは**遅延読み込み**で、起動時には読まれない。

#R773 への rebase のあと、同じ理由で `atlas-console`（1,075,811 → **1,082,100 B**）と
`dist.assets`（18,444,509 → **18,539,724 B**）も実測値へ更新した。
⚠ **この 2 行はバイト単位で内訳を分けていない**——分けるには `origin/main` を別に build して測る必要があり、
今回はそこまでやっていない。**測っていないことを測ったと書かない**ために明記する。
この回が `js/atlas-console.js` へ入れたのは 2 か所（錪の切り替えと、死んだターンの質問を戻す 1 文）だけで、
行数は差し引き 0 のままである。
