### A6 — 「エンドポイントが死んでいた」のではなく、アプリが自分で枠を使い切っていた

⚠⚠⚠ **429 は送信元 IP 単位だった。** 本番実測で `api.fxratesapi.com` は 429
（`x-ratelimit-limit: 61` / `remaining: 0`）だが、**別 IP からは同じ URL が 200 を返した**。

＝ `minIntervalMs: 60000` のまま永久に叩き続ける。⇒ 429 の URL を `retryAfterMs` の間**訊かずに飛ばし**、
全候補が窓の中なら `rateLimited` で reject する。`open.er-api.com` を主系統、fxratesapi を2番手へ
（**消していない**——鍵を取れば戻せる）。
⚠⚠ **出典行は答えていない provider を名乗っていた**（固定リテラル `'fxratesapi / er-api'`。#R352 と同型）

⚠⚠⚠ **`need()` は失敗を恒久的にメモ化していた。** `P[name]` が `false` に解決した promise を保持し、
