## R704 — **配線は 3 ラウンドかけて正しくなっていた。スイッチは一度も入っていなかった**

〈「あなたに普段任せている IntMap の開発を、Codex でも完全に同じ使用感でやりたい」〉

### 1. ⚠⚠⚠ hook は「たまに届かない」のではなく、**一度も走っていなかった**

`~/.codex/config.toml` に `[hooks.state]` が **1 件も無い**。Codex は hook の trust を
`[hooks.state."<key>"] trusted_hash` に記録し、`trustedHash === currentHash` の完全一致で判定する
——記録が無いということは、`.codex/hooks.json` が宣言している 3 つの `SessionStart` コマンドは
**一覧に出るだけで、一度も実行されていない**。

状況証拠ではなく直接測った。`~/.codex/sessions` の 2026-09-01 以降の全 rollout（200 本超）に
`agent-memory.mjs --check` が出す文字列「IntMap · 蓄積メモリの索引」は **0 件**。
`worktree.mjs status --brief` の状態行は見つかるが、**現れる唯一の場所は `[external_agent_tool_result]`
の中**——それは Claude Code の記録を Codex に取り込んだものであって、hook の出力ではない。

つまり #R696 が「別人感の正体はモデルでも設定でもなく、片方だけが知っていることだった」と結論して
1 か所にまとめた蓄積メモリは、**Codex 側にはその後も一度も渡っていなかった**。

### 2. ⚠⚠⚠ 完成した配線が通電しているかを、どの門も測っていなかった

`check:agents` は `.agents/` から描いた写しと生成物を照合する。#R503 → #R696 → #R699 で
正本は 1 つになり、hook すら `.agents/session-start.json` 1 か所から両製品へ描かれるようになった。
**それでも、描いた hook が向こう側で走ったかどうかは、その門の測る対象ではない。**

この形は #R488（綴りを固定した検査が死んだ規則を守った）や #R505（ソースを読む検査は評価順序を
見られない）と同じ帯にいる——**生成物が正しいことと、生成物が効いていることは別の主張**である。

### 3. 直し方は 2 層に分かれる

| 層 | どこ | 何 |
|---|---|---|
リポジトリの外 | `~/.codex/config.toml` | `npm run setup:codex` が測り、`:apply` が揃える |
リポジトリの中 | `AGENTS.md` §0 の 4・`.codex/config.toml` C-0 | **hook が届かないときに同じ中身へ戻る道** |

⚠ **(b) が本体である。** hook trust は `key` も hash もアプリが計算するのでリポジトリからは与えられず、
`.codex/hooks.json` を変えるたびに `/hooks` が 1 回要る。**その 1 回を無くすことより、届かない間に
「メモリが無い」と誤認しないことのほうが効く**——道の中身は `.agents/session-start.json` から
**導出**する（手で書いた 2 本目の一覧は、また片方だけが知っている状態を作る）。

### 4. 承認・サンドボックス・書ける場所も、既定に委ねられていた

`approval_policy` も `sandbox_mode` も**未設定**だった。`AGENTS.md` §5.1 は commit・push・PR・merge・
deployment に追加承認を求めないことを要求するが、それが成り立つかはアプリの既定次第だった。

- `sandbox_mode = "workspace-write"` ＋ `[sandbox_workspace_write] network_access = true`
- `approval_policy = "on-failure"` — ⚠ **`never` にしない。** USB ミラー（§11.2）の宛先は
  ラベルで探すリムーバブルで、どの workspace にも入っていない。`never` はそこを 1 つの質問ではなく
  **無言の失敗**に変える。**逃げ道のある最も静かな政策**を採る。
- `writable_roots` — ⚠ **`workspace-write` は、この仕事が書く先の 3 つを含んでいなかった**:
  メモリの正本・`~/.intmap-handoff`・`%LOCALAPPDATA%\Temp\intmap-worktrees`。3 つとも
  **所有者に訊いて導出**する（原本は `git rev-parse --git-common-dir`、メモリは
  `agent-memory.mjs --path`、worktree は `worktree.mjs` と同じ `os.tmpdir()` の結合）。
  ⚠ **USB だけは入れない**——ドライブ文字はバックアップ時にラベルで見つけるものなので、
  今日の文字は明日の誤りになる（`.agents/rules/no-ad-hoc-hardcoding.md` §4 の「失効条件」）。

### 5. 推論の深さは、仕事ごとには変えられない

利用者の問い「自動で推論変えるってできないの？」に対する実測: **できない。**
`~/.codex/config.toml` の `[projects."<path>"]` が持てるのは `trust_level` **1 つだけ**
（exe の `struct ProjectConfig with 1 element`）で、深さを絞れる単位は profile しかない。
`model_reasoning_effort` はグローバルな既定で、`low` のままだった——`AGENTS.md` §3 が要求する
「根本原因での修正」は、浅い推論では**手順を踏んで判断を落とす**形で失敗する。
費用は利用者のものなので、**利用者が `high` を選んだうえで**書いた——
**そして書き戻された。**

⚠⚠ **この鍵はアプリが所有している。** `high` を書いた数分後、`config.toml` の mtime が動き、
値は `low` に戻っていた（同じ書き込みで入れた `sandbox_mode` / `approval_policy` /
`writable_roots` は 3 つとも残っていた＝ファイル全体を書き戻したのではなく、**この鍵だけ**が
アプリのモデル選択 UI の写しである）。⇒ `codex-setup.mjs` は**この鍵を書かない**。
**持続しない修正は、修正が無いことより悪い**——報告は「✎ 直した」と言い、値は戻っているから。
書く代わりに、**誰がその値を持っているのか**を言う（`tests/…-checks ⑥` がそれを固定する）。

### 6. ⚠⚠ #R703 の記述を 1 つ撤回する

#R703 は「trust を丸ごと外す 2 経路はデスクトップのバンドルにどちらの綴りも無い」と書いた。
**build 0.153.4 では誤りである**——`--dangerously-bypass-hook-trust`・環境変数 `BYPASS_HOOK_TRUST`・
app-server の `bypass_hook_trust` override が**3 つとも実在する**（「DANGEROUS. Intended only for
automation that already vets hook sources」という説明文ごと）。
**それでも採らない**——効く範囲が IntMap ではなく**このマシンの全プロジェクト**で、
`/hooks` の 1 回と引き換えに払う代償として釣り合わない。

ついでに、この文書が長く主張していた探索パスも綴りで確かめた: `.codex/hooks`・`.codex/agents`・
**`.agents/skills`** はどれも exe に実在するリテラルで、**`.codex/skills` は 0 件**。

### 7. 検査

`tests/r704-codex-parity-seamless-checks.test.mjs`（6 件）。中心は ②——
**`.agents/session-start.json` に Codex 宛のコマンドを足したら、hook が届かないときの代替も
それを言うか**。書いた直後に欠陥を戻して実測した: 一覧をハードコードすると ② が、
`AGENTS.md` から入口を消すと ③ が落ちる（他の 3 件は緑のまま）。

⚠ `npm run setup:codex` は **`check:*` ではない**。測っているのは**このマシン**で、CI runner には
`~/.codex` が無い——`check:*` にすると `gate-callers` が CI での呼び出しを要求し、そこでは
意味のない緑になる。CI に証明できる分だけが上の検査に入っている。
