## R744 — 進行表示が 2 つあり、片方はどのターンでも同じ語を出していた

〈利用者の指示と、その場で送られてきた本番のスクリーンショット 1 枚〉

### 1. ⚠⚠⚠ 読者が見ていたもの（実測）

```
▾ Working                                    40.5s     ← 泡の上：#R723 の一覧の見出し
  ✓ Thinking                                  7.9s
  ↻ Researching  Which volcano in Indonesia…
Researching                                            ← 泡の中：#R313 のシマー
```

**1 つの状態について、2 か所に生きた指標がある。** しかも 2 つは**違うことを言う**——上は
「Working（作業中）」でどのターンでも同じ、下は「Researching」でいま走っている操作の語。
#R313 は「進行表示はアプリ全体で 1 種類だけ」にするために古い点々を消した回で、
**#R723 は一覧に見出しを与えるときに、その規則を自分で破っていた**（語を動かさなかったから）。

合計時間も同じ重複の別の面である。**各行は自分の所要を既に書いている**ので、見出しの合計は
「行の和」を読者の代わりに足しているだけで、しかも**何も起きていない間に画面で唯一変化するもの**
＝ 250 ms の tick が存在する唯一の理由だった。

### 2. 直したもの

- **語は見出しへ。** 一覧の見出し（＝展開のボタン）が `.atl-stage` を持ち、そこがシマーする。
  読者が他の AI で見ているのと同じ形——**上に 1 語、開くと詳細な行**。
- **合計時間は残す。** ⚠ 一度は「これも重複」と読んで削除したが、それは誤りだった——
  **重複していたのは語だけ**で、**ターンが何秒走っているかは他のどの要素も述べていない**。
  行はその数ではない（行は**操作**を測り、ターンの大半は**その間の待ち**）。tick も残る。
- **印は動かさない。** `.atl-stage` は #R313 以来 2 つの仕事を持っていて、片方は委譲できない
  ——取り消し走査 (`.atl-b.a .atl-stage`) と `markCancelled`（**その span を停止の注記で置き換える**）が
  **泡の子孫**としてこの綴りを探す。⇒ 泡の中には**中身の空の span** が残り、`:empty` が場所を消す。
  語まで一緒に動かしていれば、**取り消しがアプリ全体で無言で死んでいた**。
- **見出しの span は使い回す。** 作り直すと CSS アニメーションが 0% から始まり、歩が進むたびに
  帯が戻る。文字だけを比べる検査には見えないので、検査は**要素の同一性**を訊いている。

デザインは変えていない（見出しの型・行・記号・折り畳みは #R723 のまま。語は見出しの 11.5px を継ぐ）。

⚠ `tests/i18n-coverage-floor.json` の de / es / ru が 7598 → **7597**。消えたのは
**「Working（作業中）」を見出しに書いていた `L(…)` 呼び 1 件**で、**同じ文字列は `wordFor()` の
fallback に今も在る**——読者が持っている語を 1 つも失っていない（`CONSTITUTION.md` §0-3）。

### 3. 検査 — `tests/r744-atlas-trace-head-checks.test.mjs`（6 本）

6 本とも**モジュールを評価して**訊く（#R505）。変異で全部鳴ることを確かめた。
⚠ **② は一度「合計時間が出ないこと」を測っていて、それは間違ったものを測っていた**——
書き直した ② は「合計が**行の和ではない**」を測り、**行の和で置き換える変異で鳴る**
（[[intmap-restate-the-defect-not-the-fix]]：到達した答えではなく、元の欠陥を述べる）。
⚠ **#R723 ② はこのラウンドで空虚になるところだった**——`stageHtml('think')` に語を訊いていたので、
印が文字を持たなくなった瞬間に「どの能力も『考え中』と名乗らない」が**空文字列との比較で真**になる
（[[intmap-window-is-a-length-not-a-relevance]] と同じで、**測っているつもりの対象が変わっていた**）。
語そのものを返す `phaseWord()` を足し、そちらに訊き直した。
