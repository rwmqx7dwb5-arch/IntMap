# 歴史地図の地方区分 — IntMap 自身による復元 (Reconstructed historical divisions)

> **正本はこの文書。** 既存の典拠（OpenHistoricalMap・出版者の歴史地図）が答えず、現代の区分を
> 遡らせることもできない地域・時代の第 1 級区分を、IntMap が**史実から組み立てる**ときの方法・形式・
> 判定基準・対象の選び方を持つ。実装は `scripts/build-hist-admin-recon.mjs`（→ `data/hist-admin-recon.js`）、
> 事実は `scripts/histrecon/dossiers/*.json`（調書）と `scripts/histrecon/meiji-*.json`（明治の府県）。
> 原則は `.agents/rules/historical-verification.md` §0（精度は絶対に妥協しない・調べて決まることを
> 不明で逃げない）。経緯と実測は開発記録（`node scripts/dev-notes.mjs --list` の hist-reconstruction）。

## 1. 方法 — 区分は「部品の和集合」、所属は 1 件ずつ出典つきの事実

- **部品（atom）**は、境界線が史実の線と一致する細かい単位。ある時点の区分は部品の和集合で、
  手で描かない・平滑化しない・補間しない。
- **所属**（どの部品がいつどの区分に属したか）は、法令・官報・公式の変更一覧・研究書などの
  出典を 1 件ずつ付けた事実。
- 部品の境界と一致しない史実の線（郡の一部だけの移動、後に引き直された線）は**描かない**——調書の
  `unresolved` に、何を調べたか・なぜ決まらないか・どの部品なら運べるかを書く。

| 部品の集合（`atomSet`） | 中身 | ライセンス | 使い道 |
|---|---|---|---|
| `ne-admin1@ca96624` | Natural Earth 10m admin-1（全精度・commit 固定） | パブリックドメイン | 現代の区分の「この形はいつからか」と、分割前の親区分（＝今の区分の和集合） |
| `ristat-1897-uyezd@v3` | ロシア帝国 1897 年の郡 824（RISTAT） | CC0（出典表示の依頼） | 県 = 郡の和集合。1897 年から前後へ、外周の変化まで |
| 明治（`scripts/histrecon/assembled/meiji.mjs`） | 国土数値情報 N03 1920 年の郡・町村（CC BY 4.0 相当）と e-Stat 2020 小地域の大字（政府標準利用規約 2.0・CC BY 4.0 互換） | 同左 | 府県 1871-12 → 1890-12（試作として承認済み） |

### 現代の区分を部品にするときの 2 つの形

1. **この形はいつからか**: 今の区分の外周が最後に変わった日から、その区分を描く。証拠は「その日以後、
   外周に触れる変更が 1 件も無い」ことを示す完全な変更一覧。名前の設立日（Wikidata の P571）ではない。
2. **分割前の親**: 新しい区分が 1 つの親から丸ごと切り出されたなら、それ以前の親は「今の親 ＋ 子」の和集合。
   複数の親から切り出された・一部の郡だけ動いた、なら和集合では書けない（細かい部品が要る）。
- ⚠ Natural Earth の区分は国によって**過去のある時期の配置**である（例: スーダンの 17 州は 2012-01-10 から
  2013-07-13 までしか存在しない）。始まりだけでなく**終わりの日**も史料で決める。
- ⚠ 1 つの国の 1 つの時点では**部品の集合を 1 つだけ**使う（出版者の違う部品を混ぜると継ぎ目に隙間と重なりが出る）。

## 2. 判定基準（試作と同じ 4 つ ＋ 地図との突き合わせ）

| | 基準 | 測る所 |
|---|---|---|
| ① | 独立した正解との一致（史実どおりの差を除く） | 明治: 1920 年の府県・旧国との IoU。他は区分数と変更一覧の整合（独立した幾何の正解がある所で追加） |
| ② | 史料が述べる区分数との一致 | `dossier-check.mjs`（`counts`） |
| ③ | 各時点で各部品がちょうど 1 つの区分に属す（または「国外」「未解決」と名指し） | `dossier-check.mjs` |
| ④ | 所属 1 件ごとの出典 | `dossier-check.mjs`（`sources`） |
| 検査 3 | その土地がその日、地図上で 1 つの政体の中にある | `build-hist-admin-recon.mjs`（穴埋め記録と同じ判定を import） |
| 検査 4 | 日付つきの記録（OHM・出版者）が答える所では譲る | 同上（`answeredSpans`、共有の譲り方） |

**優先順**: OpenHistoricalMap ＞ 出版者の記録 ＞ **この復元** ＞ 現代の区分の遡及（`data/hist-admin-fill.js`）。
穴埋め記録は復元に譲る（`recordFiles()` が `reconstructed` の記録を読む）。

## 3. 調書（dossier）の形式

`scripts/histrecon/dossiers/<ISO3>[-<地域>].json`。1 国（またはロシア帝国の 1 地域）1 ファイル。

```json
{
  "country": "DZA", "atomSet": "ne-admin1@ca96624",
  "atomGroups": ["(任意) 部品の一部だけを扱うとき — ロシア帝国の 1897 年の県名など"],
  "scope": { "from": "1984-02-04", "to": "2019-12-31" },
  "polityNote": "どの政体の区分か",
  "units": [ { "id": "…", "names": { "en": "…", "ja": "…", "local": "…" }, "wikidata": "Q…",
      "spans": [ { "from": "1984-02-04", "precision": "day", "to": "2019-12-18",
          "atoms": ["DZA-…"], "sources": [ { "url": "…", "title": "…", "says": "短い要約", "accessed": "2026-10-05" } ],
          "dateNote": "公布日と施行日の違い・旧暦の原日付など" } ] } ],
  "events": [ … ], "counts": [ { "date": "…", "n": 48, "sources": [ … ] } ],
  "atomsOutside": [ { "atom": "…", "from": "…", "to": "…", "why": "その期間その国の施政下に無い" } ],
  "unresolved": [ { "what": "…", "unit": "…", "atoms": ["…"], "from": "…", "to": "…", "why": "…", "checked": ["…"], "needs": "運べる部品" } ]
}
```

- 日付は ISO。`to` は**排他的**（その日にはもう無い）。年・月までしか確定しないものは `"1984"`・`"1984-02"` と
  書き `precision` を合わせる（日を作らない）。ロシアの法令は**旧暦（ユリウス暦）を新暦に換算**し、原日付を `dateNote` に残す。
- `says` は出典が述べることの短い要約（長い引用をしない）。Wikipedia は版（oldid）を固定して引く。

## 4. 対象の選び方（2026-10-05 の全世界調査）

**自作するのは「既存の再配布可能な典拠では埋まらない所」だけ。** 取り込めば埋まる所は対象外（取り込みの作業）:

| 対象外（取り込みで埋まる） | 典拠とライセンス（一次資料で確認） |
|---|---|
| フランスの県・郡・小郡 1870–1940（年ごと） | TRF-GIS（Victor Gay）Harvard Dataverse `DVN/ULQYM5` — CC BY 4.0 |
| イタリアの県・郡・コムーネ 1861–1981 | Istat「Confini statistico-amministrativi: analisi storica」— CC BY 4.0 |
| スペイン 1785–89 の州 | UAM「Nomenclátor de Floridablanca」— CC BY 4.0 |
| 朝鮮 1910–45 の道・府郡・邑面（変更履歴つき） | 国史編纂委員会 歴史地理情報 DB（data.go.kr 15080854）— 公共著作物 第 1 類型 |
| 清 1907–1911 の府 | Virtual Shanghai「Prefectures in 1909 Qing China」— CC0 |
| 英領・仏領アフリカ 20 植民地の行政単位（1898–1963 の断面） | Müller-Crepon, Harvard Dataverse `DVN/9JI06R` — CC0 |
| アナトリアの郡 1893 頃 | Amasyalı「ottoman-anatolia-schooling-hgis」— CC BY 4.0（README） |

**使えない典拠（再配布不可）**: CHGIS（V4–V6・非商用・再配布禁止）、GADM、SHRUG（CC BY-NC-SA）、
India State Stories の形状（ライセンス無し）、THCTS（台湾、CC BY-NC-SA・国内限定）、IPUMS の境界、
Berkeley/China Data Center、UN SALB。

**自作で埋める所と、その順序**（未被覆の面積 × 精度を落とさず組めるか）:

1. 現代の区分の日付と分割前の親（`ne-admin1`）— 中国・アルジェリア・コンゴ民主共和国・スーダン・イラン・
   サウジ・リビア・インドネシア・アルゼンチン・トルコ・エジプト ほか約 80 か国。1950–2019 年の未被覆の大半。
2. ロシア帝国の県（`ristat-1897-uyezd`）— 1886–1914 年の最大の空白。
3. 明治の府県（試作）。
4. （次の段）1992–2008 年のロシア連邦構成主体（郡を部品に）、トルコ 1926–1999（郡）、インド 1950–2020、
   中華人民共和国 1949–79、清 1667–1906（1909 年の府を部品に）、スウェーデン・フィンランド・ポーランドの
   統合前の区分（市町村を部品に）。

**精度を保って組めない所（調べ尽くした結果）**: ムガルのスーバ（測量された線が無い）、オスマンの 16–19 世紀の
エヤレト・アラビアとリビアのヴィラーエト（線が引かれていない）、カージャール朝以前のイラン、1708 年以前の
ロシアの郡、満洲国の省（再配布可能な形が無く、戦後に郡界が大きく引き直された）、清代台湾の番界、
1500 年より前のほぼ全域（線を運ぶ部品が無い）、先史・文化圏の「政体」（区分が存在しない）。
