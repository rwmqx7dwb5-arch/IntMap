# 歴史地図の地方区分 — IntMap 自身による復元 (Reconstructed historical divisions)

> **正本はこの文書。** 既存の典拠（OpenHistoricalMap・出版者の歴史地図）が答えず、現代の区分を
> 遡らせることもできない地域・時代の第 1 級区分を、IntMap が**史実から組み立てる**ときの方法・形式・
> 判定基準・対象の選び方を持つ。実装は `scripts/build-hist-admin-recon.mjs`（→ `data/hist-admin-recon.js`）、
> 事実は `scripts/histrecon/dossiers/*.json`（調書）と `scripts/histrecon/meiji-*.json`（明治の府県）。
> 原則は `.agents/rules/historical-verification.md` §0（精度は絶対に妥協しない・調べて決まることを
> 不明で逃げない）。経緯と実測は開発記録（`node scripts/dev-notes.mjs --list` の hist-reconstruction）。

## 1. 方法 — 区分は「部品の和集合」、所属は 1 件ずつ出典つきの事実

- **部品（atom）**は、境界線が史実の線と一致する細かい単位。ある時点の区分は部品の和集合で、
  手で描かない・平滑化しない・補間しない。
- **所属**（どの部品がいつどの区分に属したか）は、法令・官報・公式の変更一覧・研究書などの
  出典を 1 件ずつ付けた事実。
- 部品の境界と一致しない史実の線（郡の一部だけの移動、後に引き直された線）は**描かない**——調書の
  `unresolved` に、何を調べたか・なぜ決まらないか・どの部品なら運べるかを書く。

| 部品の集合（`atomSet`） | 中身 | ライセンス | 使い道 |
|---|---|---|---|
| `ne-admin1@ca96624` | Natural Earth 10m admin-1（全精度・commit 固定） | パブリックドメイン | 現代の区分の「この形はいつからか」と、分割前の親区分（＝今の区分の和集合） |
| `ristat-1897-uyezd@v3` | ロシア帝国 1897 年の郡 824（RISTAT） | CC0（出典表示の依頼） | 県 = 郡の和集合。1897 年から前後へ、外周の変化まで |
| `gb-adm1@2026-10-06`・`gb-adm2@…`・`gb-adm3@…` | geoBoundaries gbOpen の各国 ADM1／ADM2／ADM3（データセットごとに commit 固定・`scripts/histrecon/atoms/geoboundaries-manifest.json`） | データセットごと（PD・CC0・CC BY・CC BY IGO・ODbL・CC BY-SA）。継承条項つきの部品から組んだ記録はその条件で提供（LICENSE §5、記録ごとの `sources[].offeredUnder`） | 今日の郡・市町村の和集合として、それより前の州・県。郡境がその期間に引き直されていないことを変更一覧で示せる所だけ |
| 明治（`scripts/histrecon/assembled/meiji.mjs`） | 国土数値情報 N03 1920 年の郡・町村（CC BY 4.0 相当）と e-Stat 2020 小地域の大字（政府標準利用規約 2.0・CC BY 4.0 互換） | 同左 | 府県 1871-12 → 1890-12（試作として承認済み） |

### 現代の区分を部品にするときの 2 つの形

1. **この形はいつからか**: 今の区分の外周が最後に変わった日から、その区分を描く。証拠は「その日以後、
   外周に触れる変更が 1 件も無い」ことを示す完全な変更一覧。名前の設立日（Wikidata の P571）ではない。
2. **分割前の親**: 新しい区分が 1 つの親から丸ごと切り出されたなら、それ以前の親は「今の親 ＋ 子」の和集合。
   複数の親から切り出された・一部の郡だけ動いた、なら和集合では書けない（細かい部品が要る）。
- ⚠ Natural Earth の区分は国によって**過去のある時期の配置**である（例: スーダンの 17 州は 2012-01-10 から
  2013-07-13 までしか存在しない）。始まりだけでなく**終わりの日**も史料で決める。
- ⚠ 1 つの国の 1 つの時点では**部品の集合を 1 つだけ**使う（出版者の違う部品を混ぜると継ぎ目に隙間と重なりが出る）。geoBoundaries は同じ国でもレベルごとに出版元が違い線が入れ子にならない（ウガンダ: ADM1 は OpenStreetMap、ADM2 は Wikimedia Commons）ので、レベルごとに別の集合である。
- ⚠ **同じ土地・同じ日を 2 本の調書が描いてはならない**——組み立て器が拒む: 同じ集合では同じ部品の scope の重なり、違う集合では同じ今日の国（`atomCountries`）の scope の重なり。新しい部品で過去へ延ばすときは、既存の調書の `scope.from` の前日で `scope.to` を切る。
- ⚠ **今日の郡は今日の線である。** ある期間の区分を今日の郡の和集合と書けるのは、その区分の外周に乗る郡境がその期間ずっと同じ線だったと変更一覧で示せるときだけ（郡がのちに分割されたのは構わない——和集合は変わらない）。

## 2. 判定基準（試作と同じ 4 つ ＋ 地図との突き合わせ）

| | 基準 | 測る所 |
|---|---|---|
| ① | 独立した正解との一致（史実どおりの差を除く） | 明治: 1920 年の府県・旧国との IoU。他は区分数と変更一覧の整合（独立した幾何の正解がある所で追加） |
| ② | 史料が述べる区分数との一致 | `dossier-check.mjs`（`counts`） |
| ③ | 各時点で各部品がちょうど 1 つの区分に属す（または「国外」「未解決」と名指し） | `dossier-check.mjs` |
| ④ | 所属 1 件ごとの出典 | `dossier-check.mjs`（`sources`） |
| 検査 3 | その土地がその日、地図上で 1 つの政体の中にある | `build-hist-admin-recon.mjs`（穴埋め記録と同じ判定を import） |
| 検査 4 | 日付つきの記録（OHM・出版者）が答える所では譲る | 同上（`answeredSpans`、共有の譲り方） |

**優先順**: OpenHistoricalMap ＞ 出版者の記録 ＞ **この復元** ＞ 現代の区分の遡及（`data/hist-admin-fill.js`）。
穴埋め記録は復元に譲る（`recordFiles()` が `reconstructed` の記録を読む）。
⚠ **調べたが決まらない土地にも譲る。** 調書の `unresolved`（部品と期間を名指したもの）は「この土地のこの期間、線は史料で決まらない」という調査結果であって「誰も答えていない」ではない。組み立て器はその土地と期間を書き出し（`scripts/histrecon/withheld-file.mjs` が場所を決める・リポジトリの外の部品のキャッシュ）、穴埋め記録はそれを描かれた行と同じく復元の記録として読んで譲る——今日の線を当てない。無ければ穴埋め記録の組み立ては止まる。実測（2026-10-06）: これが無かった間、穴埋め記録はカザフスタンの 1997 年の州合併の前に合併後の州を、ジョージアの州を 1995-01-01（最後の州の設置は 1995-12-19）から、モルドバの郡を 2003-01-01（施行は 2003-03-21）から描いていた。

**門は部品を取りに行かない。** ③ に要るのは国の部品の一覧（ID）であって形ではない。組み立て器が読んだ一覧を `scripts/histrecon/atoms/catalogue-lock.json` に書き、`npm run check:histrecon`（CI が毎回走らせる）はそれだけを読む。調書が一覧に無い集合・国を名指せば、門はネットワークへ戻らずに「組み立て器を走らせよ」と落ちる。

## 3. 調書（dossier）の形式

`scripts/histrecon/dossiers/<ISO3>[-<地域>].json`。1 国（またはロシア帝国の 1 地域）1 ファイル。

```json
{
  "country": "DZA", "atomSet": "ne-admin1@ca96624",
  "atomGroups": ["(任意) 部品の一部だけを扱うとき — ロシア帝国の 1897 年の県名など"],
  "scope": { "from": "1984-02-04", "to": "2019-12-31" },
  "polityNote": "どの政体の区分か",
  "units": [ { "id": "…", "names": { "en": "…", "ja": "…", "local": "…" }, "wikidata": "Q…",
      "spans": [ { "from": "1984-02-04", "precision": "day", "to": "2019-12-18",
          "atoms": ["DZA-…"], "sources": [ { "url": "…", "title": "…", "says": "短い要約", "accessed": "2026-10-05" } ],
          "dateNote": "公布日と施行日の違い・旧暦の原日付など" } ] } ],
  "events": [ … ], "counts": [ { "date": "…", "n": 48, "sources": [ … ] } ],
  "atomsOutside": [ { "atom": "…", "from": "…", "to": "…", "why": "その期間その国の施政下に無い" } ],
  "unresolved": [ { "what": "…", "unit": "…", "atoms": ["…"], "from": "…", "to": "…", "why": "…", "checked": ["…"], "needs": "運べる部品" } ]
}
```

- 日付は ISO。`to` は**排他的**（その日にはもう無い）。年・月までしか確定しないものは `"1984"`・`"1984-02"` と
  書き `precision` を合わせる（日を作らない）。ロシアの法令は**旧暦（ユリウス暦）を新暦に換算**し、原日付を `dateNote` に残す。
- 今日の国境をまたぐ単位（オスマンのヴィラーエト・清の省・英領インドの州）は、`country` に 3 文字の政体キー（`OTT`・`QNG`・`BRI` …、既存の ISO3 と衝突しないもの）を置き、`"atomCountries": ["TUR", "SYR", …]` で部品を取る国を列挙する。③ 分割はその国々の部品全部について判定する（政体の外の部品は `atomsOutside` に期間つきで）。
- `says` は出典が述べることの短い要約（長い引用をしない）。Wikipedia は版（oldid）を固定して引く。

India State Stories の形状（ライセンス無し）、THCTS（台湾、CC BY-NC-SA・国内限定）、IPUMS の境界、
Berkeley/China Data Center、UN SALB。
⚠ **IntMap は営利である**（利用者 2026-10-06）。非営利に限る条件の典拠は、再配布できても使えない——国立歴史民俗博物館
「旧高旧領取調帳」データベース（利用規程が営利目的を禁じる）と、その領主の列を転載した Kyudaka_agrivillage（作者の
CC BY-SA は上流の禁止を外さない。村の位置と農業集落の対応は作者の作業なので使える）。

**部品として使えないと実測した geoBoundaries のデータセット**（名前と形が一致しない・線が公表値と大きく食い違う。
各調書の `unresolved` が測った数字を持つ）: BFA ADM3（2007、「Ouagadougou」の形が約 150 km 離れた所にある）、
COG ADM2（名前と形が入れ違い、Brazzaville が約 6,000 km²）、GNB（Bissau 自治区が公表面積の 2.4 倍）、
GEO ADM2（OSM との IoU 0.42–0.77、市が郡に吸収）、ARM ADM2（時期不明の raion、面積が最大 40% 合わない）、
NAM ADM2（Swakopmund が Hardap にある）、TKM ADM2（ラベルの一部が不正確——州のまとまりと面積は合うので州単位では使う）、
KGZ ADM1（Toguz-Toro 郡をナルン州側に入れている）、EGY ADM2・IRQ ADM2（県の面積が公表値と合わない）。

**自作で埋める所と、その順序**（未被覆の面積 × 精度を落とさず組めるか）:

1. 現代の区分の日付と分割前の親（`ne-admin1`）— 中国・アルジェリア・コンゴ民主共和国・スーダン・イラン・
   サウジ・リビア・インドネシア・アルゼンチン・トルコ・エジプト ほか約 80 か国。1950–2019 年の未被覆の大半。
2. ロシア帝国の県（`ristat-1897-uyezd`）— 1886–1914 年の最大の空白。
3. 明治の府県（試作）。
4. （2026-10-06 に組んだ段）今日の郡・市町村（geoBoundaries）を部品に、各国の `ne-admin1` 調書より前へ——
   ナイジェリアの州 1961–、ガーナ・マリ・セネガル・コートジボワール・ウガンダ（1962–）・タンザニア・アンゴラ・
   ザンビア・ジンバブエ・モザンビーク（1954–）・スーダンと南スーダン（1948–）・チャド・トルコの県 1957–・
   イラン 1986–・タイ 1947–・ベトナム 1976–・ミャンマー 1937–・ロシア連邦構成主体 1991–2008・カザフスタン 1991–・
   中華人民共和国の省 1958–79・英領インドの州 1886–1947・アナトリアのオスマンの州 1891–1907 ほか約 140 本。
5. （次の段）部品の線が当時の線と一致すると示す変更一覧が揃えば描けるもの——各調書の `unresolved.needs` が
   必要な部品と史料を名指す。とくに: 村・集落単位の部品（セネガルの村落共同体・モルドバのコミューン・
   タイの tambon）、OpenStreetMap の関係から作る今日の精密な境界（ジョージア・アドジャラ）、
   植民地期の法令の附表（ニジェール 1961・コートジボワール 1986・アンゴラ 1960 の concelho）。

**府藩県期（1868–1871）**: 藩・府・県は第 1 級で、村の和集合として組める（旧高旧領取調帳が村→領主を与え、
土佐で旧国との IoU 0.996、播磨 0.987）。⚠ しかし営利で使える村→領主の典拠が今は無い——歴博のデータベースは上のとおり、
営利利用できる明治大学図書館本（パブリックドメイン・明治大学図書館所蔵の明示と加工の明示が条件・4,429 コマ）は公開画像の
解像度では翻刻が 2 回の読みで村名 98.8%・石高 89.9%・領主 81.3% しか一致しない（`scripts/histrecon/kyudaka-meiji-pilot.json`）。
高精細な画像（明治大学への照会）と互いに独立した 3 人読み・郡の村数と石高の合計による検算が揃うまで出荷しない。
1891–1943 年の府県は `scripts/histrecon/assembled/fuken-1891.mjs`（1920 年の町村の和集合）。
部品の集合が当時の土地を持たないときは `scripts/histrecon/annex/<KEY>.json`（`scripts/histrecon/annex.mjs`）が、別の部品の集合から
環 `within` の内側に外環が丸ごと入る多角形だけをその単位の区間に足す（和集合の外に並べ、切らない）。N03-1920 は 1950 年の
市町村で編まれていて択捉より北東の町村を持たないので、1891〜1943 年の北海道庁に得撫島から占守島までの千島（1875 年の条約で
日本領、1945 年まで）を geoBoundaries の北千島・千島の郡から足す。千島国・根室国は北海道庁の中の地理的な国で、第1級区分ではない。

**精度を保って組めない所（調べ尽くした結果）**: ムガルのスーバ（測量された線が無い）、オスマンの 16–19 世紀の
エヤレト・アラビアとリビアのヴィラーエト（線が引かれていない）、オスマン期のシリア・イラク・アラビアのヴィラーエト
（今日の郡の線が当時の県境と一致すると示す変更一覧が無い）、カージャール朝のイラン（1907 年法の郡の一覧と 1911 年の
区分図が手に入らない）、1708 年以前のロシアの郡と 1775 年以前の旧県（郡の一部が魂数で振り分けられた）、
1708–1822 年のシベリアの県（要塞線・ゴルビツァ川の条約線が 1897 年の郡を横切る）、清と中華民国の省（再配布できる部品が
無い——上の CHGIS 派生を参照）、満洲国の省（再配布可能な形が無く、戦後に郡界が大きく引き直された）、清代台湾の番界、
1500 年より前のほぼ全域（線を運ぶ部品が無い）、先史・文化圏の「政体」（区分が存在しない）。
