# IntMap — 産業立地データ（Siting）

> 「半導体の工場を置くなら、どの土地が有利か」に、公開統計の実数で答えるためのデータ・エンジン・Atlas の扉の正本。
> 企業と拠点は [`COMPANIES.md`](COMPANIES.md)、データの出自・権利・鮮度の規則は [`DATA-GOVERNANCE.md`](DATA-GOVERNANCE.md)。

## 1. 何のためにあるか

立地は条件の束で、電力の値段・用地の値段・雇える人・近くの研究機関・適用される規則を並べないと比べられない。
これらは IntMap のどこにも並んでいなかった。`data/siting/<国>.json` が**出典が述べた数だけ**を行政区域ごとに置き、
`js/siting.js` が読み、Atlas の `siting.compare`（`js/atlas-cap-siting.js`）が答える。

**総合点は出さない。** 何が効くかは工場で違うので、重みは利用者か Atlas が述べるもので、ここに隠さない。
順位は指標ごと（1 = その指標の良い側。価格なら安い、件数なら多い）。

## 2. データ（日本・都道府県別 — `data/siting/jp.json`、`scripts/build-siting-jp.mjs` が書く）

| 次元 | 指標 | 出典 | 注意 |
|---|---|---|---|
| power | `power_spot_avg` `power_spot_day`（円/kWh） | JEPX スポット市場 エリアプライス（最新の完結した年度の全コマ平均／8-18 時平均） | **卸のエネルギー価格**で、工場が払う料金（託送・賦課金を含む）ではない。県→エリアは供給区域の事実。静岡は東西で事業者が分かれる（註を出す）。沖縄は JEPX のエリアではなく null |
| land | `land_ind_median` `_min` `_max` `_n`（円/㎡） | 国土数値情報 地価公示（L01）の標準地のうち、用途地域が工業・工業専用、または利用現況が工場のもの | 標本が少ない県がある（`_n` を必ず併記）。標準地そのもの（座標・価格）も `sites` に持つ |
| labor | `labor_min_wage` `_prev`（円/時）、`labor_working_age` `labor_openings_ratio` `pop_total` | 厚生労働省 地域別最低賃金（発効日つき。**いま有効な改定**を採り、まだ発効していない改定は `pending`）／SSDSE-B | 最低賃金は賃金の床で、技術者の相場ではない。有効求人倍率は「労働力の競争」を表し容量ではない |
| research | `research_universities` `_faculty` `_students` | SSDSE-B（学校基本調査） | 大学の数・教員・学生。研究所は含まない |
| regulation | `rules[]`（国単位の規則） | e-Gov 法令 API: 工場立地法 第11条・同施行令 第2条 | 届出が要る規模（敷地 9,000㎡／建築面積 3,000㎡）と、届出受理から 90 日の着工制限。ビルド時に条文から文言を取り、数字が変われば落ちる |
| anchors | 企業拠点 | `data/companies/footprint.json` の日本の拠点を、Natural Earth admin-1 のポリゴンで県に落としたもの | 足さない・推測しない。海岸で簡略化された輪郭の外に落ちた点だけ、0.1° 以内の最寄りの県へ |

**空白は `gaps` に理由つきで残す。** 現在: 工業用水（商用で使える公開源に届かなかった — 国土数値情報のダム W01 は非商用に限られ、METI 経済構造実態調査の
Excel は bot 確認の裏にあり、これを回避しない）、物流（地図レイヤーはあるが県の表に結んでいない）、小売の産業用電力料金（県別のオープンデータが無い）。

## 3. 世界へ広げる設計

国ごとに同じスキーマの 1 ファイル（`data/siting/<iso2>.json`）を足す。指標 id（`power_spot_avg` ほか）・単位・`better`・出典・版は各国のファイルが宣言し、
`loadSiting(cc)` と `compare()` は国名を一つも知らない。国をまたぐ比較は、同じ指標 id を宣言した国どうしだけで行う（出典が違えば `source` と `vintage` で見える）。
次の国で最初に要るのは、その国の行政区域の識別子（ISO 3166-2）と、電力・用地・賃金の公開源の特定。

## 4. 検査

`tests/siting-checks.test.mjs`（`npm test` に入る）— 47 県が 1 つずつあること／全指標が出典と版を持つこと／用地の値が同梱の標準地から再計算できること／
同じ電力エリアの県が同じ価格であること／拠点が footprint の日本の拠点そのものであること／空白が黙って埋まらないこと／順位の向き・名前解決・失敗コード／条文の文言。
出典の鮮度は `check:datagov`（`GOVERNANCE`・周期 P1Y の根拠は `scripts/lib/upstream-cadence.mjs` `SITING_JP`）。

## 5. 再取得

`node scripts/build-siting-jp.mjs`（network）。`--check` は上流と同梱のバイトを比べる。最低賃金は**ビルドの日に有効な改定**を採るので、改定の発効日をまたぐと値が動く。
