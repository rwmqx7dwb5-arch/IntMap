# IntMap — よくある質問と、その答えの根拠 (Sales FAQ)

> 問い合わせへの返信で使う答え。**公開ページに載っている問い**は、文の正本が `scripts/org-pages-text.mjs`
> （en + jp）なので、ここでは**根拠**だけを示し文を写さない。公開ページに無い問いは、ここに答えを書く。
> 新しい問いに答えたら 1 行足す。答えられない問いは**推測で答えず**運営者に確認する。

## 公開ページに載っている問い（文は `scripts/org-pages-text.mjs`）

| 問い | 載っているページ | 答えの根拠 |
|---|---|---|
| 料金はかかるか | 報道・学校・研究・料金欄 | `PRODUCT.md` §2.4、[`pricing.md`](pricing.md) |
| 埋め込みは同じ表示のままか | 報道 | `js/embed-mode.js`（表示の全状態は共有リンクと同じアドレスに入る） |
| 画像を紙面に使えるか | 報道 | 出典ごとの条件（`sources.html`・`js/reference-data.js`） |
| 読者は追跡されるか | 報道・学校 | プライバシーポリシー §4（`js/legal-text.js`・`scripts/outbound-hosts.json`）。広告・外部解析なし |
| 契約や学校向けライセンスは | 学校 | `LICENSE` §2（教育目的は無料） |
| 地図に誤りがあったら | 学校 | アプリ内のフィードバック（`js/feedback.js` → `reader-reports`） |
| 助成プロジェクトで使えるか | 研究 | `LICENSE` §2・§3 |
| どう引用するか | 研究 | 元データが著作者。IntMap は描画したツール |
| API はあるか | 研究 | 製品としては無い |

## 公開ページに無い問い

| 問い | 答え | 根拠 |
|---|---|---|
| オフラインで使えるか | 地図はネットワークからタイルとデータを読みます。一度見た地図タイルはブラウザに保存されることがありますが、オフラインでの利用は保証していません。 | `sw.js`（タイルのキャッシュ） |
| 自分たちのサーバーに置けるか | ソフトウェアの複製・設置は `LICENSE` の条件に従います（個人・教育・非営利研究は可、商用は別途ライセンス）。各データの条件はそれぞれの出典に従います。 | `LICENSE` §2・§3・§5 |
| ロゴや名前を消して使えるか | できません。著作権表示と帰属表示は残す条件です。 | `LICENSE` §4 |
| 地図の言語は | 画面は 9 言語。IntMap が書く文は英語と日本語が正本です。 | `CONSTITUTION.md` §7 |
| 係争地の表示は誰の立場か | 出典データに基づく技術的な表示で、いかなる立場も主張しません。 | 利用規約 第11条 |
| 稼働率・障害の連絡は | 稼働保証はありません。障害の連絡の仕組みもありません。 | 記録が無い（約束しない） |
| 返信はいつ来るか | 時期の約束はしません。 | 利用規約 第13条 |
| 個人情報をどう扱うか（相談フォーム） | 回答のためだけに使い、管理者だけが読み、受信から 730 日（迷惑なものは 30 日）で削除します。 | `20261003100000_org_inquiries.sql` の `purge_org_inquiries` |
