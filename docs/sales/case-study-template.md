# IntMap — 導入事例の型 (Case-study template)

> **事例は、実在し、相手が書面で公開に同意したものだけを書く。** 架空・匿名の合成・「〜のような学校」は書かない
> （`CONSTITUTION.md` §0、`PRODUCT.md` §2.1）。2026-10-03 時点で**公開できる事例は 0 件**——公開ページは
> 「導入事例はまだありません」と書いている（`scripts/org-pages-text.mjs` の `exampleNote`）。
> 1 件目を公開するときは、その文も同じコミットで直す。

## 公開してよい条件（全部そろってから）

1. 相手の組織名・担当者名・掲載してよい範囲について、**相手から書面（メール可）の同意**がある。
   同意のメールは `org_inquiries` の該当行のメモに日付つきで記録する（行は 730 日で消えるので、運営者の手元にも保存）。
2. 書いた本文を**相手が読んで了承した**。
3. 数字（生徒数・閲覧数・時間の短縮など）は**相手が測った数**だけ。IntMap 側で推定しない。
4. 載せる地図は実際に開ける共有リンク／埋め込みで、出典の表示が残っている。

## 型

```
# <組織名> — <一文の要約：何に IntMap を使ったか>

- 区分: 報道機関 / 学校・教育委員会 / 研究機関・NGO
- 時期: <YYYY 年 M 月から>
- 掲載の同意: <YYYY-MM-DD に書面で取得>

## 課題
<相手の言葉で。引用なら引用と分かるように>

## 使い方
<どの地図を、どこで、どう使ったか。実際の共有リンク／埋め込みを 1〜3 本>

## 結果
<相手が測った数、または相手の言葉。無ければ「数字は測っていない」と書く>

## 相手のひとこと（任意）
<本人が了承した文だけ>
```

## 公開する場所

`scripts/org-pages.mjs` に事例の節を足して en + jp で生成する。
