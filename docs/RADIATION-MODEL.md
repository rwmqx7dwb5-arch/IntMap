# IntMap — 放射性物質拡散モデルの正本 (Radioactive dispersion model)

> **`js/radiation-model.js` に書いてある数のすべてが、どこから来て、いつ無効になるかを書く場所。**
> モデルの構造（どのファイルが何を持つか）は [`../Architecture.md`](../Architecture.md) §7.9、
> ファイルの役割は [`FILES.md`](FILES.md)、検査は [`TESTING.md`](TESTING.md)。
> **ここは「なぜその数なのか」だけを持つ。**
>
> ⚠ **このモデルは HYSPLIT / FLEXPART の代わりではない。** 設計思想（ラグランジュ粒子輸送＋乱流拡散
> ＋乾性湿性沈着）は同じ系統だが、気象場は公開 API の格子点であって数値予報モデルの全格子ではなく、
> 化学も、湿度依存の粒径成長も、地形の効果も入っていない。**この文書が言えるのは「どの数がどの一次
> 資料の何であるか」までで、「実際の被害がこの通りになる」ではない。**

## 0. なぜこの文書があるのか

`#R568` で外部から 10 点の講評を受けた。要旨は「教育・探索用としては良い、**定量的に読むモデルとしては
危険**」。10 点のうち 6 点は**上流に訊けば分かることを訊いていなかった**ことによる欠陥で、残る 4 点は
**根拠のない数を根拠のあるものとして印字していた**ことによる欠陥だった。後者を二度と起こさないために、
数の出所を 1 か所に集める。

**`js/radiation-model.js` に定数を足すときは、ここに行を足す。**
`AGENTS.md` §3 の 9（`.agents/rules/no-ad-hoc-hardcoding.md`）が要求する 3 点——**観測・失効条件・正本**
——のうち、このモデルの「正本」はこの表である。

## 1. 事故ごと × 核種ごとの大気放出量 (source term)

⚠ **1 つの事故に 1 つの放出量は存在しない。** #R568 以前は `chernobyl: 8.5e16 Bq` を選ばれた核種に
そのまま渡していたが、8.5×10¹⁶ Bq は**チェルノブイリの Cs-137** であって、同じ事故の I-131 は
その 20 倍、Sr-90 は 8 分の 1 である。

## 2. 地表沈着 → 外部被ばく線量率 (ground shine)

`ISOTOPES[*].gsh`、単位は **Sv/h あたり Bq/m²**。成人、無限平面上に立位。

| 核種（娘核種込み） | 値 (Sv/h per Bq/m²) | 導出 |
|---|---|---|
| Cs-137 (+ 0.947 × Ba-137m) | 1.27 × 10⁻¹² | FGR-15 の実効線量から**皮膚項を除いたもの**に娘核種を加算 |
| Cs-134 | 3.50 × 10⁻¹² | 同上（皮膚は 1.5%） |
| I-131 | 8.57 × 10⁻¹³ | 同上（皮膚は 2.0%） |
| Sr-90 (+ Y-90) | 1.08 × 10⁻¹⁴ | 同上 |

**正本**: Federal Guidance Report 15, **EPA 402-R-25-001 (2025-07)**, Table 4-1「Adult」列 / 配布データ
`RefAdult_GrdPl.DAT` の `e` 列。<https://www.epa.gov/system/files/documents/2025-07/fgr15_rev2025july_final_508.pdf>

### ⚠ なぜ皮膚項を除くのか（この行が無いと表が読めない）

- FGR は**親核種のみ**を表にする。Cs-137 の光子はほぼ全部 **Ba-137m** から出るので、娘核種を足すのは
  省略ではなく必須（分岐比 0.947、IAEA/ENSDF）。
- FGR-15 は ICRP 103 に基づき、実効線量に**皮膚を w_T = 0.01 で含む**。純ベータ核種ではその 1 項が
  公表係数の **92〜97%** を占め、その結果 **Sr-90+Y-90 が Cs-137+Ba-137m の 30%** になる。
  それは皮膚についての正しい数だが、**サーベイメータが読む量でも、避難基準が書かれている量でも、
  このモデルが µSv/h と呼んでいる量でもない**。皮膚項を除くと Sr-90+Y-90 は Cs-137 の **約 1/120** で、
  これが文献と直観の一致する関係。
- 貫通線量として見た FGR-15 は **ICRP 144 と数%で一致**する（ORNL/SPR-2025/3803 Table 4: Na-22 1.03、
  Co-60 1.02）。Cs-137 だけ 26 倍ずれるのは、まさにこの皮膚・電子の扱いの違い。

### ⚠ 使ってはならない版

**EPA 402-R-19-002 (2019) と 402-R-18-001 は撤回されている**（EPA 自身が線量係数表に誤りがあったと
明記）。2019 年版の成人 Cs-137 地表値は現行の 26 倍。

**失効条件**: EPA が FGR-15 を再改訂したとき、または本モデルが皮膚込みの量を報告するように変わったとき
（そのときは数だけでなく**提示する文言も**変える必要がある）。

## 3. 沈着密度による法定区分 (zoning)

`RAD.zonesFor(isotope)`。⚠ **核種ごとに存在したりしなかったりする。**

### Cs-137 — 存在し、3 か国で同一

| kBq/m² | Ci/km² | 区分 |
|---|---|---|
| ≥ 1480 | 40 | 強制移住 |
| 555–1480 | 15–40 | 義務的避難／後続移住 |
| 185–555 | 5–15 | 移住権 |
| 37–185 | 1–5 | 要観察・優遇的社会経済状態 |

- ロシア連邦法 1244-1 (1991-05-15) 第 8〜11 条 — [ru.wikisource](https://ru.wikisource.org/wiki/%D0%97%D0%B0%D0%BA%D0%BE%D0%BD_%D0%A0%D0%A4_%D0%BE%D1%82_15.05.1991_%E2%84%96_1244-I/%D0%A0%D0%B0%D0%B7%D0%B4%D0%B5%D0%BB_II)
- ウクライナ法 791а-XII (1991-02-27) 第 2 条 — [НКРЗУ 公式](https://nkrzu.gov.ua/dial/eks/eks-zon) ／ [zakon.rada.gov.ua](https://zakon.rada.gov.ua/laws/show/791%D0%B0-12)
- ベラルーシ法 385-З (2012-05-26) 第 6 条 — [etalonline.by](https://etalonline.by/document/?regnum=h11200385)。**法文自身が両単位を併記**しており、1 Ci/km² = 37 kBq/m² が立法上明示されている
- 換算は厳密値: 1 Ci = 3.7×10¹⁰ Bq、1 km² = 10⁶ m² ⇒ 1 Ci/km² = 37 kBq/m²（丸めではない）

### Sr-90 — 存在するが、**3 か国で値が違う**

モデルはウクライナ法 791а-XII の 3 段を使い、**凡例に「(UA)」と書く**。ロシアは 3.0 Ci/km² の 1 段だけ、
ベラルーシは 0.15 / 0.5 / 2 / 3 Ci/km² の 4 段。「旧ソ連 3 国に共通の Sr-90 のはしごがある」は誤り。

| kBq/m² | Ci/km² | ウクライナ法の区分 |
|---|---|---|
| ≥ 111 | 3.0 | 無条件（義務的）移住 |
| 5.55–111 | 0.15–3.0 | 保証付き自主移住 |
| 0.74–5.55 | 0.02–0.15 | 強化放射線生態管理 |

### I-131 と Cs-134 — **存在しない**

3 法とも核種の列挙は **Cs-137 / Sr-90 / プルトニウム**の 3 つだけで、I-131 は現れない。構造的な理由が
あり、これらの法は事故の 5 年後に**長寿命核種による恒久的な居住制限**のために作られている（I-131 は
制定時点で 200 半減期以上経過している）。I-131 に対して存在するのは**線量率**（IAEA の OIL）と
**食品中濃度 Bq/kg**（Codex CXS 193、日本の暫定規制値）であって、**Bq/m² の防護行動トリガーは国際的な
EPR 体系にも存在しない**。

⇒ この 2 核種には**政策的な語を持たない密度の段**（10⁰〜10⁴ kBq/m² のディケード）だけを出す。
#R568 以前は Cs-137 の 1480/555/185/37 を全核種に流用し、**ヨウ素の沈着に「強制移住」と塗っていた**。

### 日本（福島）

⚠ **沈着密度による区域指定は存在しない。** 警戒区域は 20 km という**距離**、計画的避難区域とその後の
3 区分は**積算実効線量**（20 / 20–50 / 50 mSv/年）で定義されている（環境省・原子力安全委員会）。
MEXT/DOE の航空機モニタリングによる Bq/m² 地図は**科学的成果物**であって区域指定の法的基準ではない。

**失効条件**: いずれかの国が法を改正したとき。

## 4. 環境半減期 (weathering)

`ISOTOPES[*].weather`。沈着した核種の**地表線量率**が、放射性崩壊とは別に、土壌への浸透・流亡で減る分。
2 成分指数モデル `Σ f_i · exp(−ln2 · t / T_i)`。

| 核種 | 速い成分 | 遅い成分 |
|---|---|---|
| Cs-137 / Cs-134 / Sr-90 | f = 0.45, T = 1.5 年 | f = 0.55, T = 50 年 |
| I-131 | f = 1.0, T = 30 日 | — |

⚠ **I-131 の 1 成分は近似である。** 物理半減期 8.02 日が支配的で、1 年の積分に効くのは実質的に崩壊の
ほうであり（下の §6 で 110 実効時間、ほぼ全部が最初の 1 か月）、この 30 日成分を 20 日にしても 60 日に
しても初年度線量は数%しか動かない。**それでも 1 成分と書いてあるのは、書かずに崩壊だけにすると
「洗い流されない」と主張することになるから。**

**失効条件**: このモデルが数十年スケールの積算を報告するようになったとき（そこでは遅い成分の係数が
支配的になり、いまの粗さが効いてくる）。

## 5. 大気の乱流 (turbulence)

⚠ #R568 以前は `stab = 0.6 + (気温 − 5)/25` で拡散係数を決めていた。**気温は安定度ではない**——20 °C の
夜と 20 °C の対流的な午後は同じ大気ではない。

| 量 | 式 | 係数の出所 |
|---|---|---|
| 摩擦速度 | u\* = k·U(10) / ln(10/z₀) | k = 0.4（カルマン定数）、z₀ = 0.1 m（陸上の粗度。Stull §9.7） |
| 中立時の境界層高度 | h = c · u\* / f | c ≈ 0.2（Rossby–Montgomery）。⚠ **上流が境界層高度を返すときは使わない**（下記） |
| 鉛直・水平の速度分散 | σ_w = 1.3 u\*、σ_u = σ_v = 2.0 u\* | Hanna (1982) の中立スケーリング |
| ラグランジュ時間尺度 | T_Lw = 0.5 h/σ_w、T_Lu = 0.15 h/σ_u | 同上 |
| 拡散係数 | K = σ² · T_L | |

**境界層高度は上流に訊く。** Open-Meteo の forecast は `boundary_layer_height` を返す（実測 2026-09-09:
福島、260 / 345 / 520 m）。**ERA5 archive は返さない**（同日実測: キーは来るが値は全部 null）。だから
過去の日付を指定した run だけが上の Rossby 数式にフォールバックし、その事実は `pblEstimated` として
報告される——**1986 年の混合層高度を知っているふりをしないため**。

境界層は**蓋**であり、粒子はその下では 0 と h で反射し、**その上に出た粒子は地面と切り離される**
（乾性沈着せず、自由対流圏の弱い拡散だけを受ける）。放出高度が結果を左右するのはこれがあるからで、
実測では 800 m の混合層内からの放出が 12 時間で 4.9% を沈着させるのに対し、2,500 m からは 0.8%。

**失効条件**: Open-Meteo が archive にも境界層高度を出すようになったとき（フォールバックが不要になる）。

## 6. 沈着と線量の時間積分

| 量 | 値 | 出所・注 |
|---|---|---|
| 乾性沈着速度 v_d（エアロゾル） | 1.0 × 10⁻³ m/s | 微小粒子の標準的な値。**箱モデル**として h（混合層厚）で割って損失率にする |
| 乾性沈着速度 v_d（ヨウ素） | 5.0 × 10⁻³ m/s | ヨウ素は粒子状・元素状・有機の混合で輸送されるため速い |
| 湿性洗浄 Λ = A·I^B（I は mm/h） | A = 1.0 × 10⁻⁴, B = 0.79 | エアロゾルの標準形 |
| 重力沈降 v_s | 3 × 10⁻⁵ m/s（エアロゾル）／1 × 10⁻⁴（ヨウ素） | ⚠ #R568 以前は 0.002〜0.022 m/s だった——それは 10〜100 µm の**塵**の落下速度で、事故放出の微小エアロゾルのものではない |
| 沈着可能割合 | 0.55（エアロゾル）／0.75（ヨウ素） | 希ガスは地面に落ちない。核種の**形態**の性質。⚠ **セシウムとストロンチウムについては根拠が無い**（放出量はその核種の放射能で、希ガスは入っていない）。直したときの効き目と、既定値を変えていない理由は §10b。1 回の実行で変えるには `simulate` の `depositableFraction` |
| 遮蔽・滞在係数 | 0.5 | 屋内滞在と建物遮蔽の慣用値 |

**初年度の外部被ばく線量**は次の積分で、掛け算ではない:

```
D(T) = Ḋ(0) · ∫₀ᵀ exp(−λ_r t) · Σ fᵢ exp(−λᵢ t) dt · 0.5
```

⚠ #R568 以前は `ピーク µSv/h × 8766 × 0.5`、すなわち**「この線量率が 1 年続く」**だった。実効時間で
比較すると: Cs-137 **3,929 h**、Cs-134 **3,393 h**、**I-131 110 h**——素朴な積の 4,383 h に対して、
ヨウ素は **40 分の 1**。半減期 8 日の核種に 1 年分を掛けていたのがこの項目である。

**失効条件**: 摂取・吸入経路を足したとき（そのとき「線量」は外部被ばくだけではなくなる）。

## 7. モンテカルロ誤差 — なぜピーク値に誤差棒が付くのか

粒子は**質量を連続的に失う**（FLEXPART と同じ扱い）。以前は 1 粒子が丸ごと 1 セルに死んでいたので、
2,600 粒子 × 8.5×10¹⁶ Bq では 1 粒子が 1.8×10¹³ Bq を代表し、**ピークセルはコイン投げ**だった。

いまは 1 粒子が経路上の多数のセルに寄与する（実測: 1,000 粒子が 1,000 以上のセルを埋める）。各セルは
**寄与した相異なる粒子の数 n** を数え、相対標準誤差を **1/√n** として報告する。**n < 30 のセルについて
は数値を出さない**——誤差棒の無い数は「誤差が無い」と読まれるから。

**worker で 20,000 粒子、worker が無い環境では 4,000 粒子**で、どちらで走ったかは `engine` として
報告される（誤差棒が違うものを同じ声で言わないため）。

**失効条件**: 沈着の格子解像度 `depRes` を変えたとき（セルあたりの粒子数が変わるので 30 の意味も変わる）。

## 8. 気象場の解像度と領域

| | 内側ネスト | 外側ネスト |
|---|---|---|
| 格子 | 7 × 7（49 地点） | 9 × 9 〜 13 × 13（81〜169 地点） |
| 範囲 | ±0.75°（間隔 0.25° ≈ 25 km） | 平均風 × 追跡時間 × 1.6、最大 ±15° |
| 間隔の上限 | — | **2.5°** |

⚠ **③（解像度）と ④（領域）は互いに引っ張り合う。** 9×9 のまま 80 時間のプルームに合わせて領域を
広げると間隔が 5° ≈ 450 km になり、**このラウンドが置き換えた ±2.6° の箱より 5 倍粗くなる**。だから
点数も領域と一緒に増やし、両方に上限を置く。上限は**実測で決めた**——2026-09-09、forecast 4 日・
9 変数に対して 121 地点 6.9 s、169 地点 6.9 s、**225 地点 21.5 s**。169 が読み手が待てる最後の大きさ。

領域を出た粒子は**退役して数えられる**（`escapedFrac` / `escapedMassFrac`）。以前は座標を格子境界に
クランプしていたので、領域外の粒子が**境界セルの風で永久に押され続けた**まま、最大 900 km の到達距離が
印字されていた。到達距離はいま**粒子から測る**。

**地域の入れ子（任意）。** `RAD.midPlan` は ±2.5° に 13 × 13（間隔 0.42° ≈ 46 km）——外側と同じ 169 点で 6 倍細かい。
場 `F` に `mid` があれば、風・雨・境界層は「内側 → 地域 → 外側」の順に、細かい側の重み（`nestBlend`）で混ぜる。
無ければ従来の 2 枚と**同じ計算**（同じ種なら同じ沈着）。⚠ **ライブのシミュレータはまだ取得していない**（点数の予算）。
答え合わせでの効き目は §10b。

**時間変化する放出（任意）。** `simulate(F, src, { release: [{ t0, t1, bq, zBot, zTop }] })` は区間の表を受け取る
（`t0`/`t1` は実行の開始からの時間、`bq` はその区間で出た放射能、高さは地上 m）。粒子は**同じ放射能を運ぶ**ので、
放出の半分を出した区間は粒子の半分を受け持つ。各粒子の放出時刻と高さは累積放出の逆関数を (i + ½)/N で引いて決める
（決定的なので、乱数は従来どおり輸送だけに使われる）。窓の外の区間は放出せず、結果の `releaseOutsideBq` が量を述べる。
`release` が無ければ従来の「一定の速さで `emitHours`」の経路がそのまま走る。

**失効条件**: Open-Meteo の応答速度が変わったとき（上の実測をやり直す）。

## 8b. 乱数の種とアンサンブル

- **乱数には種がある。** `simulate(F, src, {…, seed})` は種があればその間だけ mulberry32 を使い、
  無ければ従来どおり `Math.random`。同じ種・同じ風・同じ引数なら沈着格子は**完全に一致**する。
  種はパネル・Atlas の回答・登録されるデータセットの出自に載る。
- **アンサンブル**（`RAD.ensemble`）＝ **種 × 放出量の倍率**。沈着は放出量に**線形**（各粒子が bq/N を運ぶ）
  なので、§1 の**報告されている幅**（下限・上限）は解き直さず**倍率で**入れる。乱流は線形ではないので、
  種は**解き直す**。プリセットの放出量を使ったとき（`bq` を指定していないとき）だけ幅を入れ、
  そうでなければ種だけのアンサンブルになり、回答がどちらかを述べる。
- セルごとに全メンバーの密度（置かなかったメンバーは 0）から **10・50・90 パーセンタイル**の地図を作り、
  **区分ごとの面積と最大値はその 3 枚の地図から読む**。p90 の面積は「悲観側の地図の面積」であって、
  面積の 90 パーセンタイルではない。

## 9. このモデルが**やらないこと**

- 化学（ヨウ素の形態変化、粒径成長）
- 地形の効果（山越え、谷での滞留）——気象場は格子点の内挿だけ
- 湿度依存の沈着
- 摂取・吸入・甲状腺等価線量（**Sr-90 の危険はここにあるが、このモデルは外部被ばくしか計算しない**）
- 再浮遊
- 混合層より上の詳細な鉛直構造（自由対流圏は 1 つの弱い拡散係数で代表している）

### なぜ良くないのか（わかっていることと、わかっていないこと）

- **わかっている**: プリセットは**一定の速さで 120 時間**放出する。実際の放出は特定の風と雨に結びついた何度かの山で、
  どの時刻にどれだけ出たかは**逆解析の結果**（UNSCEAR が採る Terada ほか 2020、JAEA の Katata ほか 2015 など）である。
  （当初 `simulate` は時間変化する放出率を受け取れなかった。今は受け取れ、その効き目は §10b が測る。）
- **わかっている**: 全沈着の約 78 % は調査された範囲の外に置かれた（上の表の最終行の裏返し）。
- **切り分けた（§10b）**: 放出の時間変化・地域の風・沈着可能割合を 1 つずつ足すと、相関は主に放出の時間変化で、
  量の外れは主に地域の風と沈着可能割合で縮む。残り（最後の段でも中央のセルが約 3.5 分の 1）は**切り分けていない**。

### 何を守っているか

`tests/radiation-hindcast-checks.test.mjs` が同じ手順（種も同じ）でモデルを回し直し、
**上の指標のどれかが記録値より悪化したら赤**になる。さらに、束の `model` の地図が今のモデルの出力と一致しているかも見る
（**読者に見せる地図＝モデルの今の答え**）。モデルを改善して数が良くなったときも、記録が古いと赤になるので、
`--offline` で束を作り直し、**この節と `js/locales/pages.*.js`（science.html の放射性プルーム節）の数**を同じコミットで更新する
（検査がこの節の数を束と照合する）。

**失効条件**: ① 実測の束を置き換えたとき（出典・日付・md5 を書き直す） ② `fukushima` プリセットの放出量・高度・時間を変えたとき
③ モデルの物理を変えたとき ④ ERA5 の取り直し。

### ⚠ 読者に向けて

この比較は**この 1 つの事故・この 1 つの気象・このモデルの既定値**についてのもので、「他の事故や他の場所でも同程度に外れる」ことも
「当たる」ことも言わない。シミュレータのパネル（「2011 年の答え合わせ」）は、実測・モデル（p50）・両者の比を同じ尺度で描く。

  のどれか（またはすべて）で、**切り分けていない**。

**⚠ 独立の検証ではない。** JAEA の放出の時間変化は、**拡散モデル（WSPEEDI-II）を大気中濃度と線量率の実測に合わせて**
逆推定されたもので、論文はそれが航空機モニタリングの沈着を再現すると述べている。`jaea` 以降の段の点が上がっても、
それは「このモデルが 2011 年を予測できた」ことを意味しない——**どの要因がどれだけ効くか**の測定である。パネルと Atlas は
この段を表示するたびにそう述べる。

**⚠ ライブのシミュレータは、まだ `preset` の段のまま。** 地域の入れ子は取得していない（API の点数の予算。§8）し、
セシウムの 0.55 も変えていない。0.55 を 1 にすると §10 の門のうち 1 MBq/m² の figure of merit が 0.191 → 0.179 に下がり
（許容幅 0.01 を超える）、**門を弱めずには既定値を変えられない**——プリセットの熱い場所がずれているので、量を正しくすると
外れた場所の面積が広がる。既定値の変更は判断が要るので、ここでは測って記録するだけにした。

**守っているもの**: `tests/science-next-checks.test.mjs` が 3 段を worker で並列に回し直し、**どの指標も記録より悪化したら赤**、
読者に見せる地図が今のモデルと違えば赤（§10 と同じ許容幅）。放出表は Copernicus の付属 zip の md5 を固定し
（`scripts/build-fukushima-release.mjs`。上流は md5 を公表していないので 2026-10-03 の実測値）、区間の和が CSV 自身の
総量（14.5 PBq）と 1 % 以内で一致しなければ書かない。風は `node scripts/radiation-hindcast-fetch-wind.mjs` が**足りない入れ子だけ**
取り（既にある入れ子は取り直さない＝記録を取り直した日に依存させない）、`tests/fixtures/radiation-hindcast-era5.json.gz` に固定。

**失効条件**: §10 の 4 つに加えて ⑤ 放出表を置き換えたとき（Terada ほか 2020 が再配布できる形で出たら採る）
⑥ `RAD.midPlan` を変えたとき（風の固定を取り直す）。
